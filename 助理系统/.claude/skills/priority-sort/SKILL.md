# 优先级排序

## 触发

"排序""最该做什么""先做哪个""轻重缓急""太多事忙不过来"

## 工作流程

```
① 拉取   待办档案（未完成）+ 事项档案（进行中）+ 想法池（可选纳入）
② 评分   每项按三维评分：
          紧急性：截止临近度（0-5）
          重要性：**显式读取身份档案「长期目标」**（愿景+1年目标定稿口径，如月入1万/主线涨薪/副线量化体系成型）后评分——该项推进哪个长期目标？关联度（0-5）；无关联可打低分，不得凭隐含印象给分（R-003 固定化）
          精力成本：完成所需精力（低分=高优先，用零碎时间能清的先清）
③ 排序   四象限归类 + 分数排序
④ 输出   建议执行顺序（今日可做项打★）
⑤ 落地   老板确认后重排待办档案顺序；完成项状态更新
```

## 输出格式

```markdown
📊 优先级排序（<日期>）
【今天就能做】★
  1. ……（原因：……）
【本周内】 2-4项
【可推迟】 …
【想法池参考】 若有已到启动时机者提示：I-0XX 已搁置 N 个月，考虑启动？

💡 建议：先清 2 个低精力项，再攻大项——减少待办心理负担
```
