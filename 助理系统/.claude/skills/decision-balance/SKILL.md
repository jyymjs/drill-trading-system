# 决策权衡

## 触发

"选哪个""A还是B""帮我权衡""纠结""利弊""要不要做X"

## 工作流程

```
① 确认选项   列出候选（通常2-4个），老板补充约束
② 对比矩阵   逐项分析（见格式）
③ 结合背景   读身份档案（长期目标）+偏好档案+决定档案（历史相关决定）
④ 给推荐     推荐+理由（助理有建议权，决定权归老板）
⑤ 落地      老板定案后 → 写入决定档案（含理由）
```

## 对比矩阵格式

```markdown
⚖️ 决策对比：<决策主题>
| 维度 | 选项A | 选项B |
|---|---|---|
| 优势 | | |
| 劣势 | | |
| 成本 | | |
| 风险 | | |
| 与长期目标契合度 | | |
| 适合场景 | | |

💡 推荐：A/B —— 理由：……
（结合你的：<引用相关档案依据>）
```

## 注意

- 若选项超出 4 个 → 先建议合并收敛
- 关键决策（涉及资金/职业/健康）→ 输出后建议老板再考虑一晚（决策冷静期）
