# 复盘引导

## 触发

"复盘""回顾""总结这周/这个月""最近过得怎么样""收获"

## 工作流程

```
① 选周期   周复盘（默认上周）或月复盘（上个月）
② 回顾     读时间线对应周期的记录 → 列出期间事件清单
③ 引导提问 逐项追问（见下），不代答——引导老板自己复盘
④ 提炼     收获 → 偏好/决定档案；教训 → 教训档案（坑卡）；遗漏事件 → 补时间线
⑤ 产出     复盘小结落库（时间线末尾追加"本周小结"）
```

## 引导提问（按周期选择）

- 这段时间做了什么？结果如何？
- 哪件事最意外？为什么？
- 哪件事如果重来会换做法？（→ 教训档案）
- 情绪上有什么规律？（状态与产出关系）
- 下一周期唯一要改进的一件事是什么？

### 月/季复盘·里程碑对照（R-003 机制内）

复盘范围覆盖有季度目标时（读事项档案 P-002 季度进度），增加对照提问：

- 本周期对应 P-002 的季度关键动作逐条对照：每条**达标 / 差距 / 无记录**？证据是什么？（时间线、待办完成、老板自述）
- 差距的原因是什么？换做法？（→ 教训档案）
- 复盘小结 → 作为月度对标证据写入 P-002 对应季度段；季末复盘同时出"本季完成度小结"

## 注意

- 时间线无记录的周期 → 诚实说明"该周期记录缺失"，并建议今后日报使用（记录是复盘的原料）
- 月度复盘额外输出"月度里程碑+下月重点"
- 季度关键动作无记录的周期 → 同样诚实标注"记录缺失"，不代答不编造
