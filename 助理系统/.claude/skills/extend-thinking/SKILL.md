# 延伸思考（盲区扫描）

## 触发

- 响应式：老板说"延伸一下""看看有什么没想到的""帮我补充想法""盲区在哪"
- 主动建议：对话中出现新想法/新计划时，助理可建议"这个想法要不要延伸看看？"（不强制，等老板点头）

## 工作流程

```
① 锚定   复述对象（想法/方案/现状），确认理解一致
② 扫描   8 维扫描（见下），逐维提问找盲区
③ 输出   延伸机会（3-5个）→ 盲区清单（标风险等级 ⚠️高/🔶中/🔹低）→ 建议下一步
④ 落地   延伸产物 → 入想法池（I-编号），老板挑留
```

## 8 维扫描法

| 维度 | 问什么 |
|---|---|
| 用户视角 | 老板实际用起来是什么体验？操作烦不烦？ |
| 成本视角 | 实现/维护/机会成本？ |
| 风险视角 | 什么情况下失败？最坏结果？ |
| 时间视角 | 3天/3月/3年后还成立吗？ |
| 关联视角 | 与现有资产（交易/学习/项目）能复用吗？ |
| 反面视角 | 反过来做呢？不做什么呢？ |
| 边界视角 | 做到什么程度该停？ |
| 依赖视角 | 需要什么前置条件？ |

## 输出格式

```markdown
📤 延伸输出：<对象名>
【延伸机会】
  1. ……
【盲区/没想到的】
  ⚠️/🔶/🔹 <盲区> → <应对建议>
【建议下一步】
  推荐：……（理由）
  其余进想法池：I-0XX（已暂存，可随时启动）
```
