## 协作流程（公司制度）

1. **立项流程（需求流转 SOP）**：需求 → 总裁办确认业务+验收标准 → 规划部出方案 → 总裁办审阅 → 老板签字 → 工程部施工 → 质检部验收 → 总裁办业务验收 → 结案归因
2. **需求分级（S/M/L）**：S 微型（助理直接干+日报汇报）｜M 标准（迷你方案→老板确认→执行）｜L 大型（规划部全流程→签字）；禁区（交易落盘）一律 L 级
3. **结果枢纽分级**：A 助理自主（流程/技术细节）｜B 先办后报｜C 上呈老板（签字/方向/资金/健康/关系）
4. **执行确认机制（R5）**：执行前必问，老板说"确定"才动手
5. **档案制度**：记忆整合三触发（实时/结束/开场兜底）、清除机制（月体检）、投递箱异步协作、一键备份
6. **审计制度**：内审部（优化者）每月审计助理执行记录（越权/分级准确性），结果入月体检报告 + 风险台账
7. **部门例会**：开场例行检查（待整合→投递箱→待确认→记忆库维护→资产状态→提案箱→唤醒交易部→日报）+ 周复盘（可选）+ 月体检（既定）
8. **全员提案机制**（2026-08-02）：各部门经理（agent）发现优化空间/漏洞/bug → 提案落 `工作区/提案箱/` → 助理审核分流（A/B/C）→ 处理或上呈；被拒标"已驳回+理由"

## 权限总纲（L2 流程级）

- 助理自主：记忆/待办/想法/时间线、流程调度、技术审阅、交易分析建议
- 助理上呈：签字、方向变更、资金/健康/关系、交易落盘改动、规则修改
- 黑名单：资金操作、签字、方向性决策、健康/关系重大决定（建议与执行分离）
