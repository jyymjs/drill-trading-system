# 交易部知识库管理规范

> 2026-08-03 老板拍板：交易知识全部归交易部自建知识库，交易部经理（trader）负责整理学习。
> 机制移植自原培训部 learn 技能（除系统学轨道/入库闸门外的全部机制）。

## 定位

- 交易部知识库 = 交易知识的唯一归属（课程/周会/扫盘/转写稿/学习产出）
- 交易部经理负责：入库、提炼、学习、复盘、矛盾排查
- 学习部（私人老师）可扫描本库查矛盾（发现矛盾 → 找交易部经理讨论）

## 目录结构

```
交易部/知识库/
├── index.md                    # 索引入口（主题清单）
├── 系统/知识库管理规范.md       # 本文件
├── 素材台账.md                 # 已处理素材登记（不重复提炼）
└── {主题}/                     # 如"第三十节-交易案例库"
    ├── raw/                    # 原始素材（转写稿等，保真不参与检索）
    ├── 知识卡.md               # 提炼后的结构化知识
    └── 错题卡.md               # 考问复盘用
```

## 入库检查单（提炼质量防线，逐项打勾）

1. **来源如实标注**（视频/日期/时长/素材路径）
2. **提炼防失真已过**（提炼五问 + 抗失真三查 + 三元组）
3. **知识接入关系判定**（与已有知识：互补/升级/冲突/重复，写明依据）
4. **元数据完整**（标题/主题/来源/日期/关键词/时效性/关联）
5. **素材台账已登记**（不重复提炼）

## 提炼五问（每条知识点过一遍）

1. 核心主张：材料到底在说什么？（一句话）
2. 依据：主张靠什么支撑？（数据/案例/推理）
3. 事实 vs 观点 vs 推论：哪部分是事实、哪部分观点、哪部分推论？
4. 适用条件：在什么条件下才成立？（边界/前提）
5. 保真：提炼与原意一致吗？（对照核对单）

## 抗失真三查

1. **数字原样**：数字/百分比/时间原样保留，不约整美化
2. **限定词保留**："可能/部分/特定场景下"不得删——删掉就夸大结论
3. **独立可读**：每条知识点脱离上下文也能读懂

## 三元组格式

每条知识点 = **结论 + 依据 + 条件**（缺一即不完整，宁缺毋滥）

## 检索协议（省 token 核心）

```
第 0 步 定检索面 → ① index.md 找主题 → ② 主题内文件列表
③ 文件名+元数据判相关性 → ④ 正文（仅通过 ③ 才打开）→ ⑤ 关联跳转
```
- raw/ 层不参与检索；主题已有知识卡时只读知识卡

## 知识接入五步

定位 → 对接（检索同主题旧产出）→ 判定关系（互补/升级/冲突/重复）→ 落地（互链）→ 索引

## 考问复盘（可选）

交易部经理可按 1/7/30 间隔复盘学习内容（错题卡），检验掌握度。

## 冲突处理（四步）

1. 记入矛盾清单（`系统/矛盾清单.md`）
2. 找学习部（私人老师）交叉核对
3. 找交易部经理讨论裁决
4. 裁决结果更新知识卡 + 记入素材台账

## 素材台账

已处理素材登记（路径/主题/处理日期/产出），启动学习前必查——不重复提炼。
