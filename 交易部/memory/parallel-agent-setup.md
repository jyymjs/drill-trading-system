在项目中配置了分身并行技能（parallel-agent），位于 `.claude/skills/parallel-agent/SKILL.md`。

**AI 自主决策规则：**
- 我会根据任务的重要性、复杂度、可分解性**自动判断**是否启用分身，无需手动命令
- ✅ 自动启用：多文件审查、多路搜索、多模块生成、多维度分析、大型研究
- ❌ 不启用：简单问答、单文件修改、有依赖链条的任务、复杂调试、架构设计
- ⚠️ 先询问：涉及文件修改的分身（需 worktree）、大规模并行（高 token 消耗）
- 手动覆盖：`/分身` 强制启用，`串行` 强制禁用

**适用场景：** 多文件独立审查、多路搜索、并行代码生成、多维度审查

**不适用场景：** 有依赖关系的串行任务、复杂调试、架构设计

**影响：** N 个分身同时运行 = 约 N 倍 Token 消耗；分身之间上下文隔离，不能共享信息

**Why:** 用户需要快速并行处理多个独立任务，提高工作效率

**How to apply:** 收到用户任务 → 评估是否可分解为独立子任务 → 若适合则自动启用 Agent 并发 → 汇总所有结果
