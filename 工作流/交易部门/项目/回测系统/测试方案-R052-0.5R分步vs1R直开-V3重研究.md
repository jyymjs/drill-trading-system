## 一、背景与目的

老板质疑 0.5R 分批建仓（600833 涨停但只持 0.5R 赚少了），要求重新讨论 0.5R vs 1R。R-041（2026-08-10，V2 前旧口径已归档）结论：0.5R 金额口径 +6.7% 反超、回撤减半——但**只有 26 年全量、资金层回撤未验证、无场景分层、用触发日涨幅的 B1/C2 提档方案因前视被否**。本方案在现行 V3 口径（S级/dn_confirm=1.5/C23/风险额 0.025×资金/无限制上限）下重研究，补齐缺口并回应老板痛点。

## 三、测试设计

### A. 引擎重跑 1R 直开信号集（后台 30-60 分钟）
- 命令：main.py run（r43_t2 参数重建，不加 --phase-in）→ 产出 `产出/输出/backtest_r52_1r/`
- 门禁：信号数 4,351、组合触发 22.1%、20d 触发 1,144——**不一致即停查**（phase_in 只改出场不改信号）

### B. 信号层对比（新 r52_phase_compare.py，回放 <5 分钟）
- 回放 1,144 笔 20d 触发（复用 r41_phase_variants 模板：confirm_replay.load_kline_cache + tracking._track_window/_trade_cost + indicators.half_position_confirm_delay2，成本开启）
- 双口径：r_full（全仓 R，E-046）vs r_money（金额加权：0.5R 权重 0.5/补仓 1.0/直开 1.0）
- **对账门禁 7 锚点**：逐笔 0.5R replay == r43_t2 r_20d（±0.005）、1R replay == r52_1r r_20d（±0.005）、聚合锚点（胜率/avgR/累计R/回撤）——不过即停
- 时间窗矩阵：26 年/近 7 年/近 3 年 × {avgR/胜率/累计R(r_full)/累计R(r_money)/累计R曲线回撤}

### C. 资金层对比（R-041 缺口：总资产口径回撤）
- r44.run_one 加 `half_phase: bool = True` 参数（默认 True 零变化，r48 run_cell 同步透传）
- 新 r52_capital_compare.py：6 格 = {r43_t2 × half_phase=True} vs {r52_1r × half_phase=False} × {26 年/近 7 年/近 3 年}，8401×0.025×999
- 指标：收益%/成交/avgR/**总资产口径回撤**（build_total_asset_curve 占峰值/占初始双口径）/回撤段/selfcheck；锚点 A26/A7y/A3y 零差门禁

### D. 变体矩阵（7 变体 × 3 时间窗 = 21 组，回放秒级）

| 变体 | 定义 | 前视检查 |
|---|---|---|
| V0 | 现行 0.5R 分步（delay2 确认） | 无（基线） |
| 1R | 一次直开 | 无（对照） |
| H1 | 信号日涨幅 ≥7% → 1R 直开；其余 0.5R | ✅ 信号日涨幅挂单时已知 |
| H2 | 信号日涨幅 ≥5% → 1R 直开；其余 0.5R | ✅ 同上 |
| V2 | 信号日涨幅 ≥7% → 0.5R 不补持有到底 | ✅ 同上 |
| V3 | 确认日收盘 > 开仓日收盘×1.05 → 放弃补仓 | ✅ 补仓决策在确认日收盘后做出 |
| V4 | delay2 关闭（严格首根判定） | 无 |

R-041 B1（触发日涨幅免确认）因前视不再重验；H1/H2 为无前视混合规则候选。

### E. 场景分层（回答老板 600833 痛点）
- 场景 1（决策可用）：信号日收盘涨幅分桶（≥7%/5-7%/3-5%/0-3%/负）——各桶 0.5R vs 1R 金额差
- 场景 2（描述性归因）：确认日收盘/进场价（≥1.05 大涨/1.0-1.05 小涨/<1.0 跌破）
- 环境分层：牛/熊/震荡（market_regime）下金额差
- 涨停级专项：confirm 率/追高幅度/金额差——"600833 类涨停只持 0.5R 亏多少/赚多少"量化

### F. 资金层增补（资金档交互）
- 30k × 3 窗 × {0.5R, 1R} = 6 格（资金充足时差异是否消失）
- 最优混合变体 × 8401 × 26 年 = 1 格（若 H1/H2 胜出，回放生成混合 signals）
- 蒙卡：0.5R / 1R / 最优变体三组成交集（code,date 共同成交）各 1 万次（同种子同 n）

### G. 结论与拍板（三形态）
1. 维持 0.5R（金额 ≥ 1R 且回撤显著小）→ 附 600833 场景量化解释
2. 改 1R（金额全面占优且回撤可接受）→ 引擎 phase_in=false 定案
3. 混合（H1/H2/V2/V3 若胜出）：只用挂单时可得变量 + 前视检查清单 + **引擎改造单独立项**（本方案只出证据）

## 四、实现

1. r44.run_one 加 `half_phase: bool = True`（默认零变化）+ r48 run_cell 透传 + 测试 1 条
2. 新 r52_phase_compare.py（B/D/E 信号层回放 + 对账 + 变体 + 场景）+ 新 r52_capital_compare.py（C/F 资金层 13 格 + 蒙卡）
3. 执行：引擎重跑（后台）→ 对账门禁 → 矩阵 → 报告
