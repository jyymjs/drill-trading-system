## 三、测试设计

### A. 扩展档位（继续补测②）

**波次 1（12 格，26 年全量）**：0.030 / 0.035 / 0.040 × 8401/30k/50k/100k（id X01-X12）。0.04@8401 风险额 336 元、每股风险上限 3.36 > C23 上限 3.0 → 全池可买；0.03 上限 2.52（2.5~3.0 桶部分买不到）；三档横跨"半池→全池"边界，定位顶点。

**波次 2（11 格，近 7 年 min_date=2019-01-01）**：0.030 / 0.040 × 4 资金（id W01-W08）+ **8401 档补 0.016 / 0.018 / 0.022（id W09-W11，审核意见 5：8401 档失控点在 0.020 附近——0.020 近 7 年 -22.7% 破线而 0.025 仅 -16.3% 未破，非单调，须中间格定位）**。

**波次 3（条件 4 格）**：0.040 在 4 资金档 DDR 全部仍高于 0.035 → 跑 0.050 × 4 资金（id X13-X16）。0.050 仍升 → **停止外推**（结构性说明收尾：C23 上限 3.0 已全池覆盖 + n_exec 见顶回落 + 资金不足占比上升）。

**波次 4（可选 4 格 + 1 复用）**：报告需要精确"破 -20% 最小比例"时跑 0.016/0.018 × 30k/100k × 近 7 年（P01-P04）；8401 档 0.020 **复用既有格 C8401_5_近7年（ret 615.8 / dd -22.7）不重复跑**。

**判定（v2 双判据，审核意见 6）**：顶点 = DDR 首次回落档；失控点 = **逐档实测回撤对照 -20% 线**（不机械取"前档"——8401 档 0.020 破线而 0.025 安全即反例）；**最终建议区间 = [0.012855, min(顶点, 失控点内安全档)] 分 8401/30k/50k/100k 四档给出**（0.012855 = 现行定案值，只作下界不下调）——叠加"错过成本"修正（见 C 节：8401 档最优比例应低于 30k+ 档）。

**蒙卡**：0.040 若成新最优 → 8401×0.040 × 10,000 场景 1 次（复用 r48 mc 子命令）。

### B. 收益提升归因（回应质疑 1）

新增 r48_grid.py `attr` 子命令，对 G01-G07（8401 档 7 档位）调 r44.run_one(return_raw=True) 拿 trades → join signals（code+date）取每股风险与 r_20d → 输出三表：

- **attr_pivot.csv**：id/ratio/n/sum_pnl/risk_invested/mean_risk/**U（单位风险收益 = Σpnl/Σrisk_actual，策略质量主口径）**/avgR/avgR_no_top5/ret_pct/dd_pct/peak_positions/avg_positions/资金不足计数
- **attr_decomp.csv**：相邻档 + 0.008→0.025 总分解——**精确恒等式** total_pnl(r2)/total_pnl(r1) = [U(r2)/U(r1)] × [n(r2)/n(r1)] × [mean_risk(r2)/mean_risk(r1)]；Δln 三因子贡献%（和 = 100%）
- **attr_buckets.csv**：档位 × 每股风险桶[0.5, 0.6721, 1.0, 1.5, 2.0, 2.5, 3.0] 成交集 avgR/胜率/亏损笔占比，对照信号层同桶（0.6721 = 8401×0.008 上限，桶边界对齐）

**口径声明**：归因对象 = 累计盈亏（线性可加，恒等式精确）；收益%含复利非线性不进入分解（报告标注观察值）；U 与 avgR 的差 = 仓位对齐效应（高档位大风险额笔的 R 更好 → U > avgR，如 0.025 档 1.057 vs 0.876）。

**持仓/资金约束维度（回应质疑 2）**：attr 表含 peak_positions/avg_positions/资金不足计数——"候选池种类 441→1,133 种 vs 资金不足 12→102 笔"双维度呈现（每笔金额大资金紧张时刻增多 vs 候选种类与累计成交翻倍）。

**结论格式**："总盈亏 7.4 倍 = 下注放大 ×2.22（~40%）+ 可买池解锁 ×2.32（~42%）+ 单位风险收益 ×1.44（~18%）；单位风险收益提升来自解锁 0.67~1.0 最优桶（触发集 avgR 1.032 vs 被锁死的 0.5~0.67 桶 0.770；执行以 attr_buckets 重算值为准）——不是复利幻觉也不是回测 bug，是资金约束逐步放开的可追踪机制"。

### C. 选择偏差检验（回应质疑 2/3）

**引擎 debug 被拒明细（v2 修订，交易部审核意见 1/2/3——集合差法作废）**：
- sim_capital.simulate_capital 加 `debug_rejects: bool = False` 参数（**默认 False 零行为变化**）——True 时逐笔记录被拒候选明细（code/date/risk_ps/拒因/risk_amt_at），返回 res["rejects"] 列表
- r44 run_one 加 `debug_rejects=False` 透传（默认零变化）；r48 attr 子命令 `--debug-rejects` 开启
- 精确捕获：资金不足错过集 = rejects 中拒因=="资金不足" 的行（G07 应 = 102 笔）；超限集 = 拒因含"每股风险"的行（G01 应 = 666 笔）
- 门禁：Σrejects 各类计数 == res["reasons"] 同类计数零差（引擎内部自洽对账）；n_exec == pivot

**跑量**：G01/G04/G07 带 debug_rejects（3 次）；可选 30k/100k 覆盖（G08/G25/G28，3 次）。

**输出 attr_subsets.csv**：每格成交集/超限拒集/资金不足错过集/新增子集 avgR+胜率 vs 触发集 0.882（ΔR）+ 每股风险分桶。

**错过成本量化（老板质疑 3 实证，v2 口径修正）**：每档"资金不足错过集"（debug rejects，G07=102 笔）avgR/胜率/分桶 + **错过损失估算**（Σ 错过集 avgR × 档位风险额 → 元；口径：每笔错过期望损失 ≈ avgR×risk_amt）——证明"资金固定→比例大→每笔金额大→同时持仓少→错过好股票"的真实成本；**分资金档最优比例 = f(错过成本, 每笔金额, 可买池)**。原"35 笔 avgR 1.632"载体作废（超限/资金不足混合），以 debug 精确集重算。

**蒙卡对比（3 次 simulate，秒级）**：MC(触发集 r_20d) vs MC(E(0.008) 成交 R) vs MC(E(0.025) 成交 R)：盈利概率/破产率/回撤分位/最大连败 → 选择偏差方向。

**预期结论方向**（已实测，执行时复验）：
- "正好买的都是输的"不成立：0.008 的 -0.10R 是每股风险上限把最优桶挡在门外的确定性机制（可逐笔复现）；0.025 成交集 0.908 反超全池
- 蒙卡基于成交集重抽样 = 受限实盘的同分布采样（对受限实盘无偏）；**两档偏差方向相反（v2 修正，审核意见 7）：0.008 低估 0.10R、0.025 高估 0.03R**（0.025 成交集 0.908 > 触发集 0.882，约束筛选反提升成交质量）——蒙卡结论必须分档标注偏差方向，100% 盈利率解读带"受限成交集"前缀
- **老板质疑修正（v2：载体待 debug 重算）**：资金不足错过集以 debug 精确集重算 avgR/分桶（原差集 35 笔混合体作废）→ 资金约束错过成本方向性结论保留（漏买/错过集 avgR > 成交集为已测方向），量级以 debug 数据定 → **8401 档最优比例应低于 30k+ 档**（错过成本随比例上升）

**覆盖率完整账目**：n_eligible（C23 候选）/成交/超限拒/资金不足拒/执行率 + 各拒因集 avgR——"漏买"从"几只"上升到"哪几只 + 质量如何"。
