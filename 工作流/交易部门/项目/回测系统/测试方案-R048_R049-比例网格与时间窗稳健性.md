## 一、背景与目的

现行策略 V3 资金配置：**单笔风险额 = 0.012855 × 当前资金（连续比例），持仓上限无限制**。本方案验证两个未验证点：

1. **R-048 比例系数敏感性**：0.012855 从未做过网格敏感性测试（历史仅 T-023 粗粒度 1.5%/2%/3%/5%×2/3/5仓@5600 元，及 R-045 单一阶梯点 0.00857）。需要：① 验证 0.012855 是否落在最优区间；② 验证最优比例是否随资金量漂移；③ 界定低资金下的可执行性下限（风险额不足以买入一手）。
2. **R-049 回测时间窗稳健性**：现行回测用 26 年（2001~2026）/近 7 年（2019~2026）/近 3 年（2023~2026）三口径，未系统验证"回测时间取值"。需要：① 起始点敏感性；② 滚动窗口时代漂移；③ 市场制度边界（科创板 2019-07、创业板 20% 涨跌停 2020-08）；④ 宏观周期标注。产出**回测时间取值规范建议**。

**结果用途**：数据支撑老板拍板"比例维持/调整"与"回测时间标准取值"。本方案只测不改，参数调整需老板书面同意后另行执行。

## 二、测试设计 A：R-048 比例网格

### A1 主网格（28 格：7 档 × 4 资金 × 26 年全量）

比例档（相对现行 0.012855）：

| 档 | 比例 | 8401 元风险额 | 说明 |
|---|---|---|---|
| r1 | 0.008 | 67.2 元 | 下探可执行性边界 |
| r2 | 0.00857 | 72.0 元 | R-045 B2 实测点对齐（30k~100k 已测） |
| r3 | 0.010 | 84.0 元 | 现行值下方最近点 |
| r4 | **0.012855** | 108.0 元 | 现行锚 |
| r5 | 0.016 | 134.4 元 | 现行值上方最近点 |
| r6 | 0.020 | 168.0 元 | T-023 2% 档对齐 |
| r7 | 0.025 | 210.0 元 | 上探敞口/回撤失控区 |

资金档：**8,401（实盘）/ 30,000 / 50,000 / 100,000**（16,000 不列入主矩阵——R-044/045 已有 16k×0.012855 单点作旁证）。

固定参数：信号集 `产出/输出/backtest_r43_t2/signals.csv`（S 级/dn_confirm=1.5/C23，4,351 笔，2000-05-17~2026-08-10）；`max_positions=999`（无限制）；`half_phase=True`（0.5R 分步）；无注入。
**排序口径（v2 修订，交易部审核意见 3）**：`same_day_order` 采用 r44.run_one 实际行为 **"time"**（simulate_capital 未传参的默认值）——网格必须与锚点/历史结论同口径可比。局限如实标注（复核意见 2）：**对账闭环（7 点）只证明 r44↔R-044/045 自洽，不探测 R-043 原始数字（+397.4%，0.0129 近似）的排序口径**——其与 time 复现值 391.0 的 6.4pp 差已由 0.35% 精度差解释，但 risk_mid 假设同样自洽；若后续需完全对齐 R-043 原始口径，须另查当时执行参数。r44 头注释声称"risk_mid 排序（simulate_capital 同参）"与代码不符（未透传），为既有注释缺陷；risk_mid 是实盘执行卡排序口径（T-032 定案），**回测/实盘排序差异单列观察项**，不在本方案改动范围内。

### A2 精化步（≤8 格，规则确定性；v2 修订明确规则）

对每资金档：若最优档（收益回撤比 argmax）非端点（非 r1/r7），且其左右相邻两档回撤均 >-20%，则在最优档与其左右相邻主档的**两个区间中各插 1 点**（1/3、2/3 处），每资金档最多 2 点；最优档为端点不精化；8,401 档最优即现行值（r4）时不精化、只做验证。

### A3 拐点时间窗验证（16~24 格）

每资金档取最优档 ± 相邻档（2~3 档）× {近 7 年（min_date=2019-01-01）, 近 3 年（min_date=2023-01-01）}。min_date 语义 = **信号日期过滤**（非资金起点），资金从全额起算、无注入、无前置复利。信号量：min_date=2019 → 2,961 笔；2023 → 2,244 笔。

### A4 注入补测（1 格）

8,401 档最优档 × 近 3 年 + 月注入 3,000 × risk_growth（37 个月）——对齐 R-045 注入版口径（8,401 起步 + 月注入 3,000 × 37 月 · 近 3 年 · risk_growth）。

### A5 指标与判定（v2 修订：意见 6/7/9）

- **主指标**：收益回撤比 = total_ret_pct / |dd_peak_pct|（正收益格可比）；dd_peak_pct 为总资产口径最大回撤（build_total_asset_curve：现金+持仓市值，qfq 估值）
- **否决线**：回撤 >-20% 的档位直接排除
- **辅助指标**：avgR（逐笔 pnl/实际 risk_actual）/ avg_r_no_top5（**分母 = capital×risk_ratio 固定口径，与 avgR 不可直接对比，报告分别标注**）/ n_exec / 资金不足计数与每股风险超限计数（reasons 提取；"资金不足"为固定键，"每股风险{值}超限(>{上限})"为**动态键名**，按前缀 "每股风险" 聚合）/ 敞口峰值 / max_streak / exec_rate / half_stats（n_half/n_confirm/n_reject——报告据此表述 0.5R 分步执行结构，**不称"可买率"**）
- **可行域（v2 修订）**：回撤 >-20% 且 n_exec ≥ max(该资金档网格中位 n_exec × 30%, **50 笔绝对下限**)
- **最优区间**：可行域内收益回撤比 ≥ 最大值×0.9 的连续档位段（Pareto 平坦区，不追单点噪音）
- **漂移判定（v2 修订）**：**基于 30k/50k/100k 三档**（8,401 档受可执行性约束会偏高档位，单独分析不参与漂移判定）；argmax 档位索引差 ≥1 个档距 → "最优档随资金漂移成立"；否则"现行值落入最优区间"
- **8,401 档可执行性边界**：低档位风险额 < 100 股×每股风险 → 大量"买不起"，n_exec 崩溃——这是**可执行性事实而非测试失败**，单列一节，结论按"可执行子集下的最优"表述
- **蒙卡（v2 修订，意见 5）**：候选档取舍 = 各资金档最优档去重并集（按被选次数排序），若 >2 个取 top2 + 现行基准；≤2 个则全取 + 现行基准（已在集内则取 top3）。实现：**r48 内嵌 mc 子命令**，复用 `分析决策/跟踪/monte_carlo.py` 的 `simulate()` 纯函数（FEE_PER_TRADE_R=0.0 与 R-043 同口径；numpy seed=2024 同源），**成交集 = r48 主网格同源成交（half_phase=True）**——不复用 monte_carlo_c23 的资金层（其无 half_phase 且默认 3 年旧信号源）。每候选档 10,000 场景。输出：盈利概率 / **破产率 = P(逐路径累计 R 曲线任意时点触及 -(初始资金/初始风险额)，从 simulate 返回 samples 逐路径累计新写统计)** / 终值与回撤 P5/P50/P95 / 连败分布

## 三、测试设计 B：R-049 时间窗稳健性

统一配置：8,401 × 0.012855 × 无限制（现行 V3），无注入。

### B1 起始点敏感性（6 格）

min_date ∈ {2000, 2005, 2010, 2015, 2019, 2023}（2000 = 全量，与 A 主网格现行档共用）。

**收敛判据**（自动标注）：
- 数值收敛：相邻起点 |Δ收益| ≤ 40pp 且 |Δ回撤| ≤ 3pp 且 |ΔavgR| ≤ 0.10
- 结论收敛（v2 修订）：回撤可行性判定（<20% 警示线）与 avgR > 0 判定在全部起始点不翻转
- 已知结构事实：**2002~2008 年信号为零**（2000=2、2001=2、2002-2008=0、2009=3、2010=15…）→ 2000/2005/2010 三起点信号差 <5 笔、结论必然等价——作为"早期信号稀疏、起点无信息量"结构发现呈现，非测试失效

### B2 滚动 3 年窗（v2 修订：信号数更正 + 截断方案）

固定 3 年窗（右开区间 [Y-01-01, Y+3-01-01)，末段到数据末 2026-08-10），信号按日期预过滤后跑。**跨窗截断问题与解决**（交易部审核意见 4）：simulate_capital 以 sub 内最后信号日为"数据末"，`exit_date ≥ 数据末` 的持仓按"持仓未完成(数据末尾)"剔除——预过滤后每窗末段约 3-6 周的信号会被系统性剔除。解决：**simulate_capital 加 `max_date=None` 可选参数**（None=现状行为零变化；传值=覆盖"数据末"判定），r44.run_one 透传（默认 None），r48 窗跑统一传真实数据末 2026-08-10——窗内持仓可跨窗出场，数据不截断。

| 窗 | 信号数（已实测） | 处理 |
|---|---|---|
| [2001, 2004) | 2 | 近空窗 → 不跑引擎，仅年度分布呈现（低置信） |
| [2004, 2007) | **0（空窗）** | **不跑引擎**（v2 修正：原稿 176 为 2014 年错位） |
| [2007, 2010) | 3 | 近空窗 → 不跑引擎，仅年度分布呈现（低置信） |
| [2010, 2013) | 142 | 跑（可用） |
| [2013, 2016) | 304 | 跑（可用） |
| [2016, 2019) | 937 | 跑（高密度） |
| [2019, 2022) | 562 | 跑（高密度） |
| [2022, 2026-08) | 2,399 | 跑（高密度） |
| 合并 [2004, 2010) | **3**（v2 修正） | 参考行（低置信，不占主表） |
| 合并 [2010, 2016) | 446 | 参考行 |
| 合并 [2016, 2022) | 1,499 | 参考行 |
| 合并 [2022, 2026-08) | 2,399 | 参考行 |

**时代漂移判据**：相邻可跑窗 |ΔavgR| > 0.15R 或胜率差 > 10pp → 标注"时代漂移段"，结合 B4 宏观标注归因（牛熊占比），不直接归因策略。

### B3 制度边界对比（2 格）

信号 ≤2019-12-31 vs ≥2020-01-01（各一跑；信号 1,509 vs 2,842 笔均充足）。精确制度日：科创板 2019-07-22（20% 自始）、创业板 2020-08-24（20%），2020-01-01 为近似分界。涨跌停放宽主要影响跳空与止损成交价 → 结论表述降级为"关联观察"而非因果。

### B4 宏观周期标注（1 项轻量统计，非回测格）

复用 market_regime.py（上证指数 MA20/60/120，无前视，信号日 T 只用 ≤T 数据）：对每个窗/起点段输出牛/熊/震荡交易日占比 + 该段信号层 avgR/胜率（直接统计 signals.csv，不跑引擎）。

### B5 产出：回测时间取值规范建议（老板拍板项）

由数据支撑的建议稿结构：① 信号层结论（信号质量/评级/条件类）→ 26 年全量主口径；② 资金层结论（资金利用/可执行性/回撤压力）→ 近 3 年主口径 + 近 7 年复验；③ 所有报告附信号年度分布 + 当期宏观周期标注；④（v2 修订）**早期制度差异（涨跌停 10% 时代）+ 2002-2008 空窗结构 → 起始点 <2015 仅作全量等价性旁证，参数级结论以 2015+ 起点为准**。

## 四、脚本与执行设计（v2 修订：改动清单更新）

### 脚本（新增 `项目/回测系统/r48_grid.py`，子命令 + 公共组件）

- `grid` / `timewindow`：生成矩阵 → manifest.csv（含每格参数快照：信号源/行数/capital/risk_ratio/max_positions/min_date/窗/max_date）
- `run-one --cell <id>`：单格执行器（batch 子进程入口）；`batch --manifest --workers 6 --out <dir>`：**每格独立 .json+.err 文件**（防并发写丢行）；`collect`：合并 jsonl + 枢轴表 + **selfcheck 门禁（任一格 selfcheck_pass=False → 标红停查，不静默剔除）**
- `anchor`：**7 点对账**，偏差 >1pp 停跑
- `mc`：蒙卡子命令（A5 设计，复用 monte_carlo.simulate 纯函数）
- 核心函数：`run_cell()` 调 `r44.run_one(..., return_raw=True, max_date=...)` → 从 `res["reasons"]` 提取"资金不足/每股风险*"计数（按前缀聚合）；`prefilter_signals()` 幂等预过滤（utf-8-sig，保持列序）；`window_regime_annotation()` 复用 market_regime

### 对既有文件的改动（最小化，全部需审核确认；v2 更新）

1. **r44_position_grid.py**：`run_one()` 加可选参数 `return_raw=False`（True 时返回 `(metrics, res)` 供 reasons 提取）与 `max_date=None`（透传给 simulate_capital）——**默认行为零变化**，R-044/045 复现不受影响

3. **monte_carlo_c23.py**：加 `--capital`（默认 5600，保 R-043 历史口径不变；`--max-positions` 参数已存在，无需新增）——仅支持独立运行候选档蒙卡，R048 蒙卡走 r48 mc 子命令
