# 突破日量能确认 · 回测对照实验报告（2026-08-06）

> 背景：老板质疑"光突破但力度小可以吗"——prebreak 预突破模式 5 条件评级不含 DN（动能），
> 突破发生在评级后，无法提前评动能；力度小的突破（无量/磨上去）假突破概率高？
> 拍板实验：prebreak 触发后检查突破日量比（触发日成交量 ÷ 触发日前 20 日均量，
> 口径对齐 DN 相对量比 `ref.tail(20).mean()`）> 阈值 X 才计入交易。

## 实验设计

| 项 | 口径 |
|---|---|
| 样本 | 400 只（duckdb 主库确定性抽样 seed=42，可复现） |
| 区间 | 2023-07-01 ~ 2026-07-31（3 年+，与 B1C3/C1 同口径） |
| 模式 | prebreak（预突破），评级 S（与 b1c3 同口径），hold 5/10/20，主口径 20d |
| 变量 | 仅 dn_confirm 阈值：对照组 0（纯价格触发）/ 1.5 / 2.0 / 2.5（B1/C3/C4/C1 闸门全关） |
| 量比 | 突破日成交量 ÷ 触发日前 20 日均量（不含触发日；前 20 根不足或均量为 0 → 不达标） |
| 实现 | 回测系统实验参数 `--dn-confirm`（默认 0 关，不改变现有行为） |

## 四、结论（数据说话）

### 1. 老板直觉：部分成立，但不完全对

- **成立的部分**：低量比突破的质量确实更差——被剔除集（量比≤1.5）胜率 41.3%、均R 0.345，明显低于全体触发的 43.8% / 0.553。**力度小 = 质量打折**。
- **不成立的部分**：被剔除集均R 为**正**（0.345~0.539），不是亏损源。**低量比突破不是"假突破"**（真假突破的判据是负收益），只是"平庸突破"——假突破直觉被数据证伪，弱化版成立。

### 2. 量能确认：非单调有效，X=1.5 是甜点

- **X=1.5 有效**：胜率 43.8%→48.0%（+4.2pt）、平均R 0.553→0.906（+64%）、盈亏比 2.14→3.00、最大回撤 17.7→13.7，全部 hold 一致最优。
- **X≥2.0 失效**：胜率/均R 随阈值提高而回落（2.0: 44.8%/0.753，2.5: 43.3%/0.622），不单调。原因可从组间差推算：
  - 量比 1.5~2.0 带（62 笔）均R ≈ 1.24，量比 2.0~2.5 带（44 笔）均R ≈ 1.02 ——**温和放量带（1.5~2.5）是质量最优带**；
  - 量比 >2.5（90 笔）均R 0.622 反而低于中间带——**巨量突破多为情绪化/一步到位（追高），质量回落**。
  - 结论：量能不是越多越好，存在最优量能带；"放量确认"有效，但过度放量反而差。

### 3. 代价：交易量大幅收缩

X=1.5 时 528→196 笔（**-63%**），被放弃的被剔除集 3 年累计 114.6R（正收益）是真实机会成本。基线累计R 292.2 高于任何 X 组（177.7/100.9/55.9）——**总收益口径下量能确认无益，交易频率本身就是收益**。

### 4. 阈值建议

| 用途 | 建议 | 理由 |
|---|---|---|
| 挂单指引/扫描过滤（单笔质量优先，小账户单持仓节奏） | **X=1.5（量比>1.5 才考虑挂单）** | 胜率/均R/盈亏比/回撤四项全优，质量提升 +64% |
| 总收益最大化（多持仓/量化批量） | 不接入（X=0 现状） | 基线累计R 最高，频率即收益 |
| 进一步探索（后续实验可选） | X=1.2（对齐 DN_A 1.2） | 保留更多交易同时过滤最差带，验证 1.5 是否过严 |

> 判定原则：**量能确认整体"有条件有效"**——X=1.5 质量提升明确（胜率+4.2pt、均R+64%、盈亏比 3.0），
> 但非单调（X≥2.0 回落），且以 -63% 交易量为代价；老板直觉弱化成立（力度小=质量差，非假突破）。
> 是否接入扫描/挂单指引、取哪个阈值：**签字权归老板**。参数默认关（0.0），未签字前不改变现有行为。
