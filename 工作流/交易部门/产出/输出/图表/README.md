# 📊 图表文件夹（老板直接查看 · 2026-08-07 建）

> **看这里**：所有测试/回测/蒙卡/实盘图表都存这个文件夹，打开即看。
> 命名规范固定，一眼知道每张图是什么、哪次测试产的。

## 目录结构

```
图表/
├── README.md                      ← 本说明
├── 图表-{主题}.png                ← 全景图（当前策略所有维度，dashboard 默认）
└── {YYYYMMDD}-{测试名}/           ← 专项测试图（每次测试/实验跑完自动归档）
    └── 图表-{图主题}.png
```

## 命名规范

| 位置 | 命名 | 例子 |
|---|---|---|
| 根目录 | `图表-{主题}.png` | `图表-回测资金曲线.png`、`图表-双线对照.png` |
| 测试子目录 | `{YYYYMMDD}-{测试名}/` | `20260807-全面测试/`、`20260808-量比验证/` |
| 子目录内图 | `图表-{主题}.png` | `图表-月度收益.png` |

## 生成方式

```bash
python main.py dashboard              # 全景图（回测+蒙卡+实盘）
python main.py dashboard --live-only  # 实盘图（已接入每日 19:05 扫描）
python main.py dashboard --subdir 20260807-全面测试   # 测试归档子目录
```

> 每日 19:05 扫描后实盘 3 图自动更新；回测全景图数据固定（3 年），有需要重跑。
