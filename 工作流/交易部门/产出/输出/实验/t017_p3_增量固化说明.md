## 三、增量实测结果（真实跑一次，worktree 副本）

- **范围**：全市场 5203 只 + 新股检测（发现 7 只 P2 失败股，通达信仍空表 → 永久标记跳过，不浪费重试）

- **耗时**：303 秒（5 分钟，8 线程；P2 全量 10.3 分钟）
- **校验**：重复行 daily=0 / xdxr=0；库最新日期 2026-08-05；尾部落后 >5 天 0 只
- **断点续传**：重跑仅待拉 7 只（done 全部跳过）；`--only-failed` 待拉 0
- **实测发现的修复**：mootdx 返回 datetime 既是索引又是列（pandas ambiguous）→ reset_index 规避（P2 靠 concat 隐式规避）；Windows 下 state.json os.replace 偶发被占用（防病毒）→ 3 次重试

## 四、除权校验全库扫描结果

- **全库 5203 只扫描完成**：规则 A 1752 条 + 规则 B 7620 条 = 9372 条待核（涉及 1713 只），输出 CSV 待核清单 + json 摘要
- 规则 A（送转缺除权除息）：**300093 金刚光伏 2025-11-20 精确命中**（P2 报告个案闭环）；600519 等正常股 0 假阳性（category=5 定期股本快照已排除）
- 规则 B（超涨跌停上限无记录）：P2 建议的 5% 阈值实测全库假阳性爆炸（涨停板全命中，每只数十~数百条），已改为"超过板块涨跌停上限（主板 10.5%/创业科创 20.5%）"判定，语义正确（大比例除权漏记，如 10 送 10 = -50%）

- 输出：`数据基础/data/duckdb_runtime/xdxr_check_<日期>.csv` 待核清单 + json 摘要
