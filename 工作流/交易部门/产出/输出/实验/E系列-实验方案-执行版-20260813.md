## E1 · 平台宽度质量判定

**目标**：验证"平台越窄越强"（老师原话）——TY 区间宽度是否与突破质量正相关；若成立，评估并入 C23。

**实验**：
- A 宽度网格：TY 区间振幅分档 <3% / 3-5% / 5-8% / >8%（与 TY_RANGE 阈值同构）→ 各档 avgR/胜率/触发率（26y+7y）；**分评级×分宽度交叉表**（同评级内比宽度，防评级混淆）；邻域检查（相邻档差 <0.05R）
- B 二维交叉：宽度档 × 触发质量 + 错杀/冗余分解（过滤掉了哪些本可进场的票）
- C 资金层复验：三档网格 × T-020 双口径；先锚点零差再开网格

**判据**：① 宽度与 avgR 单调正相关（Spearman p<0.05 或相邻档差 >0.05R）② 资金层卡玛提升或回撤显著改善且收益降幅 ≤20% ③ 与老师案例库判定一致性 ≥ 阈值（形态库 13 案例校准）

**产出**：通过 → 建议并入 C23（需老板拍板）；不通过 → 记录放弃

## E2 · 突破后二次买点（替代进场语义）

**目标**：突破日追不进（一字板/秒板）的替代入场路径——回踩确认后再进。

**语义定案**：替代进场为主（首进未成交 → 等回踩二买替代，不增加信号数）；加仓语义为独立子问题，与 0.5R 分步补仓对照（防重复测 0.5R）。

**实验**：
- A 回踩低点模拟：触发后回踩 ≤ 平台下沿/MA20 再进；回踩破位 → 放弃（放弃集单独报告：破位后 20 天 avgR——大跌=判据有效，仍涨=假破位需返工）
- B 首进 vs 二买对照：avgR/胜率/回撤 + 样本量披露；**分两子集**：G10 一字板放弃单 vs 其余触发单（追高吃亏路径）
- C 资金层复验：二买组独立资金模拟（三档网格）+ 加仓子问题同仓并发拥挤检查
- 回踩参数（窗口/幅度/进场价）±1 档邻域检查

**判据**（全部满足）：① bootstrap 区间不重叠 ② 效应量 ≥0.2R ③ 可执行率（追不进样本中等来二买的比例）合理 ④ 胜率提升 ≥+5pp

**产出**：通过 → 执行卡"二次买点"指引（预评估改动面后实施）；不通过 → 记录放弃

## E4 · 平台突破 vs 阻力突破语义校验

**目标**：000597 案例（评级 S 但未过上阻力位）暴露的语义错位——评级"突破"是否漏了阻力维度。

**实验**：
- A 分型对照：prebreak 触发集分型（平台内突破 vs 过阻力突破——前高 120/250 日双口径、密集成交区 = 成交量占比 ≥60% 价位带或 wvma ±3%）→ 两型 avgR/胜率对照（26y+7y）
- B 000597 评级归因：先分析 S 级构成（3-4 个 S + PT/DL 必须 S）——问题是评级构成还是缺阻力维度，先归因后决定加什么

**判据**（双向）：阻力突破质量显著更高（bootstrap 不重叠 + 效应量 ≥0.2R）→ 评级加阻力校验（改策略参数，老板拍板）；不显著 → 结论 = 个案语义错位，做评级归因修正（不做全局校验）
