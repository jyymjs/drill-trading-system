## 三、四项实验设计（v2 修订版）

### E1 · 平台宽度质量判定（对齐 T-7 + 老师"平台越窄越强"原话）

- **对齐项修正（审核 E-R3）**：T-6（触点/影线）归位到 E2/E3 上下文；E1 对齐
  **T-7 宽度近似**（宽度/内部结构指标）
- **A 宽度网格（信号层主判据）**：TY 区间振幅分档 **<3% / 3-5% / 5-8% / >8%**
  （定案分档，与 TY_RANGE_S/A/B=3%/5%/8% 同构，zuanqian_strategy:88-90）；
  输出**分评级×分宽度交叉表**（同评级内比宽度，防评级混淆，E-R4）；
  **A1.5 邻域稳健性**（相邻档 avgR 差 <0.05R + 样本量下限标注）
- **B 二维交叉**：宽度档 × 触发质量 + 错杀/冗余分解（R-069 B2 结构）；
  预置检查：**宽度过滤在触发集上的增量作用**（保留/剔除集质量对照——
  防"动量过滤触发集零作用"重演，R-069 结论②）
- **C 资金层复验**：三档网格双口径（含/不含 T-020）；先 r48 锚点零差再开网格
  （E-V5）
- **判据（审核 E-R6）**：① 宽度与 avgR 单调正相关——Spearman ρ p<0.05 或
  相邻档差 >0.05R；② 资金层三指标（收益/回撤/**卡玛**）——采纳标准 = 卡玛提升
  或回撤显著改善且收益降幅 ≤20%，全指标披露、给区间建议
- **外部校准（审核 E-A5）**：宽度档判定 vs 老师案例判定一致性 ≥ 阈值
  （T-7 校准基准=会员 25-28 课形态库 13 案例；具体阈值实验内定并披露）

### E2 · 突破后二次买点（语义定案：替代进场为主）

- **语义定案（审核 E-R1，P0）**：老板诉求"追不进的人怎么补" = **替代进场语义**
  为主实验（首进追不进 → 等回踩二买替代成交，不增加信号数）；**加仓语义**列为
  独立子问题，显式与现行 0.5R 分步补仓（half_phase 恒开启）对照——重叠/叠加/
  替代三态，防重复测 0.5R
- **信号源（审核 E-A6）**：prebreak 触发集，分两子集报告——G10 放弃单
  （一字板追不进，复用 tracking._is_one_line_blocked）vs 其余触发单
  （追高吃亏路径）
- **A 回踩低点模拟**：触发后回踩 ≤ 平台下沿/MA20 再进；失败路径固定
  （回踩破位 → 放弃）；**放弃集对照（审核 E-A2）**：放弃集触发后 20 天
  avgR/胜率单独报告（破位后大跌=判据有效；仍涨=假破位，判据返工）
- **B 首进 vs 二买对照**：avgR/胜率/回撤（R 单位，复用 stats._max_drawdown_from_r）
  + 样本量披露
- **C 资金层复验**：二买组独立资金模拟（三档网格）+ 加仓子问题同仓并发拥挤检查
- **判据（审核 E-R2，P0）**：① bootstrap 95% 置信区间不重叠 ② 效应量 ≥ 0.2R
  ③ **可执行率维度**（追不进样本中等来二买的比例——二买价值 = 替代成交
  avgR × 可执行率，非孤立 avgR）④ 胜率提升 ≥ +5pp
- **回踩参数邻域检查（审核 E-V3）**：回踩窗口/幅度阈值/进场价 ±1 档
  （相邻档 avgR 差 <0.05R 视为稳定，T-024 教训）

### E4 · 平台突破 vs 阻力突破语义校验

- **操作化（审核 E-R7）**：①"前高"= 120/250 日双口径报告；②"密集成交区"=
  区间成交量占比 ≥60% 价位带 或 wvma 量加权价位 ±3%（indicators.py:738 现成）；
  ③ 分型统计**限定 prebreak 触发集**（只有触发集有 r_20d 质量列）；④ normal
  无突破语义，不纳入
- **A 分型对照**：平台内突破 vs 过阻力突破质量对照（avgR/胜率，26y+7y）
- **B 案例回放 + 评级归因（审核 E-R8）**：先做 000597 的 **S 级构成归因**
  （S 级规则：3-4 个 S + PT 必须 S + TY≠S + SF≠S + DL 必须 S）——问题可能是
  评级构成而非缺阻力维度，先归因后决定加什么
- **判据（双向，铁律 5）**：阻力突破质量**显著更高**（bootstrap 不重叠 +
  效应量 ≥0.2R）→ 评级加阻力校验（改策略参数，老板拍板）；**不显著更高** →
  结论 = 000597 属评级语义错位个案，方案 = 评级归因修正（不做全局校验）
