## 三、实验设计

### 实验 A：C23 参数网格（T8 最新数据）（v2：审核 P2-8 稳健性）
- A1 信号层网格（主判据）：动量 [5%, 8%, 10%, 12%, 15%, 不限] × 止损区间 [0.3-3.0, 0.5-3.0, 0.7-3.0, 0.5-2.5, 0.5-不限] = **30 格**（每格：触发量/avgR/胜率/累计 R；26y + 7y）
- **A1.5 邻域稳健性（审核 P2-8）**：最优格须通过邻域检查（相邻格 avgR 差 < 0.05R 视为稳定；样本量下限标注）——防噪声尖峰当选（T-024 教训：闸门交互致单条件结论不稳）
- A2 资金层复验（10 万无约束 7y，**收益+回撤双指标**——审核 P2-9）：现行格 vs 信号层 Top3 格 vs 不设限
- 输出：最优参数 + 与 P2-1 结论对比
- ⚠️ C23 落地需老板书面同意（CLAUDE.md 规则）——实验先行

### 实验 B：放量过滤（T-020）全面测试（v2 修订：审核 P1-3/P1-4）
- **B1 信号日量比新复算**（⚠️ 审核 P1-3 实测确认：T8 enriched.vol_ratio 是**触发日**口径，与信号日量比显著不同——直接复用会把 T-020 测成 dn_confirm 重复实验。必须新复算：信号日索引 t，vol[t]/mean(vol[max(0,t-20):t])，与 scanner.py:160-167 同式）
- **B2 全候选集二维交叉**（⚠️ 审核 P1-4：信号源 = T8 全候选 4355 行（含 triggered_20d=0 的 3206 行），复用 r53_vol_dist 全候选回放框架）：
  - 交叉表：信号日量比档（≤1.0/1.0-1.2/1.2-1.5/1.5-2.0/2.0-3.0/>3.0）× 触发日量比达标率（dn_confirm 视角）× 质量（r_20d）
  - **错杀分解**（信号日≤1.5 但触发日放量且 20d 内触发 = 本可进场的错杀）vs **冗余分解**（信号日≤1.5 且触发日也不放量/未触发 = 挂单也进不了场）——核心产出：T-020 挡掉的票里有多少是真错杀、质量如何
- **B3 阈值扫描（信号层主判据，样本集合注明——审核 P2-14）**：在**全候选集**（4355 行）上输出每档 X ∈ [1.0, 1.2, 1.5, 2.0, 不限] 的保留笔数/触发笔数/质量（avgR/胜率）——与 B2 交叉表互补（B2 负责错杀/冗余分解，B3 负责阈值档位选择）
- B4 资金层复验（10 万无约束 7y，收益+回撤双指标）：T-020 保留 vs 不设限
- 输出：T-020 保留/放宽/取消的数据结论（错杀 vs 冗余量化）

### 实验 C：0.5R 补仓确认时点（v2 修订：审核 P0-1/P1-2/P1-5/P1-6）
- **T0 变体条件集固定（审核 P0-1）**：T0 收盘确认 = **{A, B, C3@T0}**——A 收盘站稳（T0 收盘≥触发价，与现行 R-053 A 同式）、B 量比>1.5（T0 触发日口径，分母=触发日前 20 日均量）、C3@T0 非放量阴线（T0 收阴且量比>1.5 拒绝，MA5 口径 indicators.py:1132-1141）——**注明：C1 与 A 冗余、C2@T0 恒真（开仓日=判定日）、无 delay2 二次机会**——不是"仅时点提前"，是条件集 {A,B,C3@T0}
- **T0 变体失败路径（审核 P1-13）**：A/B/C3@T0 任一不满足 → **0.5R 以 T0 收盘价平仓**（与现行 exit_reject 同构，判定日从 T+1/T+2 提前到 T0；无 delay2 顺延）
- **A/B 统一注入（审核 P1-2 信号层 + P1-12 资金层）**：V0 与 T0 变体**都注入 R-053 A/B**（A/B 恒绑定触发日，T0 收盘即可计算）——信号层与资金层（C1/C2）一致，比较变量只有"确认时点"；资金层 A/B 注入为**实验侧包装**（生产 sim_capital 不动，报告注明与实盘现行含 A/B 的一致性）；另保留无 A/B 版 V0 仅供 T8 引擎对账门禁（T8 r_20d 无 A）
- **补仓成交价口径固定（审核 P1-5）**：V0 补仓价 = 确认日收盘（现状 sim_trading.py:305）；**T0 变体补仓价 = T+1 开盘价**（实盘可执行：次日开盘市价补）——报告注明与实盘执行一致性
- C1 信号层变体矩阵（r52_phase_compare 加变体）：
  - V0：A/B + delay2（T+1 收盘确认 + T+2 顺延）＝现状语义
  - **T0：A/B + {A,B,C3@T0}（T0 收盘确认 → T+1 开盘补仓）＝老板方案**
  - V4：A/B + 严格首根（T+1 无 delay2）＝历史对照
  - 指标：确认通过率/avgR/累计 R/回撤（R 单位）/补仓时点分布
  - **增量集归因（审核 P2-7）**：T0 确认 ∩ V0 拒绝的增量集单独质量 + 假确认诊断（T0 确认后 **T+1 收盘 < 触发价 = 假确认**（操作化定义，审核 P2-15）占比/avgR）——"早一天补仓 vs 假确认"的核心证据；补仓后四层面出场止损兜底在报告显式交代
- C2 资金层复验（10 万无约束 7y，收益+回撤双指标）：confirm_fn 注入 T0 vs delay2
- 输出：确认时点提前的价值（早一天补仓 vs 少等一根 K 线）
