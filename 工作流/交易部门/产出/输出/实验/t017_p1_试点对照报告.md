## 一、结论速览（给老板的白话版）

1. **mootdx 全量拉取可行且快**：20 只全部成功，单只 0.3~1.1 秒（平均 0.7 秒），含 1991 年至今全部历史。全市场 5400 只估算 **1~1.5 小时**，睡前挂机即可（比估工的 2-3 小时还乐观）。
2. **duckdb 落库可用**：日K表 + 除权因子表两个表，110,446 条，查询毫秒级。
3. **复权对照（关键结论）**：
   - 自算前复权（用 mootdx 的 xdxr 除权因子）与**新浪源 qfq 在 2006 年至今区段高度一致**（20 只中 15 只误差中位 <0.08%，9 只 <0.02%）——**回测主力区段可信**；
   - **2006 年以前早期数据有 0.1%~4% 系统偏差**，原因是通达信与新浪对除权日当天的处理口径不同（通达信式保持真实涨跌幅、新浪式除权日价格连续），以及 2006 年股改除权（如茅台）的基准差异；
   - **意外发现：akshare 默认的东方财富 qfq 接口存在大面积坏数据**（20 只中约 40% 的天数是负价/异常小值，600809 山西汾酒 68% 的天数坏掉），**不能用作数据源或对照基准**，建议 P2 屏蔽东财接口；
   - **自算（通达信式）在除权日当天的涨跌幅是正确的**（真实涨跌幅），新浪式在除权日当天扭曲涨跌幅（实测茅台 2002-07-25 真实 -11.2%，新浪 qfq 显示仅 -0.7%）——对基于涨跌幅的策略，**自算复权比新浪 qfq 更正确**。
4. **与现有 3 年缓存的关系**：现有缓存 `交易部门/数据基础/data/cache/`（5205 只、454MB、2023-04 至今、未复权原始价）可直接作为 duckdb 仓库的**导入起点**，全量后替换。
5. **P2 全量建议**：可以放开，建议单服务器 + 失败重试 + 断点续拉，全市场约 1-1.5 小时 + 每日增量几分钟。

## 三、duckdb 落库（最小 schema）

临时库：`%TEMP%/t017_p1/t017_p1.duckdb`（试点临时目录，不入库）。已验证可查询、毫秒级响应。

```sql
CREATE TABLE daily (
    symbol VARCHAR, date DATE,
    open DOUBLE, high DOUBLE, low DOUBLE, close DOUBLE,
    vol DOUBLE, amount DOUBLE,
    PRIMARY KEY (symbol, date));          -- 110,446 行，20 只

CREATE TABLE xdxr (
    symbol VARCHAR, date DATE, category INT, name VARCHAR,
    fenhong DOUBLE, peigujia DOUBLE, songzhuangu DOUBLE,
    peigu DOUBLE, suogu DOUBLE, fenshu DOUBLE, xingquanjia DOUBLE,
    PRIMARY KEY (symbol, date, category)); -- 1,471 行
```

- **daily**：日K原始价（未复权，与现有缓存同口径）；category 含义：1=除权除息（复权唯一使用）、5=股本变化、其余=送配/增发/权证上市等（不影响价格）。
- **xdxr 单位**：fenhong/songzhuangu/peigu 为**每 10 股**（如 fenhong=3.60 即每10股派3.6元），peigujia 为每股配股价；复权计算时换算为每股（÷10）。
- 全市场 5400 只估算体积：日K约 3000 万行 ≈ **350-500MB**（duckdb 压缩后），远小于同规模 CSV（约 4GB）。
- **性能**：单股全量查询 1ms 级；P2 建议对 (symbol, date) 建主键后无需额外索引。

## 四、复权对照（核心实验）

### 4.1 方法与基准

- **自算**：xdxr 原始因子 → 等比复权因子链（用除权前一日收盘价；因子乘在除权日之前的 K 线上，除权日当天保持真实涨跌幅）。单位：每股分红 d=fenhong/10、送转 s=songzhuangu/10、配股 r=peigu/10、配股价 p=peigujia；因子 f=(P_pre−d+pr)/(P_pre×(1+s+r))。
- **对照基准**：新浪源 qfq（`ak.stock_zh_a_daily(adjust="qfq")`）为主基准；东财 qfq（`ak.stock_zh_a_hist(adjust="qfq")`）因坏数据仅统计不参与误差。
- **分段**：2006-01-01 前（早期，含 1990s 送配与 2005-2006 股改）与 2006 年后（晚期，回测主力区段）。

### 4.2 误差分布（自算 vs 新浪 qfq，收盘价误差百分比）

**晚期（2006-01-01 之后，回测主要用区段）——20 只误差中位数：**

| 区间 | 股票 |
|---|---|
| <0.02% （极优） | 600519(0.005%)、000858(0.006%)、000568(0.005%)、600809(0.008%)、002594(0.007%)、002415(0.017%)、601012(0.016%)、600887(0.017%)、600036(0.015%) |
| 0.02%~0.08% （优） | 000001(0.033%)、600000(0.04%)、601899(0.046%)、601398(0.079%)、000002(0.077%)、300059(0.031%) |
| 0.08%~0.4% （良） | 600900(0.153%)、601318(0.222%)*、000333(0.362%)*、300750(0.377%)* |
| 0.95% （需查） | 000651 格力（恒定差，见 4.4） |

**早期（2006 年以前）——差异显著放大：**

| 股票 | 早期中位误差 | 说明 |
|---|---|---|
| 600519 茅台 | 4.07% | 2002-2005 四次送转后累计差；2006 年股改除权后归零 |

### 4.3 高除权股细节（对照实验的重点发现）

1. **茅台（600519）——2006 股改除权基准差异**：2002-2005 年四次"送转+分红"（10送1派6、10送1派2、10送3派3、10送2派5）后，自算与新浪累计差 4.07% 且**恒定**（非累积增长）——即新浪对这四条记录有一条因子口径不同；2006-05-19 股改除权（10送10派3，停牌 5 天）后差异**归零**。进一步验证：2002-07-25 除权日当天真实涨跌幅 -11.2%，新浪 qfq 仅显示 -0.7%——**新浪在除权日当天扭曲了涨跌幅（分段复权），通达信式（自算）保持真实涨跌幅**。对涨跌幅敏感的策略，自算更正确。
2. **格力（000651）——1996/1998 两次 10送10 口径差异**：新浪隐含因子比理论值小约 2%（10送10 应按 0.5 因子，新浪按 ≈0.51）；2015 年及以后除权日（含 2015-07-03 的 10送10派30）两边完全一致——差异集中在 1990s 早期送转记录。且全期恒定 0.95% 差，提示某条 1990s 记录（如 1996-12-30 上市次月 10送10，与新浪基准价口径不同）存在口径差。
3. **比亚迪（002594）——2011 年后上市无早期记录**：全期中位误差 0.007%、>0.1% 仅 3 天，**证明算法本身在数据完整、无早期历史时与新浪完全一致**（2006 年后新上市公司误差最小）。
4. **配股股**（招行 2010 配1.3@8.85、2013 配1.74@9.29，格力 1998 配3@22、2000 配3@14）：含配股的除权日单日隐含因子与理论参考价公式吻合（误差 <0.2%），配股公式验证通过。

### 4.4 东财 qfq 坏数据（意外发现）

| 项目 | 数值 |
|---|---|
| 20 只东财数据点合计 | 110,488 天 |
| **坏值天数（收盘≤0.01 或负价）** | **43,947 天（约 40%）** |
| 最严重 | 600809 山西汾酒 5,372/7,857（68%）、000651 格力 4,510/6,981（65%）、600568 泸州老窖 4,470/7,708（58%） |
| 无坏值 | 002594 比亚迪（1 天） |

- 坏值形态：负价（-13 元）、0.02 元等荒谬值成片出现（如招行 2015-01 全周坏、2002 年上市初期全坏）；重拉验证**稳定复现**，非限流偶发。
- **结论：东财 qfq 接口（akshare 默认）历史区段不可靠，不能作为数据源或对照基准；全量方案应屏蔽该接口**，对照与回测基准用"mootdx 自算 + 新浪源"双源互验。

### 4.5 对照结论（对应验收标准 3）

1. ✅ 20 只全量数据拉取成功（最早日期/条数见第二节）；
2. ✅ duckdb 落库可查询（见第三节）；
3. ✅ 复权对照完成：**2006 年后 15/20 只误差中位 <0.08%，9/20 只 <0.02%**；早期 0.1%~4%；差异来源已定位（除权日口径差异 + 股改基准 + 1990s 记录口径）；
4. ✅ 自算复权（通达信式）在除权日保持真实涨跌幅，**优于新浪分段式**——回测系统若用自算复权，除权日涨跌幅正确；
5. ⚠️ 2006 年以前数据存在 0.1%~4% 系统差——**回测区间若涉及 2006 年前，需标注风险**；现有回测（2023 起）不受影响。

## 五、与现有 3 年缓存的关系（迁移路径）

- **现有缓存**：`交易部门/数据基础/data/cache/`（5205 只 × 454MB CSV，2023-04-17 ~ 2026-08-04，约 3 年，**未复权原始价**，列含 日期/开盘/收盘/最高/最低/成交量/成交额/涨跌幅/涨跌额/振幅/换手率）；另有 `数据基础/数据/cache/`（5232 只，456MB）疑似旧副本。
- **关系**：
  1. 现有缓存 = mootdx 全量的**子集**（同口径原始价）；mootdx 拉全量后可完全替代，无需保留双份；
  2. **导入起点**：现有缓存 5205 只 CSV 可直接灌入 duckdb daily 表作为"增量起点"，P2 只对缺失/过期部分补拉，节省约 1 小时（5400 只全拉也就 1-1.5 小时，补拉收益有限，**建议直接全量重拉更省事**）；
  3. **增量更新**：每日盘后 mootdx 增量（当日 K 线）入库，分钟级完成，替代现在"逐只补 CSV"的更新器。
- 现有代码**本次试点零改动**；试点代码在临时目录（`%TEMP%/t017_p1/`），未入库。

## 七、试点遗留问题（待 P2 或后续处理）

1. **000651 格力全期恒定 0.95% 差**：疑似 1996-12-30 上市次月 10送10 的记录与新浪基准口径不同（新浪隐含因子 1.96 vs 理论 2.0）；P2 需查该记录真实来源（通达信 vs 交易所公告）。
2. **mootdx 与新浪/东财日期条数差异**（如 000001：mootdx 8425 vs 东财 8451）：通达信服务器个别日期缺失（多为新股上市初期/停牌日归属差异），P2 需统计缺失分布，必要时用新浪补齐。
3. **股改除权（2006 年）**：通达信 xdxr 把股改对价记入 songzhuangu（如茅台 10送10派3），因子公式自动兼容；但"送认沽权证"等 category 14 记录未参与复权——**对价含权证的股票（茅台/万科等）早期复权可能仍有残差**，建议 P2 抽样验证。
