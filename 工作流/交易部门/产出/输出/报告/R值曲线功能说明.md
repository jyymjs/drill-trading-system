# R 值曲线功能说明

> 2026-08-06 老板拍板（需求澄清：资金曲线 → **R 值曲线**）

## 一、为什么是 R 值曲线（背景）

原需求是"实盘资金曲线"（每日净值跟踪）。老板澄清：**账户有外部资金注入，资金曲线会被注入干扰**；改为 **R 值曲线**——每笔盈亏 ÷ 单笔风险，**只反映策略本身**，不依赖账户余额。

- 与老师 24 节"盈亏比数列法"、回测 stats.py 的 **1R 等权口径**同构
- 资金曲线辅助版已取消，记入待办（等实盘转正时再做，含注入登记 + 修正收益率）

## 二、核心口径

| 项 | 口径 |
|---|---|
| R 值 | R = 单笔盈亏 ÷ 单笔风险。做多：R = (出场价 − 入场价) ÷ (入场价 − 止损价)，**止损平仓 R = −1** |
| 曲线 | **累计 R 曲线**（1R 等权，每笔交易记 1 次 R，逐笔累加） |
| 胜 | R > 0 |
| 平均 R | 累计 R ÷ 笔数 |
| 盈亏比 | 平均盈R ÷ 平均亏R（全胜未定义 → 显示 ∞） |
| 最大回撤 | 累计 R 曲线峰值回撤 max(peak − cum)，**全亏光也只到峰值**（组合口径，不做仓位资金曲线） |
| 连亏 | R ≤ 0 连续段数（最大连亏 + 当前连亏） |

回撤/胜率口径与 `项目/回测系统/stats.py` 完全同构（单测有对拍断言），保证实盘统计与回测结论可直接对比。

## 三、用法

入口（二选一，效果相同）：

```bash
cd 交易部门
python -m 分析决策.跟踪.r_curve <子命令> ...     # 模块直调
python main.py rcurve <子命令> ...               # 部门总入口
```

| 子命令 | 说明 |
|---|---|
| `record <日期> <入场价> <止损价> <出场价> [--symbol 代码] [--note 备注]` | 录入价格三件套，**自动算 R**（默认做多，`--short` 做空） |
| `record-r <日期> <R值> [--symbol] [--note]` | **直接录入 R 值**（最省事，亏损单约 −1；低于 −1.5 会提示确认） |
| `list` | 查看全部记录（含累计 R） |
| `stats [--plot]` | 统计报告（胜率/平均R/盈亏比/回撤/连亏），`--plot` 同时生成图表 |
| `plot` | 仅生成累计 R 曲线图 |
| `delete <id>` | 按 id 删除一条（录错纠错用） |

示例：

```bash
# 录入：入 10.00 / 止损 9.50 / 出场 10.75 → R = +1.5（自动算）
python main.py rcurve record 2026-08-03 10.00 9.50 10.75 --symbol 600419
# 直接录 R（止损单）
python main.py rcurve record-r 2026-08-04 -1.0 --note 止损
# 查看统计 + 图表
python main.py rcurve stats --plot
```

## 四、数据来源与存储

- 账本：`分析决策/交易日志/r_curve.csv`（列：id / date / r / entry / stop / exit / symbol / note）
- **同日允许多笔**（id 区分），读取按日期升序（同日按 id），累计曲线不依赖录入顺序、可复现
- 与 `journal/trade_journal.csv` 的关系：trade_journal 是**完整交易账本**（13 列，走 `main.py track` 命令，纪律报告会读它）；r_curve.csv 是**轻量 R 跟踪通道**（过程监控用，录入最省事）。两条通道并存，不做自动同步——完整交易的 R 值可事后用 record-r 补录进曲线
- 图表输出：`分析决策/图表输出/r_curve.png`（深色风格，与蒙特卡洛/资金曲线图一致：累计 R 曲线 + R 回撤子图）

## 五、与日常流程的衔接

- **复盘时**：`python main.py rcurve stats` 附带一段文本报告（可贴入复盘记录）
- **扫描报告后**：如需附带，将 `stats` 输出片段追加进当日扫描报告即可（独立 CLI，无侵入）
- **纪律联动**：报告含"当前连亏 ≥3 笔 ⚠️"提示，与 trade_guardian 纪律报告的连败警示互补
