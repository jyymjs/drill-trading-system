## 四、结论（数据驱动草稿，最终签字权归老板）

- **收益最优**：3.0%×3仓（风险 3.0% × 持仓 3）→ 终值 10,705 元 （+91.2%），回撤 124.6%，胜率 47.2%，avgR 0.541，89 笔。
- **回撤最小**：1.5%×2仓（33.9%，回撤时长 419 天）。
- 持仓 2：风险 1.5%→5.0%：成交均价 14.78→18.43 元（+3.65），收益 +54.5%→+58.4%（+4.0pp），未成交 avgR +1.002→+1.034（+0.032）→ **池改善且收益提升**
- 持仓 3：风险 1.5%→5.0%：成交均价 14.49→16.86 元（+2.37），收益 +69.2%→+54.2%（-15.0pp），未成交 avgR +1.033→+1.073（+0.040）→ 池改善但收益未同步提升
- 持仓 5：风险 1.5%→5.0%：成交均价 14.00→16.86 元（+2.86），收益 +74.1%→+54.2%（-19.9pp），未成交 avgR +1.099→+1.073（-0.026）→ 池改善但收益未同步提升
- 风险 1.5%：持仓 2→5：收益 +54.5%→+74.1%（+19.6pp），回撤 33.9%→107.4%，笔数 61→122
- 风险 2.0%：持仓 2→5：收益 +47.6%→+82.2%（+34.6pp），回撤 48.9%→137.2%，笔数 68→131
- 风险 3.0%：持仓 2→5：收益 +68.7%→+88.9%（+20.2pp），回撤 80.7%→163.4%，笔数 69→105
- 风险 5.0%：持仓 2→5：收益 +58.4%→+54.2%（-4.3pp），回撤 120.3%→132.3%，笔数 61→73

> **当前 5600 元最优配置与资金增长后的配置变化建议**：由分析正文人工复核（自动草稿只出数据）。判据：单笔风险额 = 初始资金 × 风险%，资金翻倍后同样风险%可买翻倍价格区间的股票 → 池整体右移，需重新评估是否下调风险%或扩持仓数。

## 五、C23 vs V1 网格对照（结论草稿）

- **C23 版收益最优**：3.0%×3仓（风险 3.0% × 持仓 3）→ 终值 10,705 元（+91.2%），回撤 124.6%，胜率 47.2%，avgR 0.541，89 笔。
- **vs V1 网格最优（1.5%×5仓）**：收益 +25.5% → +91.2%（+65.7pp），终值 7,026 → 10,705 元，胜率 40.0% → 47.2%，avgR 0.227 → 0.541，回撤 103.9% → 124.6%，笔数 180 → 89。

- **持仓数边际（V1 关键变量）**：C23 下持仓 2→5 风险1.5%：+54.5→+74.1%（+19.6pp） / 风险2.0%：+47.6→+82.2%（+34.6pp） / 风险3.0%：+68.7→+88.9%（+20.2pp） / 风险5.0%：+58.4→+54.2%（-4.3pp）——3/4 档风险方向为正 → **「持仓数关键」规律保持**。
- **风险%边际（V1 认为无效变量）**：C23 下 1.5%→5% 持仓2：+54.5→+58.4%（+4.0pp） / 持仓3：+69.2→+54.2%（-15.0pp） / 持仓5：+74.1→+54.2%（-19.9pp） → **「风险%无效」规律被改变**。

- **资金约束退化提示**：5.0%×5仓≡×3仓（73 笔） 成交集完全一致——风险%放大 → 每股风险上限抬高，C23 池右移（成交均价 14~18 元）后5600 元资金实际最多同时持 3 只，5 仓配置退化为 3 仓行为（5 仓未真正生效），该档 5 仓数据不等同于有效 5 仓实验。

> 对照口径：V1 最优组数据取自 2026-08-06 T-023 报告（同 5600 元 / 整手 / signals.csv / prebreak S 级 / 20d 口径）；C23 组仅信号集多一层 C23 过滤，模拟核心与口径完全一致，可直接并排对照。

> 判定说明：最优组 = 收益/回撤综合；风险%放大后若成交均价与每股风险均值上升、未成交信号 avgR 仍为正 → 池改善且收益提升 → 支持提高单笔风险；持仓数边际 = 分散（回撤↓）vs 资金摊薄（单笔变小）权衡。资金增长到何种水平配置应变的量化建议见分析正文（人工复核）。
