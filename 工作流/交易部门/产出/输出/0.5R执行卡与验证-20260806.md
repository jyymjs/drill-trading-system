### 样例（当日环境弱 = 0.5R 日）

```
〔挂单指引卡〕2026-08-06 当日环境档 = 0.5R 日（环境弱(右下角)→0.5R日）
  新候选挂单路径：0.5R 试探挂单 | 单笔风险额 56 元（5600×2%×0.5）
  流程（0.5R 试探 → 次日收线确认，2024-06-29 周会原文）：
    次日收盘 ①≥进场价（收下去）②≥开仓日收盘（动能延续）③非放量阴线（量比≤1.5 或收阳）
    → 三条件全满足：补 0.5R 至总 1R（等额挂单）；任一不满足：平仓
    止损优先：次日最低 ≤ 止损价 → 层面1 止损出场（先于确认判定）
  [S] 600419 测试股 | 触发 10.50 | 止损 9.80 | 每股风险 0.70 | 0.5R 日: 不可买（…）
  [A] 000001 平安银行 | 触发 11.20 | 止损 10.90 | 每股风险 0.30 | 0.5R 日: 挂单 100 股（风险 30 元 ≤ 56 元）
  ※ 0.5R 日：挂单量按 0.5R 半额风险预算（56 元）计算；次日确认后补仓等额。

〔分步建仓持仓卡〕2026-08-06 在持 0.5R 试探仓 1 笔
  ✅ 600419 测试股: 收线确认（收下去/动能接受）→ 补 0.5R 挂单 100 股 @ 10.50（等额，总 200 股 = 1R）
```

### 要点
- **当日环境档**：上证指数 60 日窗口 `environment_quality`（复用 `sim_trading._market_env_scale`，
  与模拟层当日头寸统一同源）→ 「1R 日 / 0.5R 日」；指数不可得 → 默认 1R 日（放行侧）
- **1R 日**：新候选给 1R 挂单指引，风险额 112 元（5600×2%，按当日资金实算）
- **0.5R 日**：新候选给 0.5R 试探指引（56 元）+ 次日收线确认流程说明
- **分步建仓持仓卡**：在持 0.5R 试探仓（sim_journal `phase=="half"`，兼容带 phase 列的
  实盘录入行）→ 复用 `sim_trading._check_half_position`（内部调
  `indicators.half_position_confirm`）→ 动作指令（补 0.5R 挂单价/平仓/持有等待/触止损）
- 实盘 trade_journal 无 phase 列（录入口径未扩），实盘 0.5R 录入后 phase 标注即可进卡

## ② 资金占用口径（sim_capital `--half-phase`，默认关 = 现有行为零变化）

`sim_capital.py` 新增 `half_phase` 参数（CLI `--half-phase`）：0.5R 起步首日半额风险预算
（股数减半、仅占用半仓资金）→ 确认日（入场次一交易日，`indicators.phase_confirm_from_kline`
真实 K 线判定）→ 确认补 0.5R 至总 1R（占用补全）/ 不确认半仓止步；半仓期间"待补预留"
资金不可作他用（可买性检查扣除 pending）；半仓买不起 1 手 → 回退 1R 直开（执行集可比）。

## ③ 确认规则质量验证（历史回放 · 514 笔全量）

按 0.5R 起步回放 `half_position_confirm`（触发日定位与回测层 `tracking._track_prebreak`
同规则；K 线 duckdb 只读全量 qfq）。

| 指标 | 数值 |
|---|---|
| 回放笔数 | 514（K 线可判定 514，无缺失） |
| **确认率**（补仓） | **39.7%**（204 笔） |
| 不确认平仓率 | 56.0%（288 笔） |
| 触止损（层面 1） | 4.3%（22 笔） |
| **误杀率** | **57.6%**（166/288）→ **>20% 需调规则** |
| **漏补率**（确认正确率） | **62.7%**（128/204） |
| 机会成本（持有 20 天近似 R） | reject 组 **+0.629** / confirm 组 **+1.725** |

**口径（写入报告）**：
- 误杀率 = 被"不确认平仓"的票中，平仓后 20 天内最高涨幅 ≥1R 的比例
  （平仓价 = 确认日收盘；20 天窗口内最高价 vs 平仓价 ≥ 单笔风险额）
- 漏补率 = 确认补仓的票中，补仓后 20 天内最高涨幅 ≥1R 的比例（口径同误杀）
- 合格线：误杀 <10% 合格，>20% 需调规则

**解读（如实）**：按口径误杀率 57.6% 超过 20% 红线——"次日收线不确认即平"在 20 天
持有视角下确实错杀大量后续能走出 ≥1R 的票（机会成本 +0.629R）。**但这是"早平仓截断
尾部大亏"与"牺牲后续上涨"的权衡**：同一批信号在 phase_in 关（c23）下 -3~-1R 大亏
208 笔 → phase_in 开后压到 77 笔（中位数 R 0.018→0.163，胜率 50.1%→55.1%）。规则
方向（降低单笔大亏）有效，代价是平均 R -6%。**是否调整（如放宽 C2/加宽确认窗口）属
业务决策，建议老板拍板；口径与数据已可复算（`python 项目/回测系统/confirm_replay.py`）。**

## ④ 大赢家归因（phase_in 前后档位对比）

| 指标 | phase_in 关（c23） | phase_in 开（final） |
|---|---|---|
| 触发样本 | 515 | 514 |
| 平均 R | +0.964 | +0.903 |
| 中位数 R | +0.018 | +0.163 |
| 胜率 | 50.1% | 55.1% |
| 累计 R | +496.4 | +463.9 |
| **10R+ 占比** | 2.1%（11 笔） | **1.8%（9 笔）** |
| 最大单笔 R | +23.1 | +21.7 |
| **最大单笔/累计 R** | **4.6%** | **4.7%** |

档位分布：phase_in 开后 -3~-1R 从 208 笔降至 77 笔、-1~0R 从 49 升至 154（亏损向
小亏区间压缩——"次日确认"的截断效应）。

**结论（如实）**：0.5R phase_in **未加剧"依赖大赢家"**——10R+ 占比 2.1%→1.8%（反而
微降），最大单笔占累计 R 4.6%→4.7%（持平，+0.1pp 在样本量 1 笔差异噪声内）。策略
收益结构依赖大赢家是**样本量本身**的问题（514 笔触发仅 9-11 笔 10R+），与是否分步
建仓无关。符合预期"非主因，样本量才是"。
