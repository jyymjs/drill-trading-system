## 一、改动摘要

### P5-1 fetcher.get_daily_kline 加 duckdb 优先分支
`数据基础/数据/fetcher.py`
- 新增 `_fetch_from_duckdb()`：读层（原始价 + 因子自算 qfq），命中直接返回；
  库缺失 / 该股未入库 / 窗口覆盖不足 → `None` 静默回退，异常不阻断主链路
- 数据源优先级：**duckdb → CSV 缓存（deprecated）→ pytdx → baostock → akshare**
- 函数签名不变（调用方零改动）

### P5-2 CacheDataProvider 改读 duckdb
`项目/回测系统/adapters/data_provider.py`
- `load()` 先直读 duckdb **全量历史**（qfq 四价自算）→ 解锁 D1 分段一致性检查
  ≥3 年数据前提（旧 CSV 仅 ~3 年窗口）；缺省回退 deprecated CSV → 网络
- 新增 `db_path` 构造参数（默认配置库，测试注入临时库）

### P5-3 CSV 缓存层降级 deprecated
`数据基础/数据/cache.py`：模块 docstring 标记 deprecated（权威源已切 duckdb），
**不删除**——旧文件保留可读（对照/回退），网络回退分支仍写缓存。
- 454MB / 5205 个 CSV 评估结论：**以 duckdb 为准，CSV 保留只读**（建议采纳，
  已标注；后续可另立数据归档项）

### P5-4 新增读层与测试
- 新建 `数据基础/duckdb/reader.py`：`read_daily_raw` / `read_xdxr` /
  `compute_qfq`（P1/P2 同款等比因子法，自 recon 提取共用，扩展**四价**同乘）/
  `read_kline`（对外统一出口，中文列 + 派生列，窗口覆盖判断）
- 新建 `测试/test_duckdb_reader.py`：11 个用例（qfq 因子手工验证 / 覆盖判断 /
  fetcher 分支优先与回退 / provider duckdb→CSV 回退）

### 收尾小项
- **recon 抽样可复现**（`数据基础/duckdb/recon.py`）：`SELECT DISTINCT symbol
  FROM daily` 加 `ORDER BY symbol`；`compute_qfq` 改为从 reader 共用（消除重复实现）
- **4 个测试断言**：`测试/test_backtest_tracking.py` 的 4 处含成本断言已在
  提交 `5edf0f9`（D2 成本压力）中同步为 `_trade_cost` 动态口径，本轮验证
  **10/10 全绿，无需改动**
- **verify 容差修订**（`项目/回测系统/verify.py`）：引擎 signal.close/出场价
  round(4)，duckdb qfq 为全精度浮点（如 2.3465346531…），旧 1e-6 严格相等
  必然误报；改为 **0.1% 相对容差（绝对下限 1e-3）**——verify 本意是防时间切片
  错位，非精度校验。4 处比较统一修订（含 verify_csv）
