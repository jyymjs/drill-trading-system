## 1. 策略总览（白话）

**是什么**：A 股趋势跟踪 + 突破埋伏策略，靠盈亏比（R 倍数）获利，不靠胜率。

- **入场主入口 = 预突破（prebreak）**：在平台突破点下方埋伏挂单，放量突破触发买入——只做"质量最好"的票（评级 + 一票否决 + 四道闸门 + C23 过滤层层把关）
- **仓位**：单笔风险 = 资金 × 2% × 环境档（1R 或 0.5R），最多 3 仓并发
- **0.5R 分步建仓**：环境弱日先进半仓试探 → 次日收线三条件确认 → 补满 1R；不确认立刻平仓
- **出场**：四层保护（原始止损→平价保护→移动获利→追踪获利）+ 主动出场
- **模拟线对照**：10 万名义资金无资金限制跑同策略，与实盘（5600 元约束）对比，作为策略修改参考

## 2. 评级体系（6 条件：DL/PT/LK/TY/DN/SF）

评级 S/A/B/C（课程标准），优先级：Tier0 一票否决 → Tier1 核心三要素（PT/TY/DN）→ Tier2 质量分级（DL/LK/SF）→ Tier3 加减分。

### DL 独立结构（结构规模）
| 参数 | S | A | B |
|---|---|---|---|
| 结构根数 | ≥60 | ≥60 | ≥60 |
| 区间波幅 | ≤20% | ≤30% | ≤35% |

- 一档化裁决（T-4.3）：根数仅作 ≥60 通过门槛，评级靠波幅容差（70+ 根反而被充分定价，0.448R < 60-69 根 0.596R）
- 过高点存在时从新起点重新计数；波幅 <3% 的结构不参与评级（无意义）
- 结构起始检测（SF 用）：120 根/20% → 90 根/30% → 60 根/35% 逐级回找

### PT 平台测试（最优先）
| 参数 | S | A | B |
|---|---|---|---|
| 有效测试次数 | ≥3 | ≥2 | ≥2 |

- 容差 0.5%、相邻测试最小间隔 8 根（T-4.4 校准，原 1%/3 根致 99% S 虚高）

### LK 轮廓质量（2024 年新增三维）
- 综合分 = 紧凑度 × 0.45 + 像素感 × 0.25 + 横盘感 × 0.30
- S ≥ 0.50（且紧凑 ≥0.45）/ A ≥ 0.40 / B ≥ 0.30
- **硬降级**：像素感 < 0.35 → C；横盘感 < 0.30 → C
- 窗口：紧凑/横盘 20 根、像素 30 根

### TY 统一区间（窄幅整理）
| 参数 | S | A | B |
|---|---|---|---|
| 最少 K 线 | 5 | 4 | 4 |
| 区间波幅 | ≤3% | ≤5% | ≤8% |

- **3 根 = 不足 C 级**（2024 年修正，非瑕疵 B）
- 实体占比均值 >0.6 的区间跳过（太实心不算整理）；价格漂移 > 波幅×2 跳过
- 区间波幅 = 区间振幅 / 基准价（MA20 优先，缺失用收盘价）

### DN 动能（相对量比 + 坚决度）
| 档 | 合并 K 线 | 相对量比 | 坚决度 |
|---|---|---|---|
| S | 1 根 | ≥1.5 | ≥0.50 |
| A | 2 根 | ≥1.2 | ≥0.45 |
| B | 3 根 | ≥1.0 | ≥0.40 |

- 相对量比 = 启动 K 合并窗口均量 ÷ 前面调整段日均量（1.0=持平）
- 坚决度 = 阳线占比 × 0.5 + 实体/振幅均值 × 0.5（收完度）；**<0.4 强制降级**
- 冲突感（z-score）：≥2.0 提级、<1.0 降级（S→A / A→B）
- 降级规则：通道感 / TY-DN 间隔 >1 根，每项降一级
- 实体仅展示不设门槛（老师语义：动能 = 相对比较 + 收完，非绝对量比/实体）

### SF 释放级别（涨幅阈值）
- 1st S：前期释放 <12%（积累充分）
- 2nd A：12%~25%（部分释放）
- 3rd C：>25%（完全释放，一票否决域）
- **数据不足 → C 观望**（A2 裁决：DL 起点缺失或 <20 根 = 看不清 → 观望，不放行伪 A）

## 4. 综合评级规则（标准模式 grade()）

- **Tier1（PT/TY/DN）任一 C → 整体 C**；Tier2（DL/LK/SF）任一 C → 最高 B（Tier1 含 B 则 C）
- **S 级**：S 数 3~4 个 + 无 B + **PT=S 且 TY≠S 且 SF≠S**（T-4.4 数据校准：5 个 S 亏钱、TY=S 负贡献、SF=S 最毒、PT=S 唯一强正贡献）
- **A 级**：B ≤1；全部 A 无 S → 降 B（老师不关注均 A 交易），除非回踩+反应双优（bonus≥2）恢复 A
- **B 级**：B ≤3（bonus≥2 且 B≤1 可提 A）
- **A1 降级**：有回踩但无明显反应（"碰一下慢慢蹭上去"）→ 综合评级降一档
- **Tier3 加分**：回踩轨迹深 + 明显反应好（bonus≥2 提一级）

## 5. 预突破模式（prebreak · 实盘主入口）

扫描 5 条件（**不含 DN**，DN 改为输出触发价/止损价）+ Tier0（跳过回踩检查）。**比标准更严**（"上膛待发"必须过硬）：

- 任一条件 C → 淘汰；**不允许任何 B** → 淘汰
- S 级：3~4 个 S + TY≠S + SF≠S；A 级：≥2 个 S；否则 B

**条件单参数**：
- 触发价 = TY 上沿 × **1.002**（+0.2% 确认突破）
- 止损价 = TY 下沿 × **0.998**（-0.2% 余量）
- 每股风险 = 触发价 − 止损价

**C23 收紧（V2 核心，T-024）**：
- 动量 ≤10%：触发价 vs 20 交易日前收盘涨幅 ≤10%（`trigger / 前第20根收盘 − 1`）
- 止损距离 0.5~3 元（太近易被扫 / 太远盈亏比差）

**放量过滤（M-21/T-020 接线）**：最新日量比 >1.5（成交量 ≥ 前 20 日均量 × 1.5）才进挂单候选——与回测 dn_confirm=1.5 口径对齐，不达标存 `_vol` 研究列表。

- **资金与仓位（2026-08-08 老板确认定案）**：8401 资金 + **单笔风险 108 元**（capital.json risk_ratio=1.29% 覆盖，不随注入机械上调）+ **5 仓并发**——完整周期回测 B2_5 最优（+280.4%/回撤27.3%/avgR 0.986/连败7）；每月 3000 注入只进本金积累（资金瓶颈已消除，注入边际≈0）
- **环境档统一**（2024-06-01 周会：同日不混合 1R/0.5R）：当日市场环境（上证 60 日窗口右下角判定）→ 全池统一 1R 或 0.5R；判定不可得 → 1R（放行侧）
- **0.5R 分步建仓**（2024-06-29 周会"先进二分之一，再进二分之一"）：
  - 0.5R 试探 → 下一根收线**三条件确认**：C1 收线 ≥ 进场价 / C2 ≥ 开仓日收盘（动能延续）/ C3 非放量阴线（量比 ≤1.5 或收阳）
  - 三条件全满足 → 补 0.5R 至总 1R；任一不满足 → 平仓；**止损优先**（先于确认判定）
  - **delay2**（M-10）：首根不确认且 T+2 到位 → 第二根再确认一次（误杀率 57.6% 超红线，delay2 "只给强票多一天"）；T+2 未到位 → 等待
- **整手 100 股**；同日多候选按**每股风险居中**排序（|每股风险−1.5| 升序，M-20/T-032：+88.8%→+107.3%）
- **模拟线**（2026-08-08 老板拍板）：10 万名义资金 × 2% 规则，扫描候选全部挂模拟条件单（到价才成交、3 交易日未触发撤销），与实盘对照

## 8. 出场体系（六层，按优先级）

| 层 | 规则 | 触发 |
|---|---|---|
| **层面1 原始止损** | TY 下沿 × 0.995（多头） | 价格触及 → 全平 |
| **层面2 平价保护** | R ≥1.0 → 止损移至成本位 | 从此不亏 |
| **层面3 移动获利** | 夹角小的明显拐点（V 型尖底：反弹斜率 ≥ 下跌斜率）+ 优势因素（<5R 需 2 个：回调深度 ≥0.5R / 拐点影线 ≥实体 2 倍 / 有调整结构；≥5R 需 1 个）→ 止损 = 拐点低点 − 回撤×10%；**硬规则：新止损必须高于进场价** | 回调后破前高 |
| **层面4 追踪获利 TTP** | 利润 ≥5R **且无合适移动获利点**（互斥）→ 允许从最高点回调 36% | 兜底保护 |
| **主动出场** | 环境前提（有利可图 R>0 + 累耗失衡：近期涨速 ≥ 前期 1.5 倍）+ 拐点三特征取 2 且强度 strong（斜率骤变 >4%/6%、短时波幅 >5%/8%、放量 >2x） | 主动离场 |
| **分批** | >5R 全出 / <5R 平一半（老师口径） | 出场动作 |
| **止盈** | A 股多头 = 趋势跟踪**无止盈**；空头/外汇 = 波段 5R 止盈 | 方向/市场类别 |

- 0.5R 半仓在确认流程中：触止损 → 层面1 按止损价平仓（先于确认判定）
- 5R 两档界（G7 统一）：原 2023 周会 3R 界已弃用（对照实验零差异，取内训 19 节正式版 5R）


## 10. 策略进化机制（完整蓝图 · 2026-08-08 老板确认整理）

> 进化 = **三源输入 → 实验验证 → 分级决策 → 规格书先行落地 → 反馈闭环**，老板门控。
> 本蓝图把「策略维护方案.md」的六步铁律与「投资研究员四层漏斗」「模拟线对照」「实盘检查点」整合为一套完整路径。

### 10.1 进化目标

让策略在**知识、数据、实盘三层证据**驱动下持续改善，每一次改动都有据可查、可回退、可验证——不靠感觉进化。

### 10.2 三个输入源（发现"改什么"）

| 源 | 通道 | 产物 |
|---|---|---|
| **知识** | 课程/周会提炼（video/text/book-distill）→ 观察池 → 模式假设 | 假设待验证清单 |
| **实验** | T-系列对照实验（抽样 → **全量复核**铁律） | 数据结论 + 新参数建议 |
| **实盘反馈** | R 曲线 vs 回测预期（蒙卡 P50/P95）、模拟线 vs 实盘偏差、连败/回撤事件 | 偏差报告 + 排查项 |

### 10.3 验证漏斗（判定"能不能改"）

```
对照实验（数据说话，先跑数据不说话）
  → 全量复核（方法论铁律：抽样结论必须全量验证）
  → 质检（六轴验收）
  → 测试回归（520+）+ 蒙卡 10000 次
  → 口径铁律（回撤一律总资产口径，现金口径禁止）
```

### 10.4 决策分级（判定"谁拍板"）

| 级别 | 范围 | 决策权 | 门槛 |
|---|---|---|---|
| **微调** | 参数数值（阈值/周期/比例） | 助理自主（数据支撑+全量复核通过），周报呈报 | 全量回测对照 + 蒙卡 + 测试回归 |
| **改进** | 规则语义（实现方式/边界） | 助理自主 + 老板知情 | 同微调 + 分布诊断（大赢家依赖核对） |
| **改版** | 结构级（评级体系/入场重构） | **老板签字**（"确认"二字） | 全面测试四组 + 双件套蒙卡 + 质检六轴 + 新旧对照不劣于旧版 |

### 10.5 落地流程（规格书先行）

```
改版/改进/微调定案
  → ① 先改本规格书（策略权威：参数/规则/出处同步更新）
  → ② 代码同步（人格链施工 + 验收）
  → ③ 生效登记（修改概览 M-编号 + 版本存档 + 记忆同步）
  → ④ 报告（周报呈报：数据/依据/结论全录）
```

> 铁律：**文档先行**——策略先以文字定案，代码是实现；规格书与代码不一致时以规格书为权威待同步（C23 常量另有运行时防漂移校验兜底）。

### 10.6 反馈闭环（判定"改对了没"）

```
模拟线对照（10 万名义自动跑现行策略）→ 与实盘逐笔/逐周对比 → 偏差即信号
实盘检查点：50 笔（执行质量）/ 100 笔（判收益）→ 重跑对照实验验证回测预期
事件驱动：连败 >12 笔 / 回撤 >18% / 盈利结构偏差（依赖大赢家变化）→ 排查是否策略问题
策略特征体检：定期重算关键分布（触发延迟/量比/动量）→ 与设定值对照，漂移报警
```
