## 一、第十三节：标准模式六条件（进场方式 1）

### 1. 学习顺序与条件代码体系
- **结论**：先掌握两种基本交易结构（平台结构 / 颈线结构）的大致样貌，再抠细节；反过来先抓细节容易"细节对了、样貌一看就错"。六条件各自有拼音代码：DL 独立结构、PT 平台位或颈线位、LK 轮廓、TY 统一区间、DN 动能、SF 释放级别；评级四级 S/A/B/C（S=优质加分项，A=正常常规，B=有瑕疵，C=完全不满足）。
- **依据**：13 节开头"交易条件化解为代码"四好处（记忆/不遗漏/周课反馈直接用/识别方法）；"DL 独立结构、平台位…统一区间、动能、释放级别"。
- **条件**：所有标准模式交易；周课堂反馈可写"交易条件代码"。

### 2. 独立结构 DL（必须 S 级）
- **结论**：独立结构 = 宏观调整/盘整行情；DL 是唯一**必须 S 级、没有 A/B/C 选项**的条件（"结构必须是优质的，它没有后面的选项"），不优秀直接 pass；标准化起点 = 90 根 K 线以上（任意决策周期都适用，但必须先定决策周期且不来回切换）；视觉习惯为主、90 根是给新手的标准化入口；**近似结构可并入**——真正平台位之前的一段盘整可并入整体计算，只要整体（含近似结构）超 90 根或满足视觉边界即可。
- **依据**：13 节"我们一定要求它是 S 级的""90根K线以上""你可以把这个近似结构并进来……包含在内超过90根"。
- **条件**：原理 = 筹码积累充足，需要大规模宏观级别盘整酝酿后面的运行。

### 3. 平台位 / 颈线位（PT）
- **结论**：平台位 = 架台子，结构内部**至少三个支点**；颈线位 = 头肩形态，内部至少三个**触点**（触点要非常明确）；两者都**可经验性穿越实体**（画得更明确更舒服，但不能突兀）；颈线尽量水平；原理 = 关键位置（被反复测试过、市场有聚焦点）+ 寻找结构薄弱点（越薄弱越易有效破位）。
- **依据**：13 节"至少三个支点""支点要把它支稳""颈线位上面的点叫触点""可以穿越实体，要合理"。
- **条件**：多画多感受积累经验；对应 2024 周会"三次测试足够强、两次=不足、离得近算一次"。

### 4. 轮廓（LK）
- **结论**：轮廓 = 视觉积累，用来排除"凌厉"走势（大开大合、筹码集中度差、消耗大）和奇怪走势，选择平整横盘；轮廓是"基于规则的主观"体系的圆润层——规则保证一致性，轮廓等视觉识别提供适应性；解决"完全标准化程序只能适应某一段行情"的问题；多练可达到一眼识别。
- **依据**：13 节"这种走势不是我们喜欢的……筹码消耗比较大""一个完全标准的程序在市场常年跑一直赚钱几乎不可能……背后要有管理者调试"。
- **条件**：规则之下放经验；经验型的弱点是可持续性/一致性，靠多练解决。

### 5. 统一区间（TY）
- **结论**：TY = 低斜率 + 小K线 + **至少四根K线或以上**；**必须紧跟着交易 K 线/动能在行情的末尾发生**（中间发生且破位不满足条件就不做）；原理 = 释放前迹象（价格波动被挤压到极限 → 必然爆发）+"价格停留时间长=统一、短=分歧，统一性无法持续"；筹码集中度强 → 未来运行规律性更强。
- **依据**：13 节"低斜率、小K线、至少是四根K线或以上""统一区间一定是紧跟着我们的交易的那根K线""它叫做释放前的一种迹象"。
- **条件**：看到调整末尾出现 TY 就可以开始注意交易条件（起迹象/提醒作用）。

### 6. 动能（DN）
- **结论**：动能 = 冲突感（相对概念：相对 TY 窄幅，K 线截然不同、突然一根起来）+ 绝对力度（单看启动 K 线本身）；**至多三根并一根**观察（合并根数越多动能越差，四根以上并在一起=动能太弱）；原理 = 某一方筹码占压倒性优势 + 验证薄弱位置合理性（案例：空头三次打压、第四次没反应形成 TY → 空头力量耗尽 → 多头站稳）。
- **依据**：13 节"至多是把三根并在一起来观察，合并观察的K线个数越多，动能越差""如果你说四根五根六根放在一起和这个一样，那这个动能就太弱"。
- **条件**：动能评级时；案例中有"A 减"做法（动能还行但收线/上影线有问题时小幅降档）。

### 7. 释放级别（SF）三类
- **结论**：一类释放 = 启动前没有释放、条件满足直接做；二类释放 = 结构内自下而上有一段不明显运行 + **统一区间必须出现在 W/M 型调整结构的末尾**（若已定义二类释放、只有四根小调整直接上去不做——筹码积累不充分）；三类释放 = 明显大段运行/释放 → **重新等待一个新的独立结构**（≥90 根，与前面无关，相当于重新关注新机会）。
- **依据**：13 节"当你把它定义为二类释放之后，在这个地方直接给你出现一个统一区间，但是它没有调整结构，然后直接往上去走，这种我们不会做""那这样怎么办呢，重新等待一个独立结构"。
- **条件**：原理 = 积累要大于消耗。

### 8. 案例判定细节
- **结论**：①动能"要收完"——做多收上去、做空收下来，卡在线上不行；②跳空：集合竞价/盘前盘后造成的跳空无碍（可补足为阳线），但**交易时间段内价格缺失 = 流动性有问题要谨慎**；③复盘时注意视觉压缩问题（后来大行情把当时结构压缩得很小，要按当时行情的视觉判断）。
- **依据**：13 节特斯拉案例（缺口）、WTI/不锈钢/苹果等 14 案例判定过程。
- **条件**：所有评级与复盘。

## 二、第十四节：意图模式（进场方式 2）

### 1. 六条件背后的意图（为什么定这些规则）
- **结论**：DL = 筹码充分积累；关键位置 = 市场关注位置（大资金平时隐匿踪迹、关键位必须真实反应争夺，越多人关注越易表达真实市场反应），反复测试 = 对该位订单的消耗（支撑位靠排队买入订单持续、反复消耗后可能跌破）；轮廓 = 优秀筹码积累方式（接力赛换棒、多空充分意见交换）；统一区间 = 极限平衡状态（价格极窄还能运行一段时间 = 多空达成平衡；平衡后突然迸发的启动有两大好处：快速脱离成本区 + 空头/机构被迫表达真实意图）；动能 = 排队买入/卖出情绪的开启 + 坚决程度；释放级别 = 避免明显消耗之后的追击（已释放过的行情，进场后动能能否立即持续成疑问 → 单子可能长期纠结在成本区附近）。
- **依据**：14 节逐条原话（"独立结构代表筹码充分的积累""关键位置是市场参与者关注的位置""统一区间是一种极限的状态""避免明显消耗之后的追击"）。
- **条件**：理解意图 → 才理解为什么标准模式定这六条规则。

### 2. 意图模式总思路
- **结论**：加入**多空争夺之后的胜者**——先有争夺（充分意见交换），争夺充分后的爆发才可能把一方力量消磨殆尽；做右侧破位，在"统一区间+启动K 达成标准"时介入；同时必须有**有利的交易条件**三要素：有效止损（行情打掉止损还继续正向运行=挫败）/ 有价值的交易（潜在盈亏比空间，零点几倍盈亏比不下单）/ 快速脱离成本区（快速做平保、风险降低）。
- **依据**：14 节"我们一定要加入的是多空争夺之后的胜者""有效的止损、有价值的交易、快速脱离我们成本区，这三个方面是我们最底层的需求"。
- **条件**：意图模式所有交易。

### 3. 意图模式两脉流程
- **结论**：
  - **一脉·筹码集中区**：①发现独立结构 → ②从价格行为找**筹码集中区**（价格重合度高/价格停留时间长；要求比 TY 低；允许平缓倾斜角度、允许**非连续**——中间无价格的区域也可）→ ③用**成交量分布图**验证 POC（分布越不均匀越好）→ ④两种交易形式：**有利突破**（统一区间+启动K 突破 POC）/ **依托**（已突破 POC 但运行幅度极为有限、回贴 POC 位置再形成统一区间+启动K）。
  - **二脉·关键位置**：①发现独立结构 → ②寻找**三次或以上测试**的关键位置（**不要求测试在同一个独立结构内完成**——与标准模式平台位的区别，放宽；触碰要有**明显反应**=有明确转折点，不是不管不顾随便穿越）→ ③交易：有利突破 或 **明显反应回踩**（夹角小、时间短、有力度，触碰立即弹起）。
  - **硬约束**：被回踩的、被有利破位的，都必须是独立结构（防止五花八门找关键位置）。
- **依据**：14 节思维导图总结原话（"我们先找筹码集中区……再用成交量分布图去验证它的 POC""寻找存在三次或以上的价格测试的位置或区域""被回踩的是一个独立结构，被有利破位的也是一个独立结构"）。
- **条件**：意图模式全套流程；有利条件没出现就不做（USDJPY 案例：POC 验证了但没出现统一区间+动能 → 不做）。

### 4. 先价格行为、后成交量分布验证（顺序不可反）
- **结论**：必须先肉眼找筹码集中区，再用成交量分布图验证；反过来（先画图硬找 POC）不正确——三个原因：①效率（一眼识别快，做一个指标的时间可看四五个品种）②持续性（手机/户外也能一眼识别）③因果关系（因为价格停留时间长，所以成交量高——因果方向不能反）。
- **依据**：14 节"不要偷懒……不建议这样做"三大理由原话。
- **条件**：意图模式一脉流程；与 2024 周会 07-13/20/27 三次强调完全一致。

### 5. POC 分布特征与市场适用
- **结论**：POC 分布**越不均匀越好**（某区域明显多于其他才有价值；均匀=没特征性）；不均匀代表分歧大、大行情可能迸发（非理性是找到破绽的时机）；场内（股票/期货）成交量精准可参考；场外（外汇 CFD/加密）只参考**分布**不参考**数值**（大券商/大交易所=有统计价值的抽样）；A 股每天 4 小时交易时段 → 筹码集中区要求可放宽（区域宽一点）。
- **依据**：14 节"它的分布不是均匀的，越不均匀越好""场外市场的成交量只能作为一个参考""A股每天就那四个小时……要求放宽一点"。
- **条件**：市场类型区分。

### 6. 意图模式下的释放级别放宽
- **结论**：意图模式下释放不按现象层严格规范（如黄金案例：上去假突破后下来依托关键位回踩——纠结时间越长酝酿行情越多、假动作越多后面迸发动能越强、筹码积累程度高，可尝试）；此方式一开始可以不用，有积累/消耗感知力后再用。
- **依据**：14 节黄金案例原话（"这个行情蛮复杂的……筹码的积累程度是相当高的""这种方式在一开始你可以不用"）。
- **条件**：经验积累后；中规中矩的状态优先。

## 三、第十五节：补充计划（两条规则）

### 1. 本质：规则与市场因素之间的"润滑"
- **结论**：补充计划解决"标准化细节规则"与"市场因素"之间的摩擦（例：统一区间 3 根/4 根在底层原理上无天壤之别，但规则必须有边界）；完全取消规则成本太高（随机/情绪化交易、没有参考系、心态情绪进入决策因素）→ 规则必须有，边界处错失机会是可接受的成本。
- **依据**：15 节"三根不能做，四根可以做，但从市场因素角度没有办法从根本性逻辑解释天壤之别""如果完全取消规则，它的成本太高了"。
- **条件**：交易系统顶层设计阶段；规则制定后**不能随意修改**（不能在遇到特别想做的行情时现场放宽）。

### 2. 补充计划一：统一区间与启动 K 之间至多 1 根间隙
- **结论**：统一区间与启动 K 之间**至多允许 1 根 K 线的间隙**（柴犬币案例：三根并一根动能不错但离 TY 隔一根；黄金案例：再往外放就变成没有边界，至多给一根）；作用：动能收线不好/上影线长（上方卖压）时等一根——下一根站在高点上方或三根并一根动能不错即可关注。
- **依据**：15 节"至多呢可以有一根K线的间隙""至多至多给一根K线的一个间隙，让我们的方法更加润滑"。
- **条件**：其他条件都非常好、就差这一点点时使用。

### 3. 补充计划二：收线过远 → 提前锚定（if-then 语句）
- **结论**：当根 K 线破位后已表现出极强动能、等收完会错过时——**提前画一条线锚定**，做 if-then 预判："当根 K 线直接打到这个位置 = 认定有动能，直接进场，不等收完"；锚点要画在**更明显的动能表达**位置（比正常收线位置更远一点、余富一点——因为直接进场没有收完稳定）；关键：**是提前计划，不是行情走了之后临时决定**（临时判断容易被行情带进去，每次不等收完被带着走 → 遇到更多诱多诱空）。
- **依据**：15 节"先画一条线，先锚定一个位置。当根K线走到这个位置，我就认为它是很有动能的""一开始你就有计划先画条线""不要反过来，看到行情走了一大段然后被带进去了"。
- **条件**：动能极强且破位清晰时；棉花/黄金案例。

### 4. 心法：先标准后补充
- **结论**：不熟悉风险交易、不了解时，先按最标准规范的方式（无补充计划）掌握好，再用补充计划（如虎添翼）；反过来使用会导致行为一直不稳定。
- **依据**：15 节结尾心法原话。
- **条件**：个人熟练度。

## 四、第十六节：应用心法（上下半场 + 经验性处理 + 分市场）

### 1. 交易上下半场
- **结论**：上半场 = 通过标准规则练就高水准交易能力素养（表现：执行一个交易系统/一致性规则达**两年或以上**——老师估计能做到的 <1% 交易者、大众散户 <1‰，是专业素养标志）；下半场 = 基本盘稳固后，盘感和经验逐渐涌上来、可适度调动（老师交易**第 13 年**才推出意图模式）；**调动主观经验的前提 = 基本盘高水准**（随便给一套系统化规则能 90% 以上执行出来）；无数交易者没建基本盘就凭感觉做 → 行为/模式/认知/心态全不稳定。
- **依据**：16 节"能执行一个交易系统达到两年或以上……百分之一都不到""现在我的交易是第13年""你一定要先把前面的基本盘把它建立起来"。
- **条件**：成长路径认知；加入学社可把基本盘压缩到约 1 年。

### 2. 时间线
- **结论**：不浪费时间的最快路径约 **5 年**：半年认识市场 → 1.5 年选根基理论+建规则测试评估 → 执行 2 年以上（快 5 年）；中途浪费（前两年乱做、第三年才想建系统）→ 7-8 年才能达到。
- **依据**：16 节时间线推算原话。
- **条件**：个人路径参照；"五年是一个坎"。

### 3. 两种模式的选择与特点
- **结论**：针对性——选适合自己的（标准=逻辑标准化思维框架的人；意图=能看懂市场、与市场贴近的人）；通用性——先标准（练基本盘）后意图。标准模式特点：规范性强/可复制性强/上手容易、现象层面判定所以**严苛**（严苛是为了让系统承受最不利的市场环境——每种系统都有最不利环境，黑暗到来时要经得住，资金管理+交易条件都要受得了）；意图模式特点：注重价格背后意愿、硬性条件放宽、更灵活、机会更多、适应性更好；**"标准模式是意图模式的特征版"**（最有特征的、最能代表背后意图的呈现方式）。
- **依据**：16 节"我们的交易系统是要能够承受最不利的市场环境""标准模式其实就是意图模式的一个特征版"。
- **条件**：模式选择；标准模式一直做效果也很好。

### 4. 经验性处理四个层面（前提：对标准+意图都足够熟悉）
- **结论**：
  1. **统一区间放宽到 3 根**：整体条件都非常好时，TY 最少放宽到三根，再不能放宽（K 线数量制定更多为了一致性，总归要有个底线）；
  2. **间隔 K 线忽略**：统一区间非常好 + 其他条件正常/不错时，TY 与启动 K 间隔不符规则可忽略；
  3. **独立结构边界忽略**（<90 根可做）——必须同时满足两个前提：①筹码集中区特征非常明显（价格停留时间长、价格重合度特别高）②**POC 分布非常明显突出**（一个明显的筹码峰/成交峰值；只比别处大一点点=不明显，不行）；
  4. **股票市场特定方式**（见下条）。
- **依据**：16 节逐条原话（"整体条件都非常好的情况下，我们可以在统一区间的最小边界上面放宽一个，放宽到三根，再不能放宽""必须满足这两个：特征非常明显 + POC 非常明显突出"）。
- **条件**：经验性处理是"特定条件下规则让步"，不是随意放宽。

### 5. 分市场：多空交易平衡性 + 股票低位 POC 特定方式
- **结论**：市场分两类——股票（有价证券，做多简单/做空复杂：要先借股才能卖；美股标普 500 有天然上行斜率；A 股散户为主、开户量约 3 亿世界独一份、震荡时间长/急涨急跌多）vs 合约（期货/外汇保证金/加密合约，多空同一逻辑、平衡）；因股票多头交易难度更低 → 股票市场特定交易方式：**低位出现 POC + 低位成交量分布占大头**（占比要求：不超过这波空头行情回调的 30%——黄金分割 23.6% 位置案例）时，**可忽略独立结构边界要求 + 忽略筹码集中区识别要求**，重点关注多头端；原理：低位大成交 = 市场聚焦+分歧大+空头非理性（恐慌卖出），空头被多头吃掉后力量骤降 + 低位天然吸引买。
- **依据**：16 节特斯拉筑底案例、奈飞案例（23.6% 黄金分割）；"多空的交易难度：股票做多比做空更容易""低位的成交量的分布是占大头的……不能超过这波空头行情的那个回调的30%"。
- **条件**：仅股票市场（其他市场多空平衡不用）；以做多为主。
- **存疑**：转写稿"不能超过这波空头行情的那个回调的30%"——从奈飞案例看指成交量分布上界在空头回调幅度 23.6%（黄金分割）以内，语义为"低位成交量分布占整段回调的比重"，**存疑**，待原文视频核对。

## 五、第十七节：成交量分布图（使用手册）

### 1. 调用与设置（TradingView）
- **结论**：用**固定范围成交量分布图**（老师不用"可见范围"——不美观+随图表移动影响视觉）；位置：指标→技术→固定范围成交量分布图，或绘图面板；可收藏到底部长期显示；设置：行数用 **30**（10/50/100 都行——行数少区间大、行数多区间窄；主要参考分布、不做某价格区间的精细一对一）；样式看**总计**（多空加总）；数值区 20%（成交最多的 20% 区域在哪）；POC 红线、两边界线都关掉（能看出来；保持盘面干净）；显示数值（便于对比，防视觉压缩误解）。
- **依据**：17 节操作原话（"我是用了三十行""我就看总计""数值区我选择的是20""我不需要那两条线""POC 你也可以选择出来，这个我也不要"）。
- **条件**：图表工具使用习惯；国内软件（东方财富/同花顺/文化财经）的"筹码分布"= 同一个东西。

### 2. 画法
- **结论**：看一段（上涨段或下跌段）连接起来即可；**纵向覆盖价格、横向覆盖时间**；终点不同低位筹码显示不同（想看哪个时点的筹码情况就放到哪个位置）。
- **依据**：17 节"你连接的时候，第一个要覆盖的是价格，纵向的覆盖价格，横向的要覆盖这个时间"。
- **条件**：意图模式验证时。

### 3. 常见误区（客观对待，不过度解读）
- **结论**：①**筹码峰 = 多空都多**（必须找到对手方才能成交；只有多头买不进去）——低位出现筹码峰+价格没下跌 = 买入情绪存在 + 可能空头非理性卖出/消耗过大；②每个区间数值**只代表该区域成交了多少量**，不是"下方筹码在减少/卖出量"；③放量不代表涨跌，**放量 = 分歧大**；成交量分布图只是"看多空交易者留下的痕迹的帮手"，要客观解读。
- **依据**：17 节"这个筹码峰代表的是多空都多""它只代表对应的这个区域当中成交了多少的量而已""放量只代表分歧大"。
- **条件**：所有成交量解读。

### 4. 特征与市场适用
- **结论**：核心用法两条——①找到成交量密集的地方（代表有争夺）②分布**不要特别均匀**（某区域明显多=分歧明显增加=特征性更好）；场内（股票/期货）成交量 **100% 准确**（黄金 COMEX 期货案例）；场外（外汇 CFD/加密）只参考**分布**不参考具体数值（大券商/大交易所=有统计价值的抽样）；**国内期货难调用**筹码分布 → 主要用价格行为识别筹码集中区（价格停留时间长的位置往往就是筹码峰）；A 股在 TradingView 报价奇怪的原因：11:30/12:30/15:00 形成半根废线（一字线），介意可换同花顺/文化财经/东方财富。
- **依据**：17 节"股票、期货都是场内品种，百分之百数字都是准的""国内的期货市场蛮难去调用这个筹码分布图""11点半……是休市的状态，但它还在显示"。
- **条件**：市场类型区分；鼠标滑轨可看历史筹码分布。

## 十、存疑 / 待核对点

1. **"低位成交量分布占大头、不能超过这波空头行情回调的 30%"**（16 节）：转写稿原文如此；从奈飞案例（黄金分割 23.6%）看，30% 指成交量分布上界占整段空头回调幅度的比例（即低位分布集中在下 30% 内）。语义推断合理但**存疑**，需对照原视频画面确认。
2. **DL"必须 S 级无选项"与代码 Tier2 逻辑的冲突**：13 节原话"独立结构这里边我们一定要求它是 S 级的，它没有后面的选项"非常明确；但代码 `DL_B=60` 与"DL=C 最高 B"与之矛盾——若确认课程口径，代码需收紧（DL 一票否决）。
3. **补充计划与周会"收完再补 1/2"的关系**：15 节补充计划二是"不等收完、提前锚定直接做"（进场机制）；2024 周会 08-03 的"补充计划 1/2 + 收完再补 1/2"是仓位用法（07-20 亦有"补充计划"出场语境）。两者可能是一体两面（同一名词不同侧），也可能指向不同机制——**存疑**，待后续节次（19-21 节离场/执行）对照。
4. **老师"交易第 13 年"（16 节）vs 周会"11-12 年验证有效"（2024-06-29）**：口径不同（推出意图模式时间 vs 经验型验证时间），暂按互补不冲突处理。
5. **"<1% 交易者能执行系统 2 年以上"（16 节）**：老师个人观察估计（自述"样本容量不够大"），非统计数据——作为观念参考，不作硬数字引用。
6. **13 节 14 个案例中有"A 减"特殊档**（狗狗币动能 A 减）：课程评级体系 S/A/B/C 之外存在临时微调档位（上影线长小降），代码无此档——属视觉微调，不代码化。
