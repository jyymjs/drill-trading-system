## 一、扫盘工作流与节奏

1. **结论**：市场扫描的周节奏 = 周五品种相对少（除加密外其他市场周五后停盘），周一集中关注最多、周中逐渐补充；"各个市场周期上面都有不同的状态，耐心的去等待机会的发生就可以了"。
   - **依据**：2024-08-02 开场原话；2024-07-29（"重点关注的品种没有之前周一的时候那么多"）。
   - **条件**：扫盘频率安排；没走坏的品种可持续关注，不必每天重筛（07-29/08-01 回顾持续关注）。

2. **结论**：老师扫盘时会自曝"为什么没把这品种筛出来"——筛选决策透明化：如棉花中间过高点（但反复测试仍有机会）、螺纹轮廓差得比较远（长时间横盘才能关注）、澳元对美元头肩太离谱/释放级别太高（单独独立结构再关注）、比特币平台位画法完全不认。
   - **依据**：2024-08-05（棉花/螺纹/工业规）、2024-08-07（澳元对美元）、2024-08-01（比特币）。
   - **条件**：实战决策示范层——筛不出来 ≠ 不看，而是说明缺哪条条件、要等什么形态。

3. **结论**：结构级别小 → 不值得设置价格警报，等结构级别走出来再关注。
   - **依据**：2024-07-23（"已经把K线放得足够大了但还是显得小"）、2024-08-06（"还不足以设置任何的警报"）。
   - **条件**：品种库管理；与种子卡一票否决#6 一致。

## 二、头肩形态评判细则（本批最大新知识点）

1. **结论**：头肩状态有评判标准——中间头部与左肩右肩差得多、不匹配 → 不当作头肩看；可退而求其次：从某处开始单独形成一个独立结构（平台位少可借助前面）。
   - **依据**：2024-07-23 欧元兑美元（"这个头肩状态实在是有点超过我们对头肩状态的评判标准……左肩右肩差的比较多"）。
   - **条件**：头肩形态识别；不匹配的头肩=分割成独立结构再看。

2. **结论**：头肩"脱节"不喜欢——老师喜欢"明显的一个头部下来然后上去、左肩右肩比较平稳"；有点脱节的暂时放一放。
   - **依据**：2024-07-23 期货案例原话。
   - **条件**：头肩形态评判；脱节=左右肩与头部衔接不平稳。

3. **结论**：从头部下来的那一段释放过大 → 不把它当作一个结构里面的正常状态；最好从头部下来处开始单独形成独立结构再关注。
   - **依据**：2024-07-23（"从头部下来的这一段释放的过大，我们一般是不会把它当做一个结构里面的正常状态"）。
   - **条件**：头肩/颈线结构判定；释放过大=头部下来的行情跑太远。

4. **结论**：头肩里右肩有筹码集中性但和左肩匹配度很差 → 仍需走出更多结构再关注。
   - **依据**：2024-07-31 原话。
   - **条件**：头肩对称性要求；筹码集中性不能弥补匹配度。

5. **结论**：头肩状态非常差（左肩右肩状态差、整个头肩不好）→ 先放一放，等后面单独形成一个好的独立结构再去关注。
   - **依据**：2024-08-02 期货案例（"这个状态为什么没选出来，左肩右肩的状态非常差"）、2024-08-07 澳元对美元（"头肩有点太离谱了"）。
   - **条件**：品种库筛选流程；与一票否决#1 通道感无直接关系，属头肩专项。

## 三、平台位置、测试次数与过高点（复现 + 大幅细化）

1. **结论**：平台位测试离得近的两次不能当作两次测试（"很难算"）；想凑第三次 → 平台位有瑕疵，可接受但等待时间会久。
   - **依据**：2024-07-23（"这两次也不能把它当作测试"）、2024-07-26（"两次离得比较近，差一次"）、2024-07-29（"平台位上方这两次离的比较近"）。
   - **条件**：平台位测试计数；与周会"离得近的算一次"一致。

2. **结论**：过高点尽量不把它当作测试点（"一般过高点的地方我们尽量的不把它当做测试点"）。
   - **依据**：2024-07-31 棉花期货（"这里别过了高点……一次要两次，所以这里别把它算做第三次"）。
   - **条件**：测试计数规则；宁可少算不可多算。

3. **结论**：中间过高点 → 一般"把它断掉"——从过高点处开始单独形成一个独立结构，前面不算它；直接冲上去不愿介入（只能当近似结构、不能当特别好的轮廓）。
   - **依据**：2024-07-25（"这种过高点不是那我们需要的……就不在我们的这个能接受的范畴之内"）、2024-08-01（"你没有办法当做一个特别好的轮廓"）。
   - **条件**：过高点处理标准做法；过高点=稍稍破位后马上下来、过度了。

4. **结论**：过了平台位置（中间过高点）→ 严谨起见后面需要对这个平台位置反复测试，且调整结构要出现，才能继续关注。
   - **依据**：2024-07-29（"严谨一点它需要反复测试"）、2024-08-05/08-06/08-07（工业规、螺纹、热卷等案例"过高点之后要对于这里反复测试"）。
   - **条件**：过平台后的关注门槛；反复测试=补足过高点消耗。

5. **结论**：平台位"分节"——一部分在这个平台上面、一部分在另外一个平台上面、完全不在同一个平台位置 → 放一放。
   - **依据**：2024-08-07（"完全不在同样的一个平台上面"）、2024-07-30（"别看筹码集中度在这里有，但是不是在一个平台位置上面……这种轮廓其实我们不是很喜欢的"）。
   - **条件**：平台位识别；筹码集中性≠平台位，必须同一水平。

6. **结论**：测试次数与调整结构联动：把某次测试当作第三次 → 后面调整结构（横盘）要出来才能关注；缺一次测试 → 要向上测试一下，时间等待久一点。
   - **依据**：2024-08-02（"直接统一区间往上走少一次测试……时间上面要等待的再久一点"）、2024-07-26/07-31 多次。
   - **条件**：平台位评级流程；测试次数够=锚定，但进入动作仍需调整结构。

## 四、独立结构与轮廓

1. **结论**：特别大的结构 → 轮廓一般都会比较差（大结构级别与好轮廓难兼得）；需要非常良好的筹码集中度横盘才可以关注。
   - **依据**：2024-07-25（"轮廓比较大的结构级别比较大的轮廓都会差一些"）、2024-07-30（"结构级别非常大的状态，一般来讲轮廓瑕疵都是比较严重的"）、2024-08-05（"特别大的结构我们往往说大的结构轮廓一般都会比较差"）。
   - **条件**：大结构品种的处理；宁可从中间某位置单独分割出独立结构（08-08 同理）。

2. **结论**：POC 想做的话，后面的独立结构要常规（"长得很奇怪所以这个不会这样做的，最起码独立结构是一个常规的结构"）。
   - **依据**：2024-07-25 成交量分布状态好但结构奇怪案例。
   - **条件**：POC 品种筛选；结构常规性先于成交量分布。

3. **结论**：加密市场几乎不用成交量分布图——成交量不准（只统计交易所内部），且 POC 必须先观察价格行为层面上的筹码集中区、再用成交量分布图验证；没有筹码集中区=完全不成立。
   - **依据**：2024-07-29 原话（"加密市场上面我们其实很少用这个成交量分布图……周会我们刚刚说完"）。
   - **条件**：POC 使用边界；与周会下知识卡"加密/OTC 几乎不用 POC"完全一致（本批为扫盘实演）。

## 五、动能、收线与进场细节

1. **结论**：直接往上冲/直接突破不做——需要行情有一个往下走的动作（回踩轨迹/依托下踩）；"横着上不做"。
   - **依据**：2024-08-02（"直接往上走我们是不做的，因为它没有所谓的回踩的这种轨迹……这种轨迹的细节我们强调过很多遍"）、2024-08-07 依托（"要这样横着上不做，不下来做统一区间"）。
   - **条件**：所有向上进场（标准/回踩/依托通用）；与周会"向下踩轨迹必须存在"一致。

2. **结论**：K 线收线规则——收完线之后才能定论（"收完线之后一定是不会进行关注的"）；收线要收完整、不出长上影才可做 1/2R（"第二根稍微的有点动能，收就收完，不要出什么长上影……可以做二分之一"）。
   - **依据**：2024-08-05（通道感+收线）、2024-07-31（"这根收的太模糊了"）。
   - **条件**：进场确认时点；上影线=上方卖盘压力（与种子卡条件性排除#6 一致）。

3. **结论**：动能与推进形式——喜欢"横盘整理充分后坚决往上冲/统一区间后坚决动能"；不喜欢"一点点蹭上去"；动能没出来只能等回踩。
   - **依据**：2024-07-23（"上去稍有些横盘然后快速的往下跌落，动能要足一点"）、2024-08-01（"慢慢往上蹭不做，下来做统一区间然后往上冲击"、"动能没出来比较可惜，只能去关注回踩"）。
   - **条件**：进场形式筛选；前面有对家（压力）时动能要求更高（07-23"对动能的要求稍微高一点"）。

4. **结论**：动能特别好时可以突破常规——棉花缺横盘直接往下走，但动能还可以 → 比较激进的话可以做 2 分 1R（0.5R）关注。
   - **依据**：2024-08-06 棉花期货（"比较激进的话我认为2分1R可以去关注一下"）。
   - **条件**：激进 1/2R 决策；仅动能强、其他条件缺时；与周会"补充计划一律 1/2R"一致。

5. **结论**：回踩力度要求——回踩下行动能太强先放一放，力度偏缓比较喜欢；回踩陡峭程度高对细节要求太严格。
   - **依据**：2024-07-31（"回踩如果这个下跌动能太强的话尽量的先放一放，下跌动能如果比较平缓还可以"）、2024-08-02（"回踩的力度偏缓是我们比较喜欢的"）。
   - **条件**：回踩交易筛选；下踩过陡=特征性不可读。

## 六、经验型启用示范（种子卡没有的实战决策层）

1. **结论**：统一区间不足（只有两根、小K线牵强）+ 平台位不错 + 轮廓中规中矩 + 动能非常强 + 环境中性（不属于绝对右上角，无优势无劣势）→ 补充计划启用经验型做二分之一。
   - **依据**：2024-07-31（"统一区间其实是不符合条件的……只能说用经验型……平台位很不错……动能是非常强，补充计划，我觉得启用经验型做个二分之一倒是可以的"）。
   - **条件**：经验型三入口之一（统一区间少 1-2 根）+ 动能与环境兜底；须注明"这是经验型"。

2. **结论**：动能不错但前面没有统一区间、且和震荡环境"差得太远" → 不太会启用经验型；没有关注就等待回踩。
   - **依据**：2024-07-31（"前面这个地方没有统一区间……因为这个差得太远了，这个我不太会启用经验型的"）。
   - **条件**：经验型启用边界；不是所有条件不足都配经验型，差距太大不启用。

3. **结论**：统一区间两根、后面慢慢往上走稍微差一点 → 若动能非常好（直接动能收到位）可以前半仓二分之一。
   - **依据**：2024-07-30（"统一区间差的，因为没到这个四根就两根……如果动能非常好……键前走二分之一"）。
   - **条件**：经验型仓位；仍为 1/2R 封顶。

## 七、环境分级判断（右上角/右下角/常规）

1. **结论**：环境分级处理——常规上涨后回调出现的平台位 = 没问题；右下角状态 → 轮廓要走得更好一点才能关注；右上角状态 → 不太喜欢（尤其做回踩偏激进）。
   - **依据**：2024-07-30（"如果是一个常规的上涨之后稍微的回调……那没有问题；如果是一个右下角的状态就需要注意一下""如果是一个右上角的状态其实我不太喜欢"）。
   - **条件**：环境判断；与周会下"右下角/右上角要么结构级别足够大要么轮廓足够好"一致。

2. **结论**：不是绝对右上角但行情之前冲得比较高 → 多头也要调整时间久一点才关注。
   - **依据**：2024-07-31 英镑对澳元（"虽然不是那种绝对右上角但是毕竟行情之前冲的是比较高的一个位置"）。
   - **条件**：高位平台品种；冲高位置=调整时间要求提高。

3. **结论**：横走之后突然下跌的"棱角轨迹"——从经验角度市场环境不是特别好；除非结构级别非常大（可做二分之一），否则要等一等。
   - **依据**：2024-07-29（"上来之后横着走，然后突然下跌……这种图形表现看起来会稍微的有些奇怪"）。
   - **条件**：经验判断（存疑——属老师经验层，未给量化标准；与"结构级别非常大=1/2R"组合出现）。

4. **结论**：市场恐慌/不确定性高的时期（如 2024-08 初美联储降息太慢的担忧蔓延、美股急坠）——任何市场环境都要经历、该等待就耐心等待；不因恐慌改变结构等待逻辑。
   - **依据**：2024-08-06（"任何的市场环境我们都要经历……该等待的时候就耐心等待"）、2024-08-05（急坠现象）。
   - **条件**：宏观情绪期心态；时效性信息（2024-08 时点）。

## 八、拐点（平仓专用，本批实演强化）

1. **结论**：拐点迹象只用于平仓、绝不用于进场——看到拐点直接进不行：拐点可能形成阶段性低点，但不代表多头有空间（可能震荡出不来空间没利润）；微型反转是市场的少数。
   - **依据**：2024-08-05（"我们识别拐点是对于平仓来讲的……不会直接的去用拐点来进场"）、2024-08-07（"我们不是说看到拐点就直接进……它有可能形成阶段性低点，但是它不一定代表着多头就有空间"）。
   - **条件**：拐点用法；开空未到指引点出现拐点可考虑平仓（08-07"假设你之前开了一些空单……出现了拐点，那这个时候你可以考虑平仓"）。

2. **结论**：急坠之后大量品种形成拐点（加密 2024-08-06/07 案例：急坠 → 短时间大幅波动 → 反向反馈 = 起稳），但"等结构出现"而非直接关注。
   - **依据**：2024-08-06（"比特币……现在有一定的企稳，那么后面还是等结构"）、2024-08-07（"昨天形成拐点还很多……但是很多品种都处在同样的这个状态……等等结构"）。
   - **条件**：市场急跌后处理；与周会下知识卡拐点四条件一致。

## 九、特殊排除/放一放规则（对照种子卡）

1. **结论**：陡峭下跌（含跳空低开）之后直接承接窄幅整理 → 这种状态不做/放一放；除非承接的不只是窄幅整理（相对好一些），或重新回踩测试。
   - **依据**：2024-07-30 Nekki（"跳空低开就相当于一个陡角下跌……如果仍然是保持窄幅整理直接突破我们先放一放"）、2024-08-05（"如果直接承接窄幅整理呢，这种状态我们是不做的"）、2024-08-07（"快速陡峭下跌……窄幅整理我们肯定不关注"）。
   - **条件**：**新增排除规则**（种子卡无此条）；陡峭下跌后窄幅整理=动能未释放干净，直接突破不可信。

2. **结论**：一字型排列——整个都是一字型（前面没有调整）→ 不关注；如果前面就有调整、慢慢慢慢进入到一字型 → 可以。
   - **依据**：2024-07-25（"他们一字型整个都是一字型……比如说他前面就有调整，然后慢慢慢慢进入到一字型那可以"）。
   - **条件**：种子卡一票否决#5 复现 + **细化例外**（前面有调整慢慢进入一字型可接受）。

3. **结论**：ST 品种一定不会筛进品种库——长期做万一哪天跳空低开大幅低开跳过止损，不确定风险太高。

## 本批新增量总结（种子卡没有的新知识）
