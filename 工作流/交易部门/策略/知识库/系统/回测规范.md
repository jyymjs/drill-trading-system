# 回测时间取值规范

> 2026-08-11 老板拍板建立（R-048/R-049 数据支撑）。本规范定义"回测该取多长、结论以哪段为准"，防止跨报告口径不一致。
> 时效：2026-08 生效；数据来源：R-048（比例网格）、R-049（时间窗稳健性）、R-050（档位扩展与归因）报告（`产出/输出/报告/`）。

## 定位

- 回测结论分两类口径，各配一个主时间窗（结论 + 依据 + 条件，三元组）
- 高档位（风险比例 ≥0.020）相关结论**必须同时呈现 26 年与近 7 年两口径**——单一口径会误导（见条款 2 依据）

## 条款

### 1. 信号层结论 → 26 年全量主口径

- **结论**：信号质量/评级/条件类结论（avgR、胜率、条件对比等）以 26 年全量（2001~2026，19 个有效年份）为主口径。
- **依据**：R-049 起始点敏感性——2000/2005/2010 起点结论等价（信号差 <5 笔），2015 起起点收益数值变化但 avgR/回撤稳定；26 年样本最足（4,351 笔信号 / 1,144 笔触发）。
- **条件**：2002-2008 空窗（信号为零）不参与统计；空窗段不跑引擎。

### 2. 资金层结论 → 近 3 年主口径 + 近 7 年复验（强制双口径）

- **结论**：资金利用/可执行性/回撤压力类结论以近 3 年（2023~）为主口径，近 7 年（2019~）必须复验并同表呈现。
- **依据**：R-048 拐点实证——风险比例 0.020/0.025 档在 30k+ 资金近 7 年回撤 -22.6%~-31.6%（超 -20% 警示线），而 26 年口径同档仅 ≤-16.1%；R-043 已知近 7 年含 2020 疫情段回撤 -13.9%。**回撤压力在近 7 年最真实**。
- **条件**：比例 ≥0.020 的档位结论缺近 7 年口径 = 不合格呈现；资金层结论引用必须注明时间窗。

### 3. 报告标配 → 信号年度分布 + 宏观周期标注

- **结论**：所有回测报告必须附信号年度分布（空窗可视化）+ 当期宏观周期标注（牛/熊/震荡交易日占比）。
- **依据**：R-049 宏观归因——熊市占比与信号层 avgR 负相关（w2010 熊 70% avgR 0.119 → w2019 牛 50% avgR 0.334）；26 年全景牛 43%/熊 47%/震荡 10%。弱段先归因宏观再谈策略。
- **条件**：宏观标注用上证指数 MA20/60/120 无前视判定（`项目/回测系统/market_regime.py`），信号日 T 只用 ≤T 数据。

### 4. 起始点规则 → <2015 不作参数级结论

- **结论**：起始点 <2015 的回测结果仅作全量等价性旁证，参数级结论（比例/条件阈值定案）以 2015+ 起点为准。
- **依据**：R-049——2002-2008 空窗 + 早期（2010-2014 仅 178 笔）信号稀疏；早期制度差异（涨跌停 10% 时代）。
- **条件**：旁证用途须标注"早期制度差异 + 空窗结构"。

### 5. 档位探顶/失控点结论（R-048/R-050 沉淀）

- **结论**：风险比例档位结论以"顶点（收益回撤比首次回落）+ 失控点（近 7 年回撤破 -20% 最小比例）+ 错过成本（资金不足错过集质量）"三维度呈现，分资金档给建议区间。
- **依据**：R-048 主网格（26 年 DDR 单调上升 0.025 未探顶、近 7 年高档回撤放大）+ R-050 扩展档位（26 年 0.030~0.040 平台无顶、**近 7 年 30k+ 资金 0.016 起全部破线、安全上界 = 现行 0.025（V4 更新，R-050 定案 0.025 且 8401 档近 7 年 -16.3% 安全）**；8401 档安全上界 0.018、0.020~0.022 非单调破线——历史口径，R-050 定案后以 0.025 为现行）。
- **错过成本数据（R-050 debug 精确集，2026-08-11 更正）**：资金不足错过集 avgR 0.581~0.858（低于成交集——错过以弱股票为主，错过损失估算最高 1.2 万元/26 年@0.025）；超限拒集 avgR 0.982~1.779（高于成交集——每股风险上限挡掉的是好股票）。原"35 笔 avgR 1.632 全部强势股"表述作废（系超限/资金不足混合体）。
- **条件**：档位建议区间 = [现行 0.025, min(顶点, 失控点内安全档)]，分 8401/30k/50k/100k 四档分别给出；禁止单一比例横跨所有资金档定案；高档位（≥0.016）结论必须附近 7 年口径（条款 2）。

## 边界

- 本规范只管"时间取值与口径呈现"，不管策略参数本身（参数调整仍走人格链 + 老板书面同意）
- 与时效权重原则（知识冲突按最新教学）不冲突：本规范是"方法论口径"，时效权重是"知识裁决原则"
