## 一、核心框架：复盘三支柱

**指数（大盘定仓位）→ 板块（找资金方向）→ 短线情绪（赚钱效应）→ 三者撮合出当日结论**

### 支柱 1：指数

- **多指数同列**：上证/深成/创业板/科创/平均股价，第一件事看分时图走势是否一致
- 防「**失增**」（指数背离）：上证涨但深成/创业板/平均股价跌 = 赚指数不赚钱，资金扎堆权重股
- **周期递进**：分时 → 5分钟 → 15分钟 → 30分钟 → 60分钟 → 日线，逐级检查：
  - 各级走势是否同步（同步上涨/下跌/横盘）
  - 是否顶到压力位（多指数同时顶压力 = 大概率调整）
  - 60分钟看趋势突破（如突破下跌趋势后拉伸回踩，可能做底部形态）
- **日线定大周期**：上涨周期 → 仓位配置重；下降周期 → 仓位轻
- 金句：**「大盘决定了你的仓位，个股决定了你的买卖」**——仓位跟随市场行情好坏配置，买卖看个股/板块是否启动

### 支柱 2：板块

- **上涨板块**：看产业链效应（如化工原料/有机硅/碳基材料同时涨 = 资金切入化工产业链）→ 找产业链「第一位」（距离压力位还有空间的个股）次日做低吸
- **延续性**：昨天涨的今天是否延续；涨幅榜一天全换 = 高速轮动（一天一轮动）→ **只能埋伏低吸，不能追涨**
- **下跌板块**：看是否产业链批量杀跌
  - **低位**批量杀跌 + 量能正常 = 正常调整（调整完还会走）
  - **高位**（已拉升一大波）大阴线 + 全产业链躺跌幅榜 = **集体出逃，千万别做**
- **金融板块（银行/证券/保险）核心作用 = 稳定指数**：「权重股搭台，题材股唱戏」——指数稳了题材资金才敢做
  - 三者常呈**翘翘板轮动**顶指数（银行保险止跌时证券调整，证券走强时银保调整）

### 支柱 3：短线情绪

- 当日看：上涨家数 vs 下跌家数；涨幅>5% vs 跌幅>5%（赚钱效应）；**跌停家数对比前一天**（最重要，跌停增加=赚钱效应变弱）
- **连板天梯**：
  - **高度**：最高板数是否持续走高 / 被压制（如昨天最高6板今天4板 = 空间被压制 → 情绪可能走弱、资金切换蓝筹）
  - **厚度**：二板/三板/四板梯队数量（如「226 结构」= 4板2家3板2家2板6家）
    - 厚（如四板4+/三板6+/二板8+）= 有替补、晋级概率大，做高度
    - 薄（四板1家三板1家二板2-3家）= 情绪极差，短线没法做
  - 高度被压制 → 资金只能做低位 → 超短只能做首板；梯队厚 → 切换做高度

### 结论撮合

三者共性是**资金**：短线情绪差 + 板块无延续性 + 指数周期向下 → 市场偏弱、次日调整概率大 → 操作防守降仓位。熟练后**半小时内复盘完**（"八九不离十"判断次日走势）。

## 二、与钻潜体系的对照与可借鉴点

| 视频内容 | 钻潜现状 | 借鉴价值 |
|---|---|---|
| 多指数同列防失增（环境一致性） | 有「市场环境」概念但无指数数据监控 | **高**：环境好坏数据化 |
| 大盘定仓位（周期→仓位映射） | 风控/仓位管理已存在 | **中高**：指数周期→仓位系数 |
| 产业链批量杀跌：低位=调整/高位=出逃 | SF 释放级别概念共通（积累 vs 释放） | **中**：互相验证 |
| 连板天梯高度/厚度 | 趋势跟踪/波段体系，非打板 | 低（可作环境参考） |
| 流水线化复盘流程 | 数据基础（pytdx 指数接口可用） | **最高**：可代码化「自动化市场环境复盘」 |
