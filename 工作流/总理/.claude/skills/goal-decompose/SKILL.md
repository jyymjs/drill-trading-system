# 目标分解

## 触发

"我的目标""规划""里程碑""三年/五年""想成为什么样的人"

## 工作流程

```
① 锚定目标   理解目标 → 写入身份档案"长期目标"（先确认）
② 拆解      按时间轴：目标 → 年度里程碑(3-5个) → 季度关键动作 → 本月第一步
③ 关联资产   目标涉及的资产/工作流（交易/学习/项目）标出
④ 落地      近期可执行项 → 事项档案（P-编号）或待办档案；里程碑 → 关系/事项档案
⑤ 维护      季度复盘时对照里程碑（配合复盘引导技能）
```

## 拆解格式

```markdown
🎯 目标：<目标描述>（确认后入身份档案）
├─ 2026年：里程碑 M1/M2/M3
├─ 本季度：关键动作 Q1/Q2
└─ 本月第一步：<具体可执行项> → 已入事项档案 P-0XX
关联资产：交易部 / 学习部 / …（对应里程碑标记）
```

## 季初拆解流程（机制内调用，R-003）

**何时触发**：季初月（8/11/2/5 月）第一次对话，月体检环节带出"本季度该拆解了"提示后启动；老板当日不想做 → 记待办延后，不强制。

**流程**：
1. 读身份档案"长期目标"（定稿口径）→ 读事项档案 P-002 上季度小结（若有）
2. 年度 → 拆出**季度关键动作 3-5 个**（可验证、可月度核对）
3. 从季度关键动作中定**本月第一步**（具体可执行项）
4. 输出季度目标卡（格式见下）→ 老板确认后落地

**落地**：
- 季度关键动作 → 写入 P-002 对应季度段（事项档案「P-002 季度进度」）
- 本月第一步 → 入待办档案（按待办池规则：老板查看详情+明确拍板后才进执行队列）
- 季度口径对齐年度：2026-08 → 2027-08 拆 4 段（08-10 / 11-01 / 02-04 / 05-07）

**季度目标卡输出格式**：

```markdown
🎯 季度目标卡 · <段名，如 2026-08→2026-10>（季初拆解日 <日期>）
├─ 年度目标（身份档案定稿口径）：主线 / 副线 / 资金纪律
├─ 本季关键动作（3-5 个，写 P-002 季度进度）：
│   Q1：<可验证动作>
│   Q2：<可验证动作>
│   Q3：<可验证动作>
└─ 本月第一步（入待办档案，老板拍板后进执行队列）：<具体可执行项>
```

## 目标采集确认门槛（R-003，防失真）

- **随口讨论 ≠ 目标变更**：对话中出现长期方向性陈述（收入目标、职业规划、愿景类）→ 先按记忆判定矩阵处理（"决定+理由"必确认），**老板明确表态后才写入身份档案**；低置信度先确认再写
- **变更流程**：目标口径/期限任何变更 → 决定档案记变更（新旧并列、变更原因、日期；旧条目标"已作废被替代"）+ 身份档案同步更新；未拍板不记
- 拆解、对标、排序等例行环节不触发采集确认，只有目标本身变化才走门槛

## 注意

- 目标必须可验证（否则拆不到行动）——帮老板把它说具体
- 冲突检测：新目标与既有在办事项冲突时，提示取舍（配合决策权衡）
