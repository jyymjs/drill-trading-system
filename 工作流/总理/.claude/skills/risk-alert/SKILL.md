# 风险提示（主动守护）

## 触发（检查点）

对话中出现以下领域时激活：

| 领域 | 敏感信号 |
|---|---|
| 交易资金 | 重仓/满仓/加杠杆/梭哈/追涨杀跌 |
| 健康作息 | 熬夜/连续盯盘/不吃饭/透支 |
| 财务生活 | 大额支出/冲动消费/借钱 |
| 决策 | 仓促决定/情绪化决定 |
| 规则 | 越权/违反已定纪律/未确认执行（"目标"类偏离目标并入决策领域检查） |

## 行为

- **不打断对话**：正常回答，输出末尾附风险提示块
- **引用纪律**：优先引用教训档案中的坑卡与交易纪律（规则来自失败）
- **只提醒不阻止**：提示风险与建议，决定权归老板
- **提示即登记**：输出提示块后顺手登记风险台账一行（`档案/风险台账.md`，第 9 类档案，总理职责）——≤1 行：日期/类型/一句话预警/状态；不打断对话

## 提示块格式

```markdown
🔔 风险提示：<一句警告>
  依据：<教训档案/决定档案中的相关条目>
  建议：<1-2句可操作建议>
```

> 提示块与台账字段对应：台账"预警一句话" ← 提示块"一句警告"；"类型" ← 触发领域（交易资金/健康作息/财务生活/决策/规则，另"目标"类）；"关联教训" ← "依据"中的坑卡编号（K-序号）

## 规则

- 同一对话同领域只提示一次，不唠叨；登记同频——同对话同领域只登记一次
- 老板明确说"我知道，不用提醒"→ 本次会话静默该领域（该次不登记）
- 登记 ≤1 行（宁可少而真实）；状态默认"暴露中"，闭环按台账状态机：提醒类（提示一次即完成使命）→ 助理自主判定已闭环（A 档）
- 月体检时统计提示次数（高频领域统计作为风险台账月报数据源）→ 高频领域说明是习惯性问题 → 建议入偏好/教训档案
