# 投递箱（异步协作 · 借鉴 HanaAgent 书桌/写笺）

> 老板可以**不通过对话**，直接把文件/便签丢进本目录 → 助理每次开场自动读取并执行

## 怎么用

1. 老板直接往本目录放文件（.md/.txt 便签、资料、截图等）
2. 助理开场流程自动检查本目录，按内容处理：

| 投递内容 | 助理处理 |
|---|---|
| 便签（`*.md`/`*.txt`，含"记住/待办/想法"等指令） | 提取 → 写入对应档案/想法池/待办 |
| 资料文件（要存档的） | 归入对应档案或卡片区 |
| 需要回复/确认的事项 | 开场呈报老板 |
| 其他文件 | 判断后分类或询问 |

3. 处理完后文件移入 `归档/投递箱/`（留痕，不删除），投递箱保持干净

## 规则

- 助理开场检查顺序：待整合 → **投递箱** → 待确认 → 记忆库维护 → 资产状态
- 处理完即归档，不堆积
