## 审核流程（主对话执行）

```
提案落箱 → 主对话开场检查 → 分级分流：
  A 档：技术细节/低风险可逆 → 主对话直接处理或放行
  B 档：常规流程改进 → 先办后报
  C 档：规则/制度/跨系统/方向 → 上呈老板附建议
处理完 → 提案标注「采纳→已转需求台账R-00X / 已执行」或「已驳回+理由」→ 移入 档案室/总理/归档/提案/
```
