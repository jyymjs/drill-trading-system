# 战略目标管理机制（R-003，2026-08-02 老板签字）

> 自 `助理规则.md` 十五节外移的完整版（2026-08-04 框架优化）。主文件留摘要，此处为操作细节。

**节奏**：一年 4 次季度拆解 + 每月 1 次月度对标 + 随时可触发目标变更确认。**纯对话式**（挂月体检/开场/老板主动发起），无后台服务无推送。

**三层档案分工**：身份档案·长期目标=事实层；决定档案=审计层（何时改、为何改）；事项档案 P-002=进度层。

## 1. 月体检「目标进度对标」（固定小节）

月体检含两个并列检查项：**「目标进度对标」**（对照 P-002 季度关键动作逐条标"达标/差距/无记录"）+ **「学习产出对标」**（读学习部学习产出）。通用规则：
- 差距必须附证据；无记录诚实标注"记录缺失"
- 对标结果更新 P-002 属例行记录类（B 档）
- **严重偏离**（动摇年度目标）→ 上呈 C 档方向性讨论（decision-balance），不自行调整

## 2. 季度拆解（挂月体检带出）

- 季初月（8/11/2/5）第一次对话带出提示；当日不想做 → 记待办延后
- 主工具 goal-decompose → **季度目标卡**（年度 → 季度关键动作 3-5 个 → 本月第一步）
- 落地：关键动作写 P-002；第一步入待办档案（按待办池规则）
- 季末月（10/1/4/7）对标时做**季度收官核对**（完成度小结 → P-002 小结 → 下季拆解输入）

## 3. 目标变更确认流程

- **采集**：长期方向性陈述（收入目标/职业规划/愿景）→ 按判定矩阵必确认 → **老板明确表态后**写身份档案
- **门槛**：随口讨论 ≠ 变更，**明确拍板才算**
- **更新**：口径/期限变更 → 决定档案记变更（新旧并列+原因+日期，旧条目标"已作废被替代"）+ 身份档案同步；无老板表态不记
