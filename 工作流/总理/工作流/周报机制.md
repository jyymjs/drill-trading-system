# 周报机制（2026-08-06 老板拍板建立）

> 定位：周度统一呈报载体——错误台账处理结果（老板 2026-08-06 授权：助理自主处理，结果周报统一呈报）+ 任务/交易/风险全景。
> 关联：日报（助理规则第七节）、月体检（每月首次对话）、错误台账（`档案室/总理/档案/错误台账.md`）。

## 触发与时机

- **固定**：每周六输出一期（周五收盘后数据完整；老板夜班作息，周六 16:00 后对话即呈）——**执行机制：开场流程第 10 条"周六且本期未出→出周报"**；错过周六（多日未对话）→ 下次对话补出并注明"补期"
- **手动**：老板说"助理，周报"随时出
- 存档：`档案室/总理/档案/周报/周报-YYYY-Www.md`（ISO 周编号）

## 板块（5 块）

| 板块 | 内容 | 数据源 |
|---|---|---|
| 1️⃣ 本周任务 | 办结（周内合并/完成）、新增待办、下周计划 | 待办档案、git log |
| 2️⃣ 错误台账 | 本周处理了什么、**不处理的原因**、**需老板决策的上报项**（2026-08-06 老板定） | 错误台账 |
| 3️⃣ 交易系统进展 | 策略/实验/扫描/回测进展（白话结论 + 关键数字） | 产出报告、注册表 |
| 4️⃣ 风险台账 | 本周登记风险项 + 状态 | 风险台账 |
| 5️⃣ 想法池 | 数量 + 本周新增想法（列表） | 想法池 |

## 模板

```markdown
# 周报 · Www（YYYY-MM-DD ~ YYYY-MM-DD）

## 1️⃣ 本周任务
- ✅ 办结：…
- 📋 新增待办：…
- 🗓 下周计划：…

## 2️⃣ 错误台账处理（助理自主处理，周报呈报）
- ✅ 已处理：E-0XX …（结果）
- ⏸ 不处理：E-0XX …（原因）
- 📨 需老板决策/处理不了：E-0XX …

## 3️⃣ 交易系统进展
- 策略/实验/数据（白话 3-5 条 + 关键数字）

## 4️⃣ 风险台账
- 本周登记：…（状态）

## 5️⃣ 想法池
- N 个搁置；新增：…
```

## 纪律

- 错误台账处理照常及时做，**不逐条打扰**，周报统一呈报（2026-08-06 老板拍板）
- 不处理必须说明原因；处理不了/需决策的注明上报
- 周报与日报不重复：日报=当日快照，周报=周度全景
