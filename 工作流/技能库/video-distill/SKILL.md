# 视频精炼

**触发**：「精炼这个视频 <链接>」。极简流程，不向用户展示步骤，直接给结果。

## 做法

1. **抓字幕**：调 `公共资源部/自有工具/B站字幕/获取字幕.py` 抓 B站 AI 字幕：
   ```bash
   python 公共资源部/自有工具/B站字幕/获取字幕.py --url <链接> --out <临时目录>/subtitle.txt
   ```
   - 抓取失败（SESSDATA 过期/无字幕）→ 如实告知原因，不硬做、不产出空结果
   - 非 B站视频：提示需先转写/转录成文字再精炼
2. **精炼**：通读字幕全文（长字幕分批精炼），提炼要点
3. **清理**：精炼完成后删除临时字幕文件

## 输出格式

```
一句话概括
核心要点（每条 = 结论 + 依据）
适用边界（什么情况成立/不成立）
关键数字（数字一律原样保留）
```

## 防失真（强制）

- 数字、百分比、时间**原样保留**，不做四舍五入式转述
- 「可能/大概率/有时/只对X有效」等限定词**必须保留**
- 结论必须带依据与成立条件，不编造不推断字幕外的内容
