# 公共资源部（全公司工具中枢）

本部门继承 `deepseek/` 根级工程框架（`../工程部门/`）。

## 部门定位（2026-08-03 老板拍板）

**一切工具类功能全部归本部门**——脚本、工具、CLI、可复用服务统一由本部门管理：
- 其他部门需要工具支持时，**直接搜索本部门调用**，不自行开发重复工具
- 确实需要新工具 → 由本部门开发/入驻
- 例外：业务部门工作流内嵌的专用脚本（如交易部扫描器/评级）属业务部门资产，不强制迁移，但需在本部门"工具清单"登记

## 工具登记规范（每个工具必须注明功能）

- 每个工具目录自带 `README.md`：**功能 / 用法 / 依赖 / 调用示例**
- 命名清晰可辨（从名字能看出功能）
- 新工具入驻 → 更新下方"工具清单"表
- 工具清单是全仓库工具的唯一索引——搜索工具 = 查工具清单

## 搜索调用机制

主对话（助理）/工程部/质检部/交易部门等需要工具时：
1. 查本文件"工具清单"（或搜索本部门目录）
2. 找到目标工具 → 按其 README 调用
3. 工具异常/缺失/需要新工具 → 唤醒**公共资源部经理**（`.claude/agents/公共资源部经理.md`）开发维护
