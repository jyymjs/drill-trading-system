## 背景与定位（用户明确）

- **系统定位**：独立运行的个人学习系统——**仅用户与 AI 直接对话完成学习**，无任何子 agent、无程序化对抗；数据归系统私有，不与外部项目共享
- **核心命题（用户强调）**：**提炼总结是系统命脉**——质量靠「过程防失真 → 产出分级 → 结果验证」三道防线
- **系统独立性（v2.5）**：与工程中枢**断开联动**（规划者不再自动启动本系统）；知识库**私有化**（移入本系统目录，仅本系统调用）
- **设计依据**：《AI学习方法/2026-08-01-AI学习新知识-学习闭环-方法建议书.md》7 项方法 + 全程用户拍板

## 系统形态（v2.5 定稿）

```
学习部 = 对话式学习 + 考问模式（仅用户与 AI，无任何子 agent）

【对话式学习】(标准模式)
输入(链接/需求/资料/书)
  ↓ 来源定位(不限条数:模型知识+外部抓取择优;找书走找书流程)
  ↓ 抓取入库(raw层) → AI分类命名
  ↓ 对话学习:
     AI 讲解(提炼五问+关键信息核对单防失真) → 主动质疑材料(夸大/漏洞/过时/边界)
     → 苏格拉底引导思考(讲完一要点先问后讲) → 盲区进错题卡 → 实时提炼"情境→行动"规则
  ↓ 知识接入(定位→对接→判定关系→落地,含关联字段互链=网状结构)
  ↓ 产出(笔记/建议书,由对话精华整理) → 索引维护

【考问模式】(用户主动触发,复习复盘)
「考考我 XX / 复盘 XX」→ AI 调知识卡+错题卡
  → 出题先问后答 → 产婆式追问自纠(连续2次卡壳给线索)
  → 防迎合批改(先挑错后认可) → 归因(我的提炼失真→修笔记 / 您的遗忘→错题卡)
  → 错题卡记推理断点,间隔重复 1/7/30,三次重建通过自动毕业清理
  → 可选费曼复盘(您讲课,AI 当严苛学生)
```

## 核心机制详述（v2.4 六问定案）

**① 苏格拉底引导（标准流程中的定位）**：对话式学习中 AI 每讲完一个要点，先向用户提问再讲下一个——激活旧知识（新知识挂到已懂知识上）、暴露真盲区（答不上来即进错题卡）、防被动灌输、调节学习节奏。与考问模式的区别：一个在过程中（先问后讲），一个在结果处（学完考）。

**② 过期/错误知识的清理与更新**：过期（时效性=短期且已失效）→ 标注"过时/已被替代"不删除；错误（发现勘误）→ 标注"勘误"+修正依据；两者均触发重学 → 新产出走接入协议"升级"关系覆盖。

**③ 矛盾知识点处理（冲突四步）**：识别（接入时对接/复盘时扫描）→ 分析各自适用条件 → 双方保留并互标"冲突，适用条件：…" → 特殊情形（一方明确过时→标"已被替代"；明确错误→标勘误；判定不了→留冲突区由用户裁决）。

**④ 复盘驱动下一次学习**：复盘发现的结构信号 = 学习需求（碎片≥5 无知识卡→系统学一次补全；未裁决冲突→学新内容裁决；短期知识卡过时→重学更新；活跃领域长期无更新→建议复习）。复盘报告产出"NEXT 清单"，用户自主决定学哪个 → 触发对话式学习 → 新产出走接入 → 下次复盘验证。闭环：复盘→发现断层→学习→接入→再验证。

**⑤ O6 回流接通**：分类规范已有"执行知识回流"规则（框架任务中产生的新知识回流知识库）但从未真正执行——"接通"= 让回流规则实际跑起来（任务产出知识时按 AI 分类+命名+元数据+索引规范入库）。v2.5 系统独立化后，回流口径改为：系统内学习/考问/拆书/复盘产出的知识全部按规范回流自身知识库。

**⑥ 错题卡毕业机制（自动清理）**：每道错题 1/7/30 三次间隔复习；每次通过 = 用户自己重建推理链成功（AI 只引导不提示）；三次全过 → AI 判定已掌握 → 自动从错题卡移除（标记"已掌握"归档）；任一次重建失败 → 停留/重新计间隔。防错题卡无限膨胀。

**⑦ 提炼保真（关键信息核对单，用户最关切的）**：
- 提炼前：把原文的 数字/专名/日期/条件/结论 抽成清单
- 提炼中：提炼五问（主张/依据/事实观点推论/适用条件/保真）+ 抗失真三查（数字原样/限定词保留/独立可读）
- 提炼后：逐项打勾核对——清单每项必须在知识点中找到，缺项回补
- 结果验证：考问归因（用户答错若归因于提炼失真 → 回去补笔记）
- 兜底：raw 全文保真 + 章节锚点（每条知识点标"第X章第X节"，任何压缩可回原文核对）
- 诚实边界：论述细节必然压缩；结论/依据/条件/数字/专名由核对单保证不丢

**⑧ 网状结构（知识接入的核心）**：每条产出元数据带 `关联:` 字段（相关主题/知识卡路径），跨主题补互链；调用协议升级为"四级检索 + 关联跳转"（可从关联主题进入）；检查器含关联字段完整性检查。树状库长出"边"，知识"接上去"而非"放进去"。

### 阶段二 · 协议与模板
**2. 来源质量筛选**：来源不限 5 条；外部来源按相关性+质量择优（宁缺毋滥）；模型训练知识直接参与、不占抓取数；来源如实标注。
- 验收：任意一次学习的来源清单含质量信号与可靠性说明

**3. 产出模板升级**：
- 笔记：核心要点 / 材料批判结论（夸大/漏洞/过时/边界）/ 对我的意义 / 验证计划（含闭卷复述）/ 规则卡（情境→行动）/ 元数据关联字段
- 建议书：来源质量标注 / 可靠性分级 / 争议裁决 / 回流计划 / 学习路线（可选）
- 知识卡：关联主题 + 认知增量记录（v1→v2 发生了什么）+ 版本号
- 验收：任一产出含全部必备章节；知识卡合并后版本与增量记录齐全

**4. 对话式学习协议**：讲解→质疑材料→苏格拉底引导（先问后讲）→规则提炼→盲区入错题卡；可靠性五级分级（一手数据/实证 > 学术理论 > 实操经验 > 自述传闻 > 待核实）。
- 验收：完整走一遍对话式学习，用户盲区如实进错题卡，产出含可靠性分级

**5. 考问模式**：出题先问后答 → 产婆式追问自纠（2 次卡壳给线索）→ 防迎合批改 → 归因（提炼失真→修笔记 / 遗忘→错题卡）→ 错题卡记推理断点 + 间隔重复 1/7/30 + **毕业机制自动清理**；可选费曼复盘。
- 验收：错题卡条目含推理断点与复习日期；三次通过自动移出；归因结论两类分明

**6. 知识接入协议**：五步接入（定位→对接→判定关系→落地→索引）；关联字段互链（网状结构）；冲突处理四步；陈旧规则淘汰；调用协议升级"四级检索+关联跳转"。
- 验收：新产出必带关系判定与关联字段；库里无静默矛盾并存

**7. 知识提炼技能**：提炼五问 + 抗失真三查 + **关键信息核对单**（前抽后核逐项打勾）+ 三元组格式（结论+依据+条件）；考问归因接入。
- 验收：抽查提炼产物——核对单每项都能在产物中找到，缺项已回补

**8. 资料库复盘协议**：四步（体检→盘点→整理→报告）；三原则（只标注不删除 / 重大决策用户拍板 / 复盘驱动下一轮学习——NEXT 清单）。
- 验收：复盘报告含体检结果+NEXT 清单；无未经确认的删除

**9. 学习闭环**：验证计划执行（学后应用验证）+ 回流接通（学习/考问/拆书/复盘产出全部按规范入库）。
- 验收：一次学习 → 验证计划 → 回流入库链路完整

**15. 找书下载**（脚本已建 `scripts/book/find_download.py` 并**完整验证**，**待签字生效**）：
- 内置渠道配置 **38 条**（2026-08 联网检索全部内置）：聚合大库 4（Anna's Archive/Z-Library/LibGen/Sci-Hub）、中文搜索聚合 8（鸠摩/熊猫/24h搜书/TheFuture/时宜/SaltyLeo/虫部落/书享家）、中文书库直存 5（知海/SoBooks/怀旧书库/电子课本网/微信读书）、合法公版 12（古登堡/Standard Ebooks/Obooko/Manybooks/Free-ebooks系/维基文库/Loyal Books/书格/中华古籍/台湾华文/港大/中大）、垂直专项 6（科学文库/码农书籍/半本书匠/幻梦轻小说/漫画迷/杂志）、其他 3（Olib/鹿鸣川/GitHub 开源书库）；时宜搜书/书享家域名待确认；镜像变动频繁，每次找书前 AI 先复核最新域名

- 验收：同名书场景下未确认不下载；下载文件类型校验通过；失败给出明确提示；连续失败 5 次自动淘汰且 list 不可见、成功一次复活；403 三次仅提示不淘汰
