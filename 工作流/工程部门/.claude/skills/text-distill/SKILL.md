# 文本精炼

**触发**：「精炼这个链接 <URL>」或「精炼这段文字 <文本>」。极简流程，不向用户展示步骤，直接给结果。

## 做法

1. **提取正文**：
   - **链接**：`requests` 获取页面 → `bs4` 解析 → 移除 `<script>/<style>`，取 `<p>`/`<h*>` 文本拼接（正文提取失败 → 提示并给出原因，不硬做）
   - **粘贴文本**：直接使用
2. **精炼**：通读全文（长文分批精炼），提炼要点

## 输出格式

```
一句话概括
核心要点（每条 = 结论 + 依据）
适用边界（什么情况成立/不成立）
关键数字（数字一律原样保留）
```

## 防失真（强制）

- 数字、百分比、时间**原样保留**，不做四舍五入式转述
- 「可能/大概率/有时/只对X有效」等限定词**必须保留**
- 结论必须带依据与成立条件，不编造不推断原文外的内容
