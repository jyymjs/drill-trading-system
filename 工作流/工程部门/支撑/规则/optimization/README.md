# 内审部规则产出目录

优化提案经用户确认后提炼出的规则、模式分析、经验沉淀存放在本目录。

- 只写**经确认**的产出（与「提案确认」流程配套）
- 每条产出标注：日期、触发（自动回顾 / /优化 / 用户指令）、关联规则号
- 变更同步记入 `docs/changelog.md`

## 季度固定开销体检（框架优化 2026-08-04 沉淀）

每季度复测框架固定上下文开销，对照验收基线（2026-08-04 建议书第七节）：

| 指标 | 基线（2026-08-04 达成后） | 目标 |
|---|---|---|
| 每会话固定上下文 | ≤16.5KB（优化后） | 维持 ≤16.5KB，超了查技能描述清单 |
| 技能描述清单 | ≤3KB（50 项精简后） | 新增技能描述 ≤80 字约定不破 |
| 单文件体量 | skill-creator ≤12KB / 助理规则 ≤20.4KB | 新增大文件（>15KB）须先评估拆解 |

复测方法：`wc -c` 各固定加载文件求和（用户级 CLAUDE.md + 项目链 + 双记忆索引 + 技能描述合计）。
