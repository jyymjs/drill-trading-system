# 组织架构（助理中心 · 2026-08-05 老板拍板 R-010）

> 单一来源文件（2026-08-04 框架优化）：各角色/部门 agent 文件**引用此处，不内联副本**。

## 架构

```
       老板（决策/签字权）
             ↓ 需求
    ┌────────┴────────┐
    │ 助理（主对话）    │ ← 业务+规划+调度一体，安排一切任务
    │ 业务/规划/台账/审核 │    记忆·待办·日报·想法池·问题台账
    └────────┬────────┘
    ┌────────┼─────────┐
    ▼        ▼         ▼
 工程部    质检部   工具 agent（需要时唤醒）
 编码施工   六轴验收  trader(交易)（learner 暂停 R-011）
 (子agent) (子agent) / 公共服务部经理(工具维护)
    └────────┴─────────┘
     资产库（按需调用，不常驻）
 交易部门/ 总理(业务资产)/ 优化部门(台账)（学习部清空 R-011）
 公共资源部/ 档案室/ 技能库/ 资料库
```

## 目录职责

| 目录 | 定位 | 说明 |
|---|---|---|
| **主对话** | 助理 | 业务（记忆/待办/日报/台账）+ 规划（拷问/拆解/派发）一体 |
| **工程部门/** | 工程框架 | 执行/测试（子 agent）+ 规则/脚本/模板；规划职能并入助理（2026-08-05） |
| **优化部门/** | 助理职能 | 问题台账/审计——由主对话执行（2026-08-05 并入助理，原内审部） |
| **总理/** | 助理业务资产 | 档案/待办/想法池/工作区/业务技能（8 个） |
| **交易部门/** | 交易资产 | 项目（回测/策略）+ 策略核心/知识库（trader 工具 agent） |
| **学习部/** | 学习资产 | ⚠️ **已清空（R-011 2026-08-05，待重新规划）** |
| **公共资源部/** | 工具中枢 | 工具清单+仓库（R9） |
| **档案室/** | 档案集中 | 按部门分类，禁止重复文件占用资源 |
| **技能库/** | 技能单一来源 | 18 工程技能（各部门 `.claude/skills` 指向此处）+ 总理 7 业务技能 |
| **资料库/** | 确认书/技术附录 | 按时间命名，按需调用不自动加载 |

## 协作方式

- 需要支持 → 主对话（助理）安排；需要编码/测试 → 工程部/质检部；深度业务 → 唤醒对应工具 agent
- 全部门产出直接呈报老板（无中转层）；签字权归老板
