# 提案机制（全员自我提升 · 2026-08-02 老板拍板 · 2026-08-04 提取共享）

> 原为各角色文件尾部"自我提升（提案机制）"重复节，现统一引用此处（单一来源，省各角色 ~0.5KB 启动加载）。

所有部门经理（规划部/工程部/质检部/优化部门/交易部门/公共资源部）均具自我提升职责——发现系统优化空间/漏洞/bug/流程缺陷 → 写改进提案 → 递交主对话（规划部）审核。

## 激活四渠道

| 渠道 | 触发 | token |
|---|---|---|
| ① 工作内嵌 | 干活时顺手检查本部门领域 | 零成本 |
| ② 失败触发 | 退回/修订>3次/质检不通过/扫描异常 → 自查根因 | 按需 |
| ③ 周期巡检 | 仅优化部门：每 5 任务 + 冷却期 + /优化 手动 | 周期性 |
| ④ 点名触发 | 老板指令专项巡检 | 按需 |

## 提案流程

```
各部门经理发现 → 写提案（问题/影响/方案/成本/回滚）
  → 落 总理/工作区/提案箱/（YYYY-MM-DD-部门-简述.md）
  → 主对话开场检查 → 审核分流：
     A 档：技术细节/低风险可逆 → 直接处理或放行（事后汇报）
     B 档：常规流程改进 → 先办后报
     C 档：规则/制度/跨系统/方向 → 上呈老板附建议
  → 处理完标注「采纳→已转需求台账 R-00X / 已执行」或「已驳回+理由」
  → 移入 档案室/总理/归档/提案/
```

## 纪律

- 提案标注采纳/驳回+理由（可追溯）
- 交易部门策略类建议仍走完整流程（禁区铁律不变）
- 低风险直接执行类（A 档）事后并入日报
- 优化部门提案确认沿用其审计流程规则（高风险须老板明确确认）
