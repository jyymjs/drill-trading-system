## 部门导航

| 部门 | 一句话说明 |
|---|---|
| 工程部门/ | 框架枢纽：规划/执行/测试/内审 + 规则/脚本/文档/模板 |
| 总理/ | 老板助理（业务层）：需求确认/记忆/通俗翻译/工作区 |
| 交易部门/ | 量化交易：项目（回测系统/策略系统）+ 策略核心/知识库 |
| 学习部/ | 私人老师，独立系统——不经过框架，主动要求才进 |
| 公共资源部/ | 工具中枢（R9）：一切工具归此，仓库只存清单不入资产 |
| 档案室/ | 全部门档案集中（按部门分类，禁止重复文件占用资源） |
| 技能库/ | 19 技能单一来源（各部门 `.claude/skills` junction 指向此处） |
| 资料库/ | 确认书/技术附录按时间命名，按需调用不自动加载 |

技能模块：`.claude/skills` → `工作流/技能库`（工程部门/交易部门/公共资源部/学习部/根级同指）

## 资源按需原则（2026-08-04 拍板）

- **不主动全量读**：角色/对话只加载本任务必要文件；文档写"按需读取"的（如 changelog、档案、资料库）一律先看指针，需要才读
- **指针式引用**：规则/提案机制/组织架构等共享文件，引用处只写路径+一句话，不复制全文
- **技能按需调用**：技能正文只在调用时加载（SKILL.md 描述已精简）
- **查资源先查清单**：工具找 `公共资源部/CLAUDE.md` 工具清单；资料找 `资料库/`；档案找 `档案室/`——不漫游目录
