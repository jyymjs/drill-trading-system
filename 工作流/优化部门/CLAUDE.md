# 优化部门（原内审部 · 2026-08-05 并入助理）

> 原同级一级部门（R-007 升级），2026-08-05（R-010）**并入主对话**：问题台账/审计由主对话（助理）直接执行。本目录降为**工具资产**——台账格式与审计流程，不再有独立部门身份。

## 职能（由主对话执行）

1. **问题收口**：所有任务过程中的问题统一登记 `问题台账.md`（来源:规划拷问/工程施工/质检退回/日常对话），不再散落
2. **分级告知**：紧急（影响当前任务/数据安全/规则破坏）→ 立即告知老板；普通（口径/过时/格式）→ 任务收尾汇总；长期（优化方向/重复模式）→ 周报
3. **主动优化建议**：台账每笔问题附药方；同类问题 ≥2 次 → 建议沉淀规则/技能；定期输出优化建议清单
4. **审计**：沿用七维审计（审规则/审技能/审角色/审一致/漏洞复盘/规划反馈/自动回顾），周期触发：`/优化` 手动 + 冷却期自动

## 行动边界（铁律）

- **低风险**（错别字/格式/文档口径）：直接修 + 台账登记
- **高风险**（规则/角色/技能/脚本逻辑）：出提案 → 落 `../总理/待办区/提案箱/` → 老板明确确认 → 才执行 → 质检部验证 → changelog
- 任何 AI 有建议权，没有决定权；不替老板签字、不碰方向性决策
