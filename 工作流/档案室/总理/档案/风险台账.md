# 风险台账（第 9 类档案 · 2026-08-02 建）

> 统一风险登记落点：登记 → 处理 → 闭环 → 归档 全链条，纯对话式（无后台服务）。
> 职责：登记执行=助理（主对话）｜闭环拍板=老板（C 档问题类）·助理（A 档提醒类）｜监督审计=助理（2026-08-05 优化部门并入）

## 登记规范（档案室维护）

- **谁写**：助理（主对话）登记——唯一每轮对话在场的角色，登记不假手他人
- **何时写**：① risk-alert 每次 🔔 提示（提示即登记）② 审计发现 ③ 对话中发现风险信号/老板自述风险 ④ 新坑卡落库（教训沉淀）
- **≤1 行怎么写**：时间 + 类型 + 一句话预警 + 状态，处理过程不展开记；需追溯时引用来源
- **频率约束**：同对话同领域只登记一次；宁可少而真实

## 类型（六类固定）

交易资金 ／ 健康作息 ／ 财务生活 ／ 决策 ／ 规则 ／ 目标（漂移·冲突，挂 P-002，与 R-003 互引）

## 状态机

暴露中 →（开始处理）处理中 →（处理完成）已闭环 →（保留 3 个月）已归档（移入 `归档/`）

- **闭环判定二分**：提醒类（提示一次即完成使命）→ 助理自主判定（A 档）；问题类（需处理/上呈/需跟踪，如审计发现的越权）→ 处理完成后**老板确认**（C 档上呈，随月度汇报或专项呈报）
- 未闭环 = 持续跟踪对象，每次月体检「风险台账扫描」逐条过
- 月体检扫描：① 未闭环逐条过 → ② 已闭环满 3 个月归档 → ③ 输出台账月报（类型分布/高频领域/未闭环清单，呈报老板摘要）
