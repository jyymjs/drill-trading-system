# R-008 规划确认书：自动化市场环境复盘模块

- 版本：v1.0 | 日期：2026-08-04 | 提出方：学习视频借鉴（B站 BV1dbSMBuEfX 袁帅马「市场复盘三支柱」）| 规划部出品
- 状态：已确认 → 已施工（akshare 数据源）→ **待验收**

## 一、背景（为什么做）

学习视频「如何像工厂流水线一样复盘市场」提炼出**复盘三支柱**：指数（大盘定仓位）→ 板块（找资金方向）→ 短线情绪（赚钱效应）。

与钻潜体系对照后最大借鉴点：**「大盘决定仓位，个股决定买卖」——把每天开盘前的视觉复盘代码化**，让环境判断从"人眼看"变成"一键出结论"，与现有回测/扫描一样走量化稳定执行器路线（补课代码化策略，2026-08-04 拍板）。

技术可行性已验证：pytdx 可拉 5 大指数（上证/深成/创业板/科创50/沪深300）+ 5分钟~日线全周期（平均股价 880003 不支持，用沪深300 替代）。

## 二、目标

`python main.py market-review` 一键输出：

1. **指数一致性**：5 大指数走势是否同向（防「失增」——上证涨但其他跌 = 赚指数不赚钱）
2. **周期判断**：日线大周期（上涨/下跌/震荡）+ 60分钟/15分钟/5分钟 递进看压力位
3. **环境结论**：综合输出「进攻 / 中性 / 防守」三档 + 建议仓位区间
4. 终端版式报告输出（沿用蒙特卡洛同款中文版式风格），可保存归档

## 三、功能（首版范围）

| 项 | 内容 |
|---|---|
| 指数数据 | 上证/深成/创业板/科创50/沪深300，日线 + 5/15/60分钟 |
| 一致性 | 各指数当日涨跌方向统计，输出"全部一致 / 有背离（列出背离指数）" |
| 大周期 | 日线趋势判断（基于关键均线/高低点结构）：上涨周期→仓位建议偏高；下跌→偏低 |
| 压力位 | 多周期递进简化版：60分钟顶压力提示（60日新高附近回落 = 顶压力） |
| 结论 | 三档环境 + 建议仓位区间（与现有仓位管理对接，只出建议不动实盘） |
| 报告 | 终端版式（中文字符风格）+ 存档 `产出/输出/market_review/` |

## 四、边界（首版不做）

- ❌ 连板天梯/涨跌家数/跌停统计（短线情绪支柱——需额外数据源，二期）
- ❌ 板块产业链分析（需板块数据，二期）
- ❌ 自动调仓/交易信号（只出环境建议）
- ❌ 分时图一致性（首版用分钟 K 线近似）

## 五、验收标准

1. `market-review` 命令可跑通，5 指数 + 4 周期数据正常获取
2. 输出含：一致性结论、周期结论、环境三档 + 仓位建议
3. 与人工视觉复盘抽样对比 3 天，环境档位一致（抽样验证）
4. pytdx 断线时给出明确错误提示（不崩、可重试）

## 六、风险

- pytdx 服务器单点（当前可用 115.238.90.165）——做多服务器池 + 失败提示
- 指数周期判断是简化规则，不追求替代老师视觉判断——定位是"环境快照 + 参考"，人工复核兜底
- 平均股价数据不可得——沪深300 替代并在报告中标注
