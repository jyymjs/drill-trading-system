# 验证记录：B 站字幕获取链路（2026-08-01）

## 结论

B 站 AI 字幕**数据存在但必须登录态**；登录后 `wbi/v2` 接口返回**明文 subtitle_url**（aisubtitle.hdslb.com），直连可下载全文。纯 API 秒级方案成立。

## 验证过程摘要

| 步骤 | 方法 | 结果 |
|------|------|------|
| 1. 视频信息接口 | view?bvid= | ✅ 8/8 成功，无需登录 |
| 2. 字幕接口 v1（wbi/v2 未登录） | WBI 签名 + 游客 cookie | ❌ subtitles=[]（全部测试视频） |
| 3. 网页版真实接口（x/v2/subtitle/web/view） | 复刻浏览器请求 | ✅ 返回 protobuf 含 ai-zh/ai-en，但 URL 加密 + 域名废弃 |
| 4. 域名检查 | nslookup | ❌ subtitle.bilibili.com NXDOMAIN（已废弃） |
| 5. 播放器 JS 逆向 | 下载 player core.js | ✅ 定位解密逻辑：subtitle.bilibili.com → aisubtitle.hdslb.com，密钥表 un 已提取 |
| 6. yt-dlp 未登录 | --list-subs | ❌ 明确提示「Subtitles are only available when logged in」 |
| 7. 浏览器 cookie 提取 | --cookies-from-browser | ❌ Edge DPAPI 失败 / Chrome 数据库锁定 |
| 8. 登录态验证 | requests + SESSDATA | ✅ isLogin=True |
| 9. 登录态 wbi/v2 | WBI 签名 + SESSDATA | ✅ **返回 subtitle_url 明文**（aisubtitle.hdslb.com，auth_key 新鲜） |
| 10. 字幕直连下载 | requests 无 cookie 直连 | ✅ 123 条字幕全文（BV1BEyzBUEu3 交易逻辑） |
| 11. 播放器真实路径（交叉验证） | playwright 注入 SESSDATA | ✅ 播放器加载 ai-zh 字幕（日志 lan=ai-zh），真实 URL 与 wbi/v2 同款 |

## 关键事实

- 未登录：wbi/v2 和 v2/subtitle/web/view 都可能返回空/加密数据
- 登录后 wbi/v2 的 `subtitle_url` 是明文可用 URL；`subtitle_url_v2` 是加密版（废弃域名，不可用）
- auth_key 有时效，字幕 URL 必须每次现取，不可缓存
- 弹幕（dm/list.so）与信息（view）全程无需登录

## 环境

- Python 3.12.10，requests/bs4/yt-dlp 可用
- SESSDATA（小号 bili_57245533672）存于 `scripts/bilibili/config.local.json`（已 gitignore）
