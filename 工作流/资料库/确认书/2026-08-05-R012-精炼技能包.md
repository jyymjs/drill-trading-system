# 确认书：精炼技能包 R-012（2026-08-05 老板签字）

> 状态：✅ 已签字（2026-08-05 老板说"确认"）

## 背景

学习系统 R-011 推倒清零后，老板明确新需求：**只要知识精炼能力**（书/视频/网页/文本 → 精炼要点），不要复杂系统（无插件/无服务/无存储库）。

## 方案（3 个技能）

| 技能 | 输入 | 功能 |
|---|---|---|
| video-distill | B站视频链接 | 爬 AI 字幕（wbi 签名 + SESSDATA）→ 精炼要点 |
| book-distill | 书文件（PDF/EPUB/TXT） | 拆章 → 逐章精炼 → 合并要点 |
| text-distill | 网页链接 / 粘贴文本 | 抓正文或直接用 → 精炼要点 |

- 精炼输出统一格式：一句话概括 / 核心要点 / 适用边界 / 关键数字
- 产出直接呈报，不建库不存档
- B站字幕抓取固化为公共资源部脚本

## 验收标准

- 「精炼这个视频 BV1GcGX6iEUG」→ 出精炼笔记
- 「精炼这本书 xxx.pdf」→ 出分章精炼
- 「精炼这个链接 / 这段文字」→ 出精炼
