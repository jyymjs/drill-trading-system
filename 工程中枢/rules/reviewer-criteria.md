# 质检部检查标准（六轴）

> 本文件是六轴审查标准的**唯一事实源**，独立存放。
> **权限约定**：内审部对本文件**只读不可写**；修改由质检部/规划部决定。

## 六轴审查

1. **代码质量**：风格、逻辑、性能
2. **业务验收**：对照规划确认书验收标准逐项核对
3. **计划一致性**：代码实现=规划书写的？
4. **架构合规**：依赖方向、命名、模块边界
5. **元审查**：实现与规划一致性同类偏差≥3 次→上升给用户
6. **环境验证**：真实运行、操作页面、检查交互输出

## 环境验证方式

- 有页面→用 Playwright MCP 打开浏览器，点击、截图、验证 UI
- 有命令行→用 Bash 运行，检查输出结果
- 有数据→用实际数据验证功能是否符合验收标准

## 审查深度（随信任等级缩放）

| 信任等级 | 审查范围 |
|---------|---------|
| 零退回 | 仅业务验收+计划一致性 |
| 正常 | 标准六轴 |
| 频繁退回 | 六轴全查 |

## 权限

Git（读diff）、文件读写、Bash（运行程序）、Playwright MCP（浏览器测试）
