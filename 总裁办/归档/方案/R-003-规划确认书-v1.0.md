## 一、问题与目标（为什么做）

现状：长期目标已定稿（身份档案，2026-08-02），目标拆解工具（goal-decompose）也有，但**拆完没人管**——缺"季度拆解 → 月对标 → 变更确认"的持续闭环。本机制把目标管理从"一次性动作"变成"例行制度"：到点就拆、每月就对、改了必确认。

机制运行三原则：
- **纯对话式**：所有环节挂在既有对话节点上（月体检、开场流程、老板主动发起），无后台服务、无主动推送
- **不新增部门/角色**：全部用现有技能与档案组装
- **不动交易系统**：不涉及交易部任何文件

## 二、机制全景（怎么运转）

**节奏**：一年 4 次季度拆解 + 每月 1 次月度对标 + 随时可触发的目标变更确认。

**三层档案分工**：

| 档案 | 角色 | 管什么 |
|---|---|---|
| 身份档案·长期目标 | 事实层 | 目标"长什么样"（定稿口径） |
| 决定档案 | 审计层 | 目标"何时改、为什么改"（新旧并列留痕） |
| 事项档案 P-002 | 进度层 | 目标"推进到哪"（季度关键动作+每月进度） |

**节奏表**：

| 环节 | 何时发生 | 做什么 | 产出落点 |
|---|---|---|---|
| 季度拆解 | 季初月第一次对话（8/11/2/5 月，挂在月体检环节里带出） | 年度 → 季度关键动作 → 本月第一步 | P-002 季度进度 + 本月第一步入待办 |
| 月度对标 | 每月第一次对话（月体检固定环节） | 对照 P-002 季度关键动作逐条核对：达标/差距 + 证据 | P-002 进度更新 |
| 季度收官核对 | 季末月对标时（10/1/4/7 月） | 本季完成度小结 → 作为下季拆解输入 | P-002 季度小结 |
| 目标变更 | 老板明确改变目标/口径/期限时 | 决定档案新旧并列 + 身份档案同步 | 决定档案 + 身份档案 |
| 月/季复盘 | 老板说"复盘/回顾"时 | 对照季度关键动作复盘，产出作为对标证据 | 时间线 + 教训档案 |

> 季度按周年对齐：2026-08 → 2027-08 拆 4 段（08-10 / 11-01 / 02-04 / 05-07），季初月为 8/11/2/5 月，与 P-002 年度口径一致。

## 三、机制细则

### 1. 目标采集与更新规则（决定档案确认）

- **采集**：对话中出现长期方向性陈述（收入目标、职业规划、愿景类）→ 按记忆判定矩阵（"决定+理由"必确认）→ 老板明确表态后写入身份档案；低置信度先确认再写
- **更新**：目标口径任何变更 → 决定档案记变更（新旧并列、变更原因、日期；旧条目标"已作废被替代"）+ 身份档案同步更新；无老板明确表态不记
- **门槛与待办池一致**：随口讨论 ≠ 目标变更，明确拍板才算（防失真）

### 2. 季度拆解节奏

- 季初月第一次对话，月体检环节带出"本季度该拆解了"提示；老板当日不想做 → 记待办延后，不强制
- 拆解主工具：goal-decompose，输出"季度目标卡"（年度 → 季度关键动作 3-5 个 → 本月第一步可执行项）
- 落地：季度关键动作写入 P-002 进度；本月第一步入待办档案（按待办池规则，老板查看详情+拍板后进执行队列）

### 3. 月度对标机制（月体检挂钩）

月体检环节内含**两个并列检查项**（均固定小节，互不包含）：

- **「目标进度对标」**（本机制新增）：对照 P-002 季度关键动作逐条过 → 每条标"达标 / 差距 / 无记录"
- **「学习产出对标」**（原 P-002 已有，保留不动）：月体检读培训部学习产出（知识库/调酒师技术专家/）对标

通用规则：
- 差距必须附证据（时间线记录、待办完成情况、老板自述）；无记录诚实标注"记录缺失"（沿用复盘引导的诚实原则）
- 对标结果更新 P-002，属例行记录类变更（B 档先办后报），不打扰
- **严重偏离**（动摇年度目标本身，如副线连续亏损）→ 上呈 C 档做方向性讨论（decision-balance），不自行调整

### 4. 与既有技能衔接

| 技能 | 衔接点 |
|---|---|
| goal-decompose | 季初拆解主工具；细化"季初拆解"流程与"目标采集确认门槛" |
| review-guide（复盘引导） | 月/季复盘时对照季度关键动作提问；复盘产出作为对标证据 |
| priority-sort | 排序评分"重要性"维度显式读取身份档案长期目标（现为隐含依据，机制运行后固定化） |

### 5. 与 P-002 联动

- P-002 成为年度目标"活档案"：季度拆解写进度、月对标记结果、季末收官出小结
- 更新优于新增：不新建事项条目，季度子进度挂在 P-002 条目下
- 月体检排布：P-002 既有"学习产出对标"保留不动；本机制新增"目标进度对标"，两者为月体检环节内**并列两小节**，后者不包含前者

## 四、验收标准（对应转交单四条，可测）

| # | 业务验收标准 | 可测化 |
|---|---|---|
| 1 | 季度拆解输出：年度 → 季度关键动作 → 本月第一步（对齐 P-002 年度目标） | 季初月第一次对话产出"季度目标卡"，对齐 P-002 年度目标；本月第一步进入待办档案 |
| 2 | 月度对标：月体检必查"目标进度"项，对照 P-002 更新 | 月体检报告含"目标进度"小节（与既有"学习产出对标"并列）；P-002 同步更新；每条有证据或无记录标注 |
| 3 | 目标变更：走决定档案确认（口径变更新旧并列） | 任何口径变更后，决定档案有新旧并列记录 + 身份档案已同步 |
| 4 | 与既有工具衔接：goal-decompose、复盘引导、priority-sort 引用长期目标 | goal-decompose 输出季度目标卡；复盘引导对照季度动作提问；priority-sort 显式引用长期目标 |

## 五、子任务分解（签字后执行）

### 子任务 1：季度拆解流程（goal-decompose 技能）
- 标准：技能含季初拆解步骤（季度目标卡输出格式）与目标采集确认门槛（明确拍板才记）
- 验收：季初月对话按固定流程产出季度目标卡，新目标未经确认不写入身份档案

### 子任务 2：月度对标与变更确认（助理规则）
- 标准：助理规则月体检环节新增"目标进度对标"固定小节；变更确认流程写明（决定档案+身份档案双落点）
- 验收：月体检报告含目标进度小节；目标变更走决定档案且身份档案同步

### 子任务 3：复盘与排序衔接（review-guide + priority-sort 两技能）
- 标准：复盘引导月复盘对照季度关键动作提问；priority-sort 重要性评分显式读取长期目标
- 验收：复盘提问含里程碑对照项；排序评分依据明确含长期目标

### 子任务 4：P-002 联动（事项档案）
- 标准：P-002 条目含季度进度记录位（季度关键动作+月度对标结果+季度小结）
- 验收：拆解/对标结果可直接落到 P-002 对应季度段

## 六、风险标注

| 风险 | 判定 | 缓解 |
|---|---|---|
| 形式主义（对标走过场） | 中 | 验收要求"差距+证据"，无记录必标注，可测 |
| 漏触发（纯对话式无推送） | 中 | 全部挂月体检固定环节，开场流程兜底（月体检本身即每月首次对话必跑） |
| 目标变更失真（随口说≠变更） | 中 | 拍板门槛与待办池机制一致，未拍板不记 |
| 月体检内容膨胀 | 低 | 对标固定一小节，不扩流程 |
| 改规则/技能文件（制度修改） | 中-高 | 只新增小节不重构；整体方案签字后执行，执行阶段走审查 |
