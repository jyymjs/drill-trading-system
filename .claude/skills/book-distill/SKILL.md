# 书籍精炼

**触发**：「精炼这本书 <文件路径>」。极简流程，不向用户展示步骤，直接给结果。

## 做法

1. **按格式提取文本**（pypdf / ebooklib 已装）：
   - **PDF**：`pypdf` 逐页 `extract_text()`；按章节标题切分，无章节结构时按页序分批（每批约 20~30 页）
   - **EPUB**：`ebooklib` 逐章提取（`ITEM_DOCUMENT`），按章节标题组织
   - **TXT**：直接读全文，按标题/空行切分
   - **扫描版 PDF**：提取不到文本 → 明确提示「需先 OCR」，不硬做
2. **逐章精炼**：每章提炼要点，长章分批
3. **合并**：各章要点合并成整本精炼笔记

## 输出格式

```
一句话概括
章节要点（按章节/批次逐条）
核心要点（全书结论 + 依据）
适用边界（什么情况成立/不成立）
关键数字（数字一律原样保留）
```

## 防失真（强制）

- 数字、百分比、时间**原样保留**，不做四舍五入式转述
- 「可能/大概率/有时/只对X有效」等限定词**必须保留**
- 结论必须带依据与成立条件，不编造不推断书外的内容
