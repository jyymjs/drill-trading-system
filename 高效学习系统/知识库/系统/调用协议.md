# 知识库调用协议（检索唯一源 · 定检索面 + 四级检索 + 关联跳转）

> 本文档是模型与人调用知识库的**统一检索协议**，一律按此执行，不靠自觉。
> 目的：省 token 的核心机制——**只读需要的文件，不扫全库**。
> 数据层规则（分类/命名/双库分层/元数据/索引维护/知识接入）→ [分类规范.md](./分类规范.md)，本文件只负责"怎么找"。

## 检索入口

- 知识库根：`知识库/`（本系统私有，仅高效学习系统调用；跨系统只读调用公司资料库见「权限声明」）
- 双索引入口：`知识库/index.md`（老板知识库 + 公司资料库两库索引均从本文件进入）
- 主题局部索引：`知识库/{老板知识库|公司资料库}/{主题}/index.md`（仅该主题文件 >8 个时存在，触发规则见分类规范「六」）

## 第 0 步：定检索面（双库 · R-001 定案）

- **默认只检本库**：检索前先明确本次调用查哪一库（老板知识库 / 公司资料库 / 系统+复盘元层）
- **跨库须显式声明**：需同时使用两库内容时，先说明跨库意图与理由，再分别按库检索
- 元层（系统/复盘）任何调用可达，不受检索面限制
- 产出头部带「库归属」标记（分类规范「四」）——调用时以库归属为第一判定依据，翻目录即辨人学/系统学

## 四级检索协议（严格按顺序，先定检索面）

```
① 对库索引入口找主题
   → 读 知识库/index.md 的对应库分区，从「主题入口」找到目标主题名（如 公司资料库/AI学习方法）
② 主题局部 index 找文件（若存在）
   → 若 知识库/{库}/{主题}/index.md 存在，读它拿精炼文件列表；不存在则跳过本步
③ 文件名 + 元数据判相关性
   → 在主题目录下，只 grep/匹配文件名（{日期}-{主题}-{内容要点}-{类型}.md）
   → 命中候选后读文件头的元数据块（标题/主题/库归属/来源/日期/关键词/时效性/可靠性/关联）二次确认
   → 文件名不命中即不读全文；raw/ 层文件一律不参与本步
④ 正文（才读取）
   → 只有通过 ③ 的文件才打开正文
⑤ 关联跳转（网状结构，可跨库）
   → 读完正文后，若需要延伸，可循元数据「关联:」字段跳转到相关主题/知识卡
   → 跨库关联路径带库前缀（如 `老板知识库/AI学习方法/xxx.md`）；从关联主题进入时，重新从 ② 或 ③ 开始（不直接读关联目标全文）
```

## 双库联合规则（相关可联合 · 助理判定）

- 两库内容**相关时可由助理判定联合使用**（如某方法建议书 + 相关学习笔记对照）
- **联合产出入公司资料库**（两库联合学习后新提炼的产出，按归位规则落公司库）
- **老板知识库内容仅作参考输入，不抄入公司资料库**——引用如实标注来源（带库路径）；需落地为产出时走学习流程重新提炼
- 跨库查重：新产出入库前两库索引都查（分类规范「双库分层·跨库查重」）

## 公司资料库 · 全项目权威参考源（老板 2026-08-02 拍板）

- **公司资料库为所有项目的权威参考文件**：本地文件中，只有公司资料库内的文件具有参考意义（知识/方法参考以公司库为准）
- 其他项目本地文件属**执行资产/过程文件**（策略代码、脚本、日志、临时产物），不作知识参考依据
- 跨库检索/联合使用时**公司库优先**；规划部/工程部做方案设计、学习复用时的知识依据一律走公司资料库（按本协议四级检索）

## 铁律

1. **raw/ 层默认不进检索**：`{库}/{主题}/raw/` 是原文层（字幕/论文原文/书籍分卷），只在文件名精准命中（如按 BV 号溯源）时才按需进入；索引不列 raw，调用不读 raw 全文
2. **主题知识卡优先**：某主题已存在 `{主题}-知识卡.md`（碎片 ≥5 合并而来）时，调用该主题**只读知识卡**；碎片文件进 `{主题}/archive/`，按需进入
3. **时效性过滤**：元数据「时效性: 长期/中期/短期」——调用时按需过滤（如学习 2026 年内容时排除标记为短期的 2024 旧条目）
4. **不读全文找相关性**：任何情况下不得为了判断相关性而读取整个文件
5. **调用后不污染库**：调用只读；新增/修改走知识接入协议（见分类规范「九」）
6. **可靠性与冲突提示**：读到标有「可靠性: 自述传闻/待核实」或「冲突」的条目时，结论使用需标注风险，不静默采信

## 新增产出时的索引维护

- 产出入库一律按知识接入协议五步执行（见分类规范「九」），**先跨库查重（两库索引都查）**，索引更新规则见分类规范「七」（更新**所属库**索引入口）
- 新主题：先查双库 index 确认无近似名，再按分类规范建目录（归位规则见分类规范「双库分层」）

## 本协议适用范围

- 高效学习系统全部调用（对话式学习 / 考问模式 / 系统学习模式 / 复盘）均按本协议检索
- 知识库私有：其他系统不主动调用；**规划部/工程部按「权限声明」只读调用公司资料库**（供料复用），检索一律走本协议（先定检索面）
