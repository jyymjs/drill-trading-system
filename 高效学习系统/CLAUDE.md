# AI 高效学习系统

> 独立系统：为所有新知识提供学习流程——抓取 → 入库 → 对话学习 → 可调用产出。
> 本系统自包含（角色/技能/脚本都在本目录），不混入项目工程框架；知识库归系统私有。
> 设计依据：《知识库/AI学习方法/2026-08-01-AI学习新知识-学习闭环-方法建议书.md》7 项方法。

## 这是什么

把「B站视频/网页/论文/书 → 可复用的知识资产」的链路产品化。**只有用户与 AI 直接对话**——无子 agent，质疑/批判/苏格拉底引导全部融入对话。

三种形态（培训部双轨制，R-001）：

- **对话式学习**（人学轨道）：给链接/资料/需求/书 → 抓取入知识库 → AI 讲解 + 质疑材料 + 苏格拉底引导 → 产出学习笔记（老板知识库）/ 方法建议书（公司资料库）
- **系统学习模式**（系统学轨道）：老板提功能需求（「调研 XX」）→ 联网检索（≤5 来源）+ 抓取（全文 ≤3）→ 提炼《方法建议书》→ 入库闸门自审 → **直接入公司资料库**，为规划部供料（时间盒 ≤30 分钟；R5 豁免仅限此场景）
- **考问模式**（复习复盘）：说「考考我 XX / 复盘 XX」→ AI 出题考问 → 错题卡间隔重复（1/7/30）→ 毕业自动清理

核心思路：先抓原文（raw 层，保真），再对话提炼（笔记/建议书），产出全部可追溯回来源；提炼质量靠「过程防失真 → 产出分级 → 结果验证」三道防线。

## 三种形态怎么用

**对话式学习（给链接，要总结）**

> 用户：「学习这个视频 https://www.bilibili.com/video/BV1wMduBNEPS，总结一下」
>
> 执行：抓取入 raw → 对话学习（讲解/质疑/先问后讲）→ `知识库/{主题}/{日期}-{主题}-{内容要点}-学习笔记.md`

**对话式学习（给需求，要规划输入）**

> 用户：「我要建一个 A 股量化选股系统，帮我调研可行方法」
>
> 执行：来源定位（外部择优 + 模型知识直接参与）→ 抓取入 raw → 对话学习 → `知识库/{主题}/{日期}-{主题}-{内容要点}-方法建议书.md`

**考问模式（复习复盘）**

> 用户：「考考我出场体系」
>
> 执行：调知识卡+错题卡 → 出题 → 追问自纠 → 批改归因 → 错题卡 1/7/30 复习

## 资料库位置（系统私有 · 双库）

- 学习产出全部存 `知识库/`（本系统数据层，**仅本系统调用**；规划部/工程部按协议权限只读调用公司资料库）
- **双库结构**：`老板知识库/{主题}/`（人学轨道：学习笔记/错题卡/raw）+ `公司资料库/{主题}/`（系统学轨道：方法建议书/raw）+ `系统/`（协议/规范/模板）+ `复盘/`（体检报告/素材台账，元层不分库）+ `index.md`（双索引入口）
- 归位规则（建议书→公司库、笔记/错题卡→老板库、raw 跟随、跨库查重）见 `知识库/系统/分类规范.md`「双库分层」；检索见 `知识库/系统/调用协议.md`（定检索面 + 四级检索 + 关联跳转）
- 素材台账 `知识库/复盘/素材处理台账.md`：系统学习启动前 / 周复盘建议主题前必查，已处理素材不重复提炼

## 学习流程入口

- 直接说需求即可，AI 自动判定形态并执行（细则在 `.claude/skills/learn/SKILL.md`）
- 资料库体检：「复盘资料库」→ 四步复盘 + NEXT 清单
