# AI 学习部（私人老师）

> 独立系统：老板的**私人老师**——对话式学习 + 考问复盘 + 扫库查重。
> 本系统自包含（角色/技能/脚本都在本目录），不混入工程中枢；知识库归系统私有。
> 2026-08-03 老板拍板：原"培训部双轨制"改为"私人老师"——公司资料库/系统学轨道/入库闸门废除；交易知识归交易部自建知识库。

## 这是什么

**私人老师**：只有用户与 AI 直接对话——讲解、质疑、苏格拉底引导、考问全部融入对话。三种形态：

- **对话式学习**：给链接/资料/需求/书 → 抓取入知识库 → AI 讲解 + 质疑材料 + 苏格拉底引导 → 产出学习笔记（老板知识库）
- **考问模式**（复习复盘）：说「考考我 XX / 复盘 XX」→ AI 出题考问 → 错题卡间隔重复（1/7/30）→ 毕业自动清理
- **扫库查重**（2026-08-03 新增）：说「查一下交易部知识库的矛盾」→ 扫描交易部知识库 → 发现矛盾知识 → **找交易部经理讨论裁决**

核心思路：先抓原文（raw 层，保真），再对话提炼（笔记），产出全部可追溯回来源；提炼质量靠「过程防失真 → 产出分级 → 结果验证」三道防线。

## 三种形态怎么用

**对话式学习（给链接，要总结）**

> 用户：「学习这个视频 https://www.bilibili.com/video/BV1wMduBNEPS，总结一下」
>
> 执行：抓取入 raw → 对话学习（讲解/质疑/先问后讲）→ `知识库/老板知识库/{主题}/{日期}-{主题}-{内容要点}-学习笔记.md`

**考问模式（复习复盘）**

> 用户：「考考我出场体系」
>
> 执行：调知识卡+错题卡 → 出题 → 追问自纠 → 批改归因 → 错题卡 1/7/30 复习

**扫库查重（知识质检）**

> 用户：「查一下交易部知识库的矛盾」
>
> 执行：扫描 `交易部/知识库/` → 提炼五问/抗失真核对 → 矛盾清单 → 找交易部经理讨论 → 裁决更新

## 资料库位置（系统私有 · 单库）

- 学习产出全部存 `知识库/`（本系统数据层，**仅本系统调用**）
- **单库结构**：`老板知识库/{主题}/`（学习笔记/错题卡/raw）+ `系统/`（协议/规范/模板）+ `复盘/`（体检报告/素材台账）+ `待处理/`（素材中转区）+ `index.md`（索引入口）
- 归位规则（笔记/错题卡/raw → 老板知识库）见 `知识库/系统/分类规范.md`；检索见 `知识库/系统/调用协议.md`
- 素材台账 `知识库/复盘/素材处理台账.md`：学习前必查，已处理素材不重复提炼
